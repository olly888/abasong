# Abasong 国际化视觉与设计系统 V2

初稿日期：2026-10-28。基线校准：2026-10-29。状态：用户已认可的视觉方向与基础组件规范；最终品牌资产、完整页面状态和生产组件库仍需交付。

## 1. 本版决定

按照用户最新要求，主方向调整为**黑白、中性灰、明确的字体层级、地图与上下文面板**。参考 Uber 所代表的出行工具设计方向，由 Abasong 自己的司机协作业务推导交互，不复制其商标、专有字体、图标或具体当前页面。本轮未做外部网站调研。

服务对象是在美国工作的华人司机及 DSP，产品保持中文优先，同时适配美国真实地址、金额、距离、时区与通知场景。国际化体现在结构、质量与本地使用习惯，而不是把所有按钮强制换成英文。

保留的产品边界：同一端；首页/司机圈/我的；没有 DSP 工作台；配送费用双方私下结算，平台没有配送对账、付款、到账或钱包功能。

## 2. 品牌气质与视觉规则

关键词：**直接、清楚、可信、自主**。

- 主体为黑白，颜色服务状态和定位；取消 V1 的黄绿品牌强调。
- 大标题有力量，任务内容有秩序，辅助信息安静；重要性不靠同时加粗和上色。
- 减少胶囊、彩色背景块、重阴影和口号装饰；卡片更紧凑但不拥挤。
- 空间信息交给地图，判断条件交给卡片，沟通交给会话，历史交给个人记录。
- 一处一个主要动作；当前协作持续可恢复；多任务不变成密集报表。
- 用户需要看到谁发布、何时可接、范围与报价，以及下一步，品牌露出不抢这些内容。

品牌字标暂用小写 abasong 的黑白排版。连接路径符号仍为探索稿，不代表最终 Logo 或已完成商标检查。品牌表达候选为“连接附近的司机，让每一次协作更简单”；展示板英文主标题是方向表达，不要求在 App 工作首页常驻。

## 3. 色彩系统

| 语义 | 色值 | 使用 |
|---|---|---|
| 主要文字/主按钮 | `#101114` | 任务、标题、主要操作 |
| 背景 | `#F6F6F6` | 应用画布，白色卡片上浮 |
| 卡片 | `#FFFFFF` | 内容与面板 |
| 弱表面 | `#F0F0F0` | 搜索、头像占位、分区 |
| 次级文字 | `#53565B` | 描述与辅助信息 |
| 元信息 | `#686C73` | 时间、来源等，按背景验证对比度 |
| 非关键分割 | `#E3E4E6` | 列表分割，不单独充当必要控件边界 |
| 必要控件边界 | `#82858A` | 次级按钮和输入边界 |
| 功能蓝 | `#245CC4` | 自己定位、文字链接、焦点；不大面积铺背景 |
| 蓝色浅表面 | `#EDF3FE` | 信息说明 |
| 成功 | `#236346` | 明确完成或可用状态，配文字/图标 |
| 提醒 | `#855307` | 等待确认与需注意 |
| 错误 | `#AE3734` | 失败、失效与危险操作 |

令牌 `signal` 现为浅蓝辅助表面 `#E8EFFA`，仅为兼容既有预览变量；不再代表品牌强调或认证。正式组件应优先使用有语义的 action、text、surface、status 和 focus 别名。蓝、绿、徽章不能把自报经验伪装成官方认证。

当前生成器检查 10 组指定色对；指定正文至少 4.5:1，必要控件边界和焦点至少 3:1。该检查不是整套产品无障碍认证；地图叠加、禁用态、实际设备与辅助技术需另行验证。

## 4. 字体、形状与组件

产品采用系统无衬线字体栈。中文依设备使用清楚的系统 CJK 字体，拉丁字与数字用系统字体；不加载或仿制其他品牌的专有字体。

工程字号：H1 28/36，卡片标题 20/28，正文 16/24，标签 14/20，辅助信息 13/18，关键数字 28–32px。数字使用等宽数字特性，金额和时间对齐。展示板的并列手机为缩略示意，字号不替代实机标注。

基础单位 4px；页面边距 16–20px；控件圆角 10px；卡片 16px；面板顶角 24px；最小触控区域 48px；主要按钮建议 52px。阴影只用于地图浮层与空间分离。

按钮为黑底白字、浅灰次级和文字操作三层。危险操作有独立语义，不能用所有按钮都黑色掩盖后果。每个组件定义按下、焦点、加载、禁用和错误，禁用原因可见。

需求卡、司机卡、公寓卡共用清晰的字级和间距语法，各自按任务决定信息顺序。公寓收起卡优先地址与密码，反馈与贡献均在展开卡内；需求卡优先区域、时间、报价单位和剩余缺口。不新增独立“当前协作”履约卡，任务报价不作为收入余额。

## 5. 地图与导航

浅灰城市底图，白色道路，低饱和公园；保留必要道路、街区与对象标签。预览使用 SVG 示意，不是真实地图与导航。

任务使用黑白价格标签；选中时反白，并同步底部卡片。可用司机按概略区域和主动状态呈现，不画持续移动车辆。自己位置用功能蓝，不能把蓝点样式滥用到其他司机实时定位。

三导航始终相同；选中态由字重、图标和位置指示表达，取消黄绿胶囊背景。发布等二级流程可暂时隐藏导航，返回恢复；首版不做交接履约流程。

首页视图为公寓/找活/找人，切换内容不切用户身份；首次默认公寓。独立“＋ 发需求”不放在公寓卡内。底部面板承载当前选择；必要详情进入二级页。司机圈首版提供文字互助动态、需求卡和基础回复；我的展示本人及有权限的记录，不生成 DSP 工作台或配送财务中心。页面范围以 V12 为准。

## 6. 面向美国华人司机的本地化

| 内容 | 规则 |
|---|---|
| 操作说明 | 中文优先，可提供完整英文语言设置，不每行堆中英双语 |
| 地名与地址 | 保留官方英文拼写，按 street/city/state/ZIP 结构；不翻译成难以与面单对应的中文 |
| 姓名 | 中文常用名与英文名均可自愿展示，不强制填写英文名 |
| 金额 | 配送报价使用 USD；显示 `$1.80 / 件` 等，涉及多币种时明确代码 |
| 距离 | 默认 mi；单位始终可见，不把区域距离称为预计到场时间 |
| 时间 | 默认适配美国 12 小时制与 AM/PM；支持用户改为 24 小时制，跨天写日期 |
| 时区 | 按任务当地时间展示；跨区域或不同日历日时写明时区，处理夏令时 |
| 电话 | 支持 +1 等国际格式；不在公开地图暴露联系方式 |
| 私下结算 | 使用清楚的中文说明，保留双方发布的约定，不设计平台收付状态 |

预览已将主要任务时间示例调整为 2:00 PM、6:30 AM 等，但不是完整语言设置实现；完整格式化由生产产品的本地化层负责。

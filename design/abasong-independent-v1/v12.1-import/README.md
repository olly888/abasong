# V12.1 截图贡献扩展原型

日期：2026-10-30。新增流程待用户评审；原先认可的[原型](../v12.1/index.html)完整保留。本版是独立交互演示，不是原生应用或真实OCR服务。

入口：http://127.0.0.1:8765/v12.1-import/index.html?flow=screenshots 。静态服务根目录为design/abasong-independent-v1，仅绑定127.0.0.1。

## 体验路径

手机视图：首页→我的→贡献公寓资料→选择截图→选一张或多张→添加→识别→集中确认→导入结果。

桌面外壳还可点“截图导入与批量确认”从空页体验，或“打开混合批次”直接开始；勾选“下一次识别部分失败”“下一次提交部分失败”验证恢复。外壳的场景和页面目录仅供原型评审，不属于App产品界面。

- 六张合成截图，包含单图多条、重复密码、字符歧义、缺失地址及未收录公寓。
- 可提交/待处理分组，一次来源与归属确认，异常项可改、选公寓或提交新公寓提议。
- 部分成功/识别失败重试/提交失败重试、截图预览、稍后继续、本人批次与取消。
- 入口接入U01、U06、H01展开层、B02；三导航与密码排序保持原基线。
- 文本粘贴和表格导入为P1，外壳说明保留，App画面不放不可用的菜单或开发备注。

## 数据与能力边界

选图界面是合成图库模拟系统选图；samples/*.svg与候选数据预先对应，不读取用户相册、不上传图片、不执行OCR、不连接地图/后端/真实账号。不能用这些固定样例测识别准确率。本版没有选择真实文件的入口，避免将任意真实截图映射为虚假识别结果。

导入草稿、来源、候选和成功记录只在页面内存保存；刷新/关闭页面后清空。离开原型内页面可继续，不代表进程结束恢复或加密服务端草稿已经实现。代码中的资格、去重及取消只是合成交互，不是服务器鉴权/事务。仅继承的公开需求分享使用本版独立合成localStorage键（与原版本隔离）；导入不新增持久存储。

app.js、prototype.css、tokens.css继承原基线；imports.js与imports.css提供扩展。原生代码、OpenAPI、数据库和OCR技术选型本轮未修改。

[实际验收记录](验收记录.md)只覆盖列明的浏览器场景；39节点/237状态没有全部逐项验收。新增页面不是用户已经认可的基线。

## 我的公寓扩展

访问 `http://127.0.0.1:8765/v12.1-import/index.html?flow=library`。U06包含我保存的/我共享的，U09含私人记录与最新共享资料；截图默认私存，可明确勾选共享。支持区域、未知地址先保存、私存修改、主动共享与贡献纠正。所有私人记录、效果统计和提交均为内存合成演示，刷新清空；不是原生密码管理或真实OCR服务。当前规格40节点/251状态，非全部已验收。

## 贡献优先调整

U01主按钮贡献公寓密码→截图识别/快速填写；私人导入留在U06。共享入口默认共享、私存入口默认私存，B05显式范围单选及来源确认，切换清确认，首次提交锁定。U06卡片直显一条私存或当前有权共享密码。首页收起无收藏/我的公寓文字；空卡添加，展开添加前置与收藏图标。当前40节点/259状态，完整状态验收未完成。

# Abasong V12.1 交互原型

日期：2026-10-29。当前状态：用户已体验并认可本版，可作为正式开发参考基线；不是已接入真实服务的App，也不是全部207种规格状态已经验收通过。后续小优化随开发记录迭代。

打开：`http://127.0.0.1:8765/v12.1/index.html`。沿用原本本地静态服务，旧版preview.html保留。若服务未运行，在本目录上级以Python静态服务启动，并使用实际端口。

## 本版可体验

- 首页公寓/找活/找人三地图视图、搜索、列表替代、当前对象卡和独立发需求。
- 公寓卡收起/展开、多条历史、大字、有用/没用及撤回反馈；有效有用组先、组内贡献时间倒序。
- 添加新密码；同码同范围合并验证，不刷新原贡献时间；本人贡献元数据、撤回后停止展示正文。
- 多公寓选择、无资料、无固定码、定位拒绝/旧位置、无资格、未登录和网络失败的本地场景。
- 部分包裹/整线/增加司机的当次需求；取件与配送区域分离；数量、下限、报价、理货及接手条件。
- 草稿、发布核对、需求详情、部分数量报名、条件变化先核对、我的报名/撤回、管理报名、缺口、关闭/重开/复制。
- 一对一文字会话、需求来源版本、失败重试、未读、常联系/备注、屏蔽、明确分享/撤回集合点。
- 可接活时段/区域设置，司机基础档案、最小组织来源；司机圈文字、基础回复及同ID需求卡。
- 发布者公开摘要分享、复制、预览、撤销；同一浏览器下新标签可看摘要，关闭后只显示终态。
- 我的记录、资料、设置；本地登录/资格申请/删除申请等界面演示。

只做临时配送支援和灵活运力协作，没有长期招聘、带教/试线/入职、支付/钱包、自动派单或POD。

## 演示控制与数据

桌面宽度下，手机两侧为原型外壳：四条流程入口、十种公寓场景、消息失败/报价变化/到期/记录失效测试开关、页面目录、重置。移动宽度只显示App画面，测试说明不进入产品界面。

手机登录使用合成号码格式；演示验证码`123456`，没有短信请求。默认以已有配送资格的合成账号进入，未登录/无资格可从外壳切换。所有姓名、门码、地址、价格和对话为合成，不能用于真实投递或分享真实敏感资料。前端资格判断只是原型呈现，不是安全控制；JS中包含可读合成数据，真实权限/加密必须由后端实现。

业务数据在内存中，刷新重置。仅主动分享的公开摘要用专用localStorage键`abasong-v121-public-synthetic`暂存，以支持同浏览器新标签预览；不存密码/私聊/精确集合点。关闭后摘要缩减为终态，撤销时清除摘要；重置会清除此专用演示键，不改其他网站数据。链接不支持跨设备真实分享，Auth与完整需求resolve仍为本地合成流程。

## 文件

- `index.html`：原型外壳、手机容器与外部测试入口。
- `prototype.css`：响应布局、地图/卡片/表单/消息组件。
- `app.js`：合成模型与本地导航/交互。
- `tokens.css`：V3令牌快照，与项目docs/design/tokens-v3.css一致。
- `coverage.json`：节点制作状态与覆盖边界。
- `page-smoke.json`：32个路由/复用页的渲染检查；加H02/H03及G01/G03对应36设计节点。
- `scenario-smoke.json`：十种公寓场景的DOM呈现/隐藏检查。
- `responsive-checks.json`：375/390/430首页宽度与三导航检查，不代表所有页面均完成响应测试。
- `验收记录.md`：已实际操作的流程、已修复问题及待验证事项。

## 未接入与未完成验收

地图为自制SVG，定位/匹配为场景切换，不是Mapbox接入或洛杉矶精度结果。无后端、Auth、通知、消息、审核运营、司机在线或承运商接口。到期由测试开关模拟，不是完整服务端定时器；反馈有效期用合成状态表达，尚无生产参数窗口/反滥用引擎。不得将浏览器里的假数据权限当成真实数据隔离。

号码恢复、资格申请、账号删除进度等为概要交互，实际供应商/后台处理尚未实现。语音、图片、地图拖拽缩放、专业救援均未增加。面板有展开/收起与手柄拖动，完整原生嵌套手势/键盘、VoiceOver/TalkBack、200%系统字体、户外真机与真实业务测试仍待执行。

项目页面规格的207种必要状态没有逐一验收；当前结果只覆盖记录中列明的浏览器操作和静态/响应检查。下一轮按四条任务评审，记录问题后迭代再冻结原型，不直接宣布生产开发完成。

# Abasong V12.1 需求补充与原型决策

日期：2026-10-29。状态：按用户最新明确边界收敛；与 [PRD V12](../Abasong_PRD_V12_首版产品需求.md) 共同组成当前需求基线。冲突处以本补充和最新用户指令为准，未修改部分沿用 V12。

## 1. 产品边界

**Abasong只做临时配送支援和灵活运力协作，不做长期招聘或司机招募平台。**

配送找人的对象是某一天、某一区域/线路、某一批包裹或当次所缺的司机。DSP与司机可以通过常联系再次合作，但产品不管理长期雇佣、招聘周期、入职、转正、带教或试线。此前从朋友圈样本推导出的长期招募方向已取消，不纳入原型、接口或数据模型。

固定结构不变：同一端、首页/司机圈/我的、首页公寓/找活/找人、独立发需求；密码查询优先，配送费用完全私下结算。

## 3. 当次支援字段及数量规则

配送发布必填：支援类型、承运商、配送区域、取件区域、具体开始日期时间、有效截止、当次包裹数量、报价及单位或明确联系议价、理货状态、接手条件。增加司机另填本次所需人数；最晚到仓和配送截止有约束时填写。一般车辆/其他求助继续使用简化地点/时间/说明。

`parcel_count`为本次待分配量；`remaining_parcels`为发布者确认的剩余缺口；`minimum_parcels`为每位最低承接量；`capacity_parcels`为司机当次可接数量；`accepts_partial`为是否允许不同司机分担。这些字段不表示已分配、已到场或已送完。

- 整线：不可拆分，最低承接量等于当次整线件数；界面明确接整线，不伪装可接其中30件。
- 部分包裹：可声明每人最低量，空值表示未声明下限，不显示“最低0件”。
- 增加司机：仍关联本次包裹与人数缺口，不接受无限期“储备人员报名”。
- 可接数量不得小于最低量或大于当前剩余量。剩余量低于原最低量时暂停新的数量报名，允许先联系；发布者需修改最低量，不由系统擅自豁免。
- 报名必须填写本次预计可到时间；不会因报名直接扣减缺口，人数/件数归零仍由发布者确认已找到。
- 已发布类型不直接切换，避免改变报名者理解；需要另一类型时关闭/复制成新草稿，原报名不搬走。
- 每条都有截止；原型以所选配送日为任务时间，不默认滚动7天长期开放。重开先更新有效时间，不能后台续期。

## 4. 区域、经验与报价

取件区域选择已定义的城市/区域/ZIP，存`pickup_region_id`，`pickup_area`为服务端派生的区域标签；配送区域为`region_id`。地图中心与距离标签明确属于哪个区域。精确集合点经发布者在会话中明确分享，不写入公开地图或分享摘要。

经验要求`any/delivery_experience/carrier_experience`，默认不限；司机自报与已核验信息分开。不能仅因缺少平台核验就把有相关经验的人判定不能支援，可补充经验/联系确认。无独立新手带教、试线、入职或长期合作类型字段。

报价是USD每件/每线路或联系议价；空金额不当作0美元，不把单量推导成日收入或净时薪。“当天结/周结”等只是发布者私下付款文字，适用条件可写在详情，不新增平台付款、到账或担保。

## 5. 分享与匿名边界

只有发布者主动分享已发布需求；公开摘要预览确认后生成高熵UUID4 token链接，复制或调用系统分享面板。用户自行选择是否发微信，平台不代发、不导通讯录、不假定微信分享SDK可用。

游客可读白名单：支援类型、承运商、配送区域、取件大致区域、当次数量/人数/最低量、报价及单位、经验要求、时间与有效状态、发布者自选公开显示名/组织名。自由说明/试线文字、手机号/微信、精确集合点、报名名单、司机精确位置、门禁、私聊、内部用户ID及完整需求历史不进入该DTO。

公开页使用独立摘要接口，不开放正常Request对象。关闭/到期显示非敏感标题及终态；撤销/不存在token返回不可用。分享token只授公开摘要读取，不能替代登录或密码资格。服务器限制访问频率，不在APM/访问日志保存原始token。

游客点报名/联系，保留token和意图，登录后通过认证resolve接口查当前需求，再由用户提交；不自动接受旧报价。未安装App时提供分发/登录入口，首版H5不复制完整司机工作端。原型可以演示回跳，实际深链及微信内表现待真实构建验证。

## 6. 本次页面梳理带来的必要对齐

- 我的贡献按元数据展示审核/撤回状态，资格失效仍可看本人记录；查看正文另查权限。
- 司机未声明可接活时，基础档案仍可看，availability可为空；找人列表仍仅显示主动声明有效的人。
- 消息总未读由独立汇总接口提供；进入消息中心不清空所有未读。
- 草稿可软丢弃，仅本人未发布草稿可操作，不删除已发布历史。
- 用户整体同意品牌推荐后，V3为新版原型设计基线；旧preview及V2令牌保留历史，不能混作已经升级完成。

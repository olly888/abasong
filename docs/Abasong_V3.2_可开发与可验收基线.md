## 4. 开发门槛与B5顺序

文档/原型准备 → 真实任务观察/问题修正与用户确认 → R4-1卡片/区域/相机 → R4-2日期/仓库/声明 → R4-3贡献/纠正/报名/消息保护回归 → B5。各批相关自动检查后，逐页按同一目标核对iOS/Android功能及视觉；未改变的既有手势不反复请求用户补测。

B6真人/云业务KMS/推送/独立包/物理设备和现场质量保持发布门槛；它们可集中安排，不以此阻塞所有独立本地开发，也不假装完成。云资源/短信/账号资格本轮没有变更。

[司机圈补充](product/Abasong_V3.2_司机圈定位与最小社区补充.md)及C01–03原型已制作，UP13/UX11；另10条B5跟进任务未测，原38条核心和0/7不变。实际App司机圈仍未开放，不将原型计作B5完成。

机器状态见[开发基准JSON](product/V3.2_开发基准状态.json)。未填人测数据不生成通过率；不将已实现能力重新列为全新开发量，不将未实现差异标为已验。

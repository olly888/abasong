## 2. 唯一来源及就绪含义

- 产品裁决：[产品基线](../产品基线.md)→最新补充/页面规格→认可原型→基础PRD。历史“待体验”或旧发布分类不能覆盖最新裁决。
- 设计：[V3.2目标](design/Abasong_设计系统_V3.2_升级方案.md)是已认可实施目标；当前App沿用V3.1共用令牌并按R4逐批接入V3.2卡片和表单。沿用tokens-v3单一源与现有生成流程，不建立另一套品牌令牌或改写SwiftUI。
- 服务：当前OpenAPI/生成源/已应用迁移才是已实现契约；技术增量是待实施设计，不靠客户端字段映射宣告服务兼容。
- 执行：[总计划1.41](Abasong_V12.1_项目开发与验收总计划.md)→[源码审查及任务](technical/V3.2_App对齐审查与开发任务.md)→差异CSV。R4-3受控实现就绪；B5及发布未就绪。
- 历史：[审查前完整快照](archive/app-alignment-audit-20261105/README.md)。保留原生/云/原型旧证据，不改写过去结果。

机器字段 `development_ready=true` 的**限定范围为当前R4-3可继续受控实现**；另有 `readiness_scope`、`eligible_batches`、`b5_ready=false` 和 `release_ready=false`，不能据此前移发布门槛。各批实际代码/迁移及执行证据见对应报告；R4-11未新增契约、迁移、云变更或真实账号资格，不沿用早期“尚未实现”的审查状态覆盖当前事实。主流程产品认可不是对未执行测试的豁免。

## 3. 组件与状态收敛

| 组件/页面 | 复用与必要状态 | 差异 |
|---|---|---|
| MapCardFrame/Carousel，H01–03 | 单卡/多卡/邻卡、活动/拖拽/键盘/大字号、尺寸变化、列表/详情回程 | D01–04 |
| AddressLine/DistanceBadge，H01/B02 | 数字/街道/完整展开；边界/直线、粗略/过期/无依据；不能挤密码 | D01/02 |
| ApartmentCard/CodeRecord | 读取/有权有值/无码/失败/无资格、完整符号、贡献人/时间、反馈/本人纠正 | D01/09/12 |
| ScreenshotPicker/Review/Result，B04–06 | 单/多图、疑字符、未收录地址核对、共享/私存、取消、部分失败、仅失败重试 | D08 |
| Request/Driver摘要与筛选，H02/03 | 当前结果/加载/空/失败，明天/到期、自报经验、声明多区去重 | D03–07 |
| PickupLocation，P03/D01 | 仓库/途中交接、地址明确/歧义/无点、复制/地图/导航失败及取消返回 | D06 |
| CircleFeed/ReplyComposer，C01–03 | 最新自然高度文字＋0–3图；可选地区/标签、同ID引用、发布/回复失败保留、作者/举报/屏蔽/本人删除、通知回跳 | D15/16/17，原生/媒体待B5 |
| SourceCard/ApplySheet/Composer | 条件变化重核、报名与接单分离、只读、待发送/失败/重试/服务端读水位 | D10 |

不重选品牌、不重做SwiftUI、不新增六边形/评分/结算/独立集合点。任意新状态若不能说明用户下一步，不新建独立页面或额外提示。

## 4. 执行和验收

R4-1首页/卡片/贡献入口/区域→R4-2发布与取件时间数量→R4-3核心保护→B5本人/团队/司机圈/邀请。每批必要契约先行，新增迁移只在明确环境执行，再做相关工程/HTTP/PG检查及iOS/Android功能视觉。没有实际跑的测试明确待验；已过未变的手势不重复请求用户补测。

B6真实账号、云KMS、远程推送、独立包、物理/现场与授权真实图质量集中安排；它们可以暂缓，不阻挡不依赖外部状态的本地任务。真实云变更、短信及账号资格不属于本次审查动作。外部依赖和当前证据见[机器记录](technical/V3.2_App对齐审查证据.json)。

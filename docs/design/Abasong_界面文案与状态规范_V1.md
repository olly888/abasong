# Abasong 界面文案与状态规范 V1

更新2026-11-05。状态：V3.2原型的目标文案表，尚未替换App字符串。依据[产品收敛方案](../product/Abasong_V12.1_产品体验升级与需求收敛方案.md)和[V3.2目标设计](Abasong_设计系统_V3.2_升级方案.md)。同状态只显示必要事实及一个下一步；说明在表内供制作使用，不复制成页面备注。

## 1. 固定术语

| 用语 | 准确含义 |
|---|---|
| 找活/找人 | 既有首页模式，不增加新导航 |
| 配送区域/取件地区 | 需求配送范围/接手地点的大致地区，分别表达 |
| 服务区域 | 司机声明愿意去的区域，不是当前所在地 |
| 接手日期 | 需求starts_at所在地日期，不是发帖日或有效截止日 |
| 可接日期/时段 | 本次意向声明的起止；未来时段明确日期 |
| 当前结果 | 本次筛选下已加载项，不是全市场总量 |
| 已报名/已联系/已找到/已关闭 | 分别保留现有状态；不等于到场、派单、配送完成或付款 |
| 自报经验 | 本人提供、未据此变成承运商核验 |
| 有用/不能用/纠正密码 | 反馈及本人纠正；不新增普通撤回 |

## 6. 不使用的词和替代

“附近司机/在线司机”用于实际位置不明的声明时，替换为“声明可接活的司机”；“预约成功/线路已保留”替换为实际的“已报名/已联系”；“全区N人”在仅加载部分结果时替换为当前结果；“贡献待审核”按真实情况改为共享成功、失败或账号资格说明。

不显示匹配置信度、batch/job ID、查码次数、演示备注、虚构使用人数，不恢复“继续上次添加”“撤回共享密码”或密码放大操作。补充文字用于消除误解，不以长说明代替明确状态。

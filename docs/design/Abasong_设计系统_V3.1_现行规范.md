2026-11-04，America/Los_Angeles。用户批准在继续业务开发前收敛设计系统、组件与逐页双端差异。本版保留已认可的V3品牌和产品方向，整合历次最新决定，替代V1/V2、旧V3正文及分散样式说明中的现行设计规则；历史文档仍是历史证据。未声称外聘真人高级设计师签审。产品与需求优先级仍为最新用户决定→逐页规格/最新补充→本版与当前原型→历史PRD；冲突须同步规范、原型和组件，不能只改一端。

## 1. 目的与边界

首要任务是快速核对公寓门牌地址和完整密码；其次便捷贡献，再其次临时支援和联系。一端、首页/司机圈/我的三导航。中文操作、英文美国地址、USD和公寓/需求所在地时间。不做长期招聘、平台收付结算、自动派单或承运商扫描/POD。沿用RN/Expo/Mapbox；局部系统选择器不改变框架。

品牌基础为白/黑/中性灰，自主皇家蓝仅用于主要动作、有限选中和品牌识别。不是Amazon/Uber官方配色或字体。主色不重选，不增加品牌色候选、开屏或营销元素。

## 2. 唯一变量源与实现位置

可编辑变量源：[tokens-v3.json](tokens-v3.json)（文件名保留兼容，description标记V3.1）。`./scripts/dev tokens:generate`同时生成packages/ui/src/index.ts、docs/design/tokens-v3.css及v12.1、v12.1-import的tokens.css。生成文件禁止手改。旧Python命令仅代理当前生成器，不再从V2重新构造令牌。CI检查这些输出漂移。

| 层 | 当前维护点 | 职责 |
|---|---|---|
| 基础变量 | tokens-v3.json / @abasong/ui | 色彩、语义色、尺寸、字级、间距、动效 |
| 原生共同UI | apps/mobile/src/ui/ | foundation、Controls、PageFrame/PageHeader、BottomSheet、Feedback、Primitives及系统选择器 |
| 业务组件 | apartments/、requests/、messages/、imports/ | 公寓卡、任务/报名、消息、截图；保留各自业务对象和权限 |
| 兼容入口 | auth/AuthControls.tsx、RequestUi.tsx | re-export共用组件，不再各存一套样式 |
| 组件验证 | DEV-only /design-system、design-lab/ui-review/messages-lab/notifications-lab | 复用真实组件，合成内存动作，不是生产菜单或真实服务验收 |

品牌`#1467D8`、按下`#1054B3`、浅选中`#EDF4FF`、白字；主文字`#101114`、次文字`#53565B`、元信息`#686C73`；白卡、画布`#F6F6F6`、次表面`#F0F0F0`；控件边界`#82858A`、分隔线`#E3E4E6`；成功`#236346`、提醒`#855307`、错误`#AE3734`、危险按下`#8F2C2A`。禁用使用中性底和可读灰字，不整体opacity减半。遮罩使用统一rgba(16,17,20,.32)。

既有白字/主色对比5.30:1、主字/白18.88:1是指定色对计算，不是整套无障碍认证。焦点、透明叠层、地图、不同系统及放大字号必须单独验证。

## 3. 排版、尺寸与层级

系统字体，不下载专有字体。point/dp为原生逻辑尺寸，CSS px为原型单位。4为基础间距，常用8/12/16/20/24/32。正文和固定提交区左右均20；窄卡内部可16，不能产生20+16的双重嵌套页边距。

| 角色 | 字号/行高 | 规则 |
|---|---|---|
| 认证引导大标题 | 32/40 | 仅认证/引导，不能套给每个二级页 |
| 内容大标题 | 28/36 | 信息段标题 |
| 二级页栏标题 | 19/26，600字重 | 栏最小64高，长标题最多两行，放大后允许增高 |
| 卡/段标题 | 20/28，600字重 | 任务摘要等可17/24紧凑呈现 |
| 正文 | 16/24 | 操作、输入和核心事实 |
| 辅助/字段标签 | 14/22 | 不能靠placeholder代替必需标签 |
| 元信息 | 12/18 | 时间/版本等；不用于密码、地址和报酬 |
| 公寓门牌/街道 | 首页28/20，同一行 | 长街道尾省略；展开完整，不缩关键数字 |
| 密码 | 常规40，紧凑/长值29 | 完整保留#、*和前导零，必要时换行，不能裁掉符号 |

按钮最小52高、控件圆角10、图标24、交互热区最小48×48。一般卡圆角16，底部面板顶角24；首页独立公寓卡圆角24是业务例外。按钮文字放大或变长允许增高换行，不能固定高度截字。价格/门牌使用清楚的数字，不显示伪收入推算。

## 4. 基础组件与状态

| 组件 | 必备状态 | 交互规则 |
|---|---|---|
| ActionButton | primary/secondary/text/danger、pressed、busy、disabled、长文案 | 一层一个主要提交；busy保留原文字+指示并防重复；disabled可读且不可触发；danger不复用主蓝 |
| Field | empty/filled/focus/error/disabled/multiline | 可见标签；焦点品牌边界；错误文字+红边；禁用中性底；保留onFocus/onBlur外部事件；错误不清输入 |
| SearchBox | empty/typing/focus/clear/busy/unavailable | 已有搜索/相机语义；查找不足条件不可触发；系统返回不丢核对输入 |
| SelectionField/日期 | empty/selected/disabled/open/cancel | iOS系统菜单/滚轮，Android系统日期或品牌选项面板；取消不修改；LA日期转换继续原逻辑 |
| IconButton/ListRow | default/pressed/selected/disabled | 必需读屏名称；禁用不可触发且图标/文字降为可读中性；选中不只依赖颜色 |
| PageHeader/PageFrame | root/secondary/hero、滚动、固定footer、键盘 | 标题/返回同一套尺寸；返回真实来源；正文和footer同边距；iOS padding、Android height避让 |
| BottomSheet | open/scroll/keyboard/cancel/system back | 内容可滚，表单最大95%可用空间；保留取消动作，不靠点遮罩强制丢数据；业务退出确认由调用者决定 |
| StatusPanel/FormError | loading/empty/error/unavailable、retry | 失败不能呈现为暂无；加载不能当成空；服务未开放不冒充零条数据；重试只处理当前对象 |

组件状态目录仅在DEV使用，真实页面不能出现工程测试按钮、查码计数、假资料或状态说明。业务权限继续由真实API决定，组件状态不得代替权限实现。

## 5. 首页地图与独立公寓卡

顶部搜索+消息；下方公寓/找活/找人；地图为主交互；右下可见区域保留定位，发需求独立在其上方；设置只在我的底部。消息为二级入口，不加第四导航。

默认200米附近候选，不要求进入建筑/G1G2/停稳8秒；按边界距离或可靠地址点距离，不因密码有无调序。分类和已收录资料共同发现；house默认不出公寓卡，社区按明确地址和密码范围组织，不按每栋屋顶重复出卡，不猜绑附近密码。初始最近；主动滑卡/点楼/展开后锁定阅读，定位按钮恢复附近推荐。蓝点始终代表真实用户位置，切卡不移动蓝点。

独立白卡，透明轨道，卡间透地图；多卡宽W−64、间距12、两端32，侧露约20；单卡W−32两侧16，不复制假邻卡。收起统一192逻辑高度，字放大同步适配；卡底距导航12。只保留手柄、单行门牌街道、原样密码或必要状态、贡献时间+用户名及必要操作。不得恢复附近公寓、页码、门禁密码标签、公寓名为主标题、卡外有用/没用按钮条。

展开仅当前卡；完整地址/公寓名称/收藏图标/有用及没用反馈进入内部。暂无共享密码保留地址和前置添加入口；读取失败保留地址并重试，不能冒充暂无。密码不能点击进入放大页。反馈有用优先，同组贡献时间倒序；保留正在操作记录的阅读锚点，切卡立即撤掉前卡密码并防迟到响应串码。比例尺/Mapbox归属可见，不遮卡/工具。地图缩放/指南针等不新增常驻工具堆叠。

## 6. 贡献、截图与我的公寓

首页和我的“贡献公寓密码”共用一个入口：截图主要、快速填写次要。明确公寓的添加直接带入地址；无明确地址先核对，不能让司机逐个重输所有地址。普通来源确认后直接共享，不逐条人工审核；资格未开通与密码审核是不同概念，不能写成贡献待审核。

截图为选择单/多图→检查地址/密码→确认共享；原图只供本人核对。地址和符号不确定时必须让本人确认，不自动发布。没有跨次“继续上次添加”，退出后的新添加从头开始；内部网络重试和服务防重保留，已共享成功项不丢也不重复。文本/表格P1，不新增本轮菜单。失败保留当前填写；快捷控件、入口和私存/共享意图可见，不展示OCR置信度、批次ID或工程状态。

我的突出贡献；我保存的卡直接显示本人私存或有权共享密码；我共享的显示贡献/反馈与本人纠正，不显示普通撤回入口。纠正保留其他来源与反馈历史；误共享由受控管理员处理。收藏是保存关联，不复制他人密码为自己贡献，不展示虚构使用次数。

## 7. 临时需求、报名与消息

发布入口为首页底部类型面板。发布表单分基本区域、时间数量、可选接手条件；报价和单位分开，不知价格联系议价，不写$0；任务当地日期/AM/PM，跨日明确。任务/来源卡优先区域、类型、报价/数量、时间和版本。本人管理，他人报名；已报名继续联系，终态不能仍报名。发布/报名/已联系/已找到不代表派单、到场、配送完成或结清。

M01对话/通知列表：用户名、时间、来源标题、未读；不预取正文，进入不清空全部未读。M02品牌蓝本人气泡、白色对方气泡、文字时间和发送状态；来源历史卡点击当前详情，不能改写历史。发送中、已发送、失败·重新发送、对方已读四态分开；重试相同消息编号；只能凭对方水位显示已读；只读时保留历史并移除输入。加载最新、向上更早；阅读不被刷新夺走。2026-11-04用户收敛：首版不建设独立集合点分享。双方在已有文字会话中约定碰面地址；不新增集合点卡、专用分享/查看/撤销面板，也不自动读取或附带GPS。普通公寓密码仍不提供撤回。通知设置位于我的→设置，使用系统Switch和现行PageFrame；系统权限、业务启用、站内记录和供应商受理分开。远程送达仍待APNs/FCM与B6，不以本机通知或合成票据冒充。

## 8. 平台、返回与访问性

iOS/Android同品牌、信息优先级和业务状态；系统键盘、日期、权限、返回手势允许平台差异，不强求系统控件逐像素一致。二级返回来源并保留已选公寓/筛选；表单退出由业务边界确认，不因统一UI破坏截图退出拦截。视图按可用高度而非固定设备截图定位。

字体缩放保持开启；主要信息不缩小到不可读，长地址可展开完整，长密码可换行。状态同时用文字/边界/图标，操作有读屏名称。弹层内焦点和取消后恢复、200%字号、小屏/大屏、VoiceOver/TalkBack及真实软键盘须记录实际结果。默认字号截图、逻辑测试和JS导出均不代表访问性认证。未测项保留明确，不补虚构通过。

## 9. 文案与未开放状态

少量事实+明确下一步，不加设计备注/工程提示。资格未开通写“暂未开通资料查看资格”，没有真实申请时不写“待审核”。司机圈业务未实现写“司机圈尚未开放”，不能“暂无动态”伪装已经有业务；不是新增审核/报名入口。生产试点是否隐藏整个未开放模块仍按发布范围决定，不在此改变三导航。

## 10. 制作与验收顺序

1. 维护现行规范、变量和真实共用组件；原型引用同一生成CSS，页面规则变化同批同步。
2. 每个已实现页面按同一数据/权限/状态对比原型、iOS、Android；未实现页面只登记规划，不建假可用页面来通过验收。
3. 差异列为规范冲突、实现问题、平台允许差异、业务未实现、待实测。记录根因、修正、截图/动作和余项。
4. 严重错误（串地址/符号丢失/按钮不可达/假成功/数据丢失）优先于圆角/像素微调；共用问题改共同组件，不能复制三套补丁。
5. 本轮不发真人短信、改云服务或授予资格；合成UI、真实HTTP及真机证据分别记录。集中B6业务门槛不提前关闭。

逐页清单及实际差异见[收敛与双端逐页核对](D2_设计系统收敛与逐页核对.md)。本版为已批准方向下的现行开发规范，完整验收状态以记录为准，不称永不修改的最终成品。

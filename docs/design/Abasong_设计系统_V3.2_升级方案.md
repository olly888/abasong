# Abasong 设计系统 V3.2 升级方案

2026-11-04。**V3.2为待原型验证的目标版；V3.1仍为当前App与组件执行规范。** R2a已在独立HTML/CSS原型实现核心页面；未修改tokens源、原生组件或品牌资产。原型验证后再根据差异实施，不能将文档版本号当作全产品视觉验收结果。

依据：[产品收敛方案](../product/Abasong_V12.1_产品体验升级与需求收敛方案.md)、[V3.1现行规范](Abasong_设计系统_V3.1_现行规范.md)、[研究](../research/DoorDash_司机端深度研究与Abasong借鉴方案_2026-11-04.md)。

## 1. 设计师结论

升级地图层级、选择关系和状态表达，沿用已认可的视觉基础。司机短暂打开查码时，地址和密码优先；司机/DSP寻找支援时，区域、时间、数量和下一步优先。

保留白/黑/中性灰＋皇家蓝、系统字体、RN/Expo/Mapbox、一端三导航。没有新增主题色、外来专有字体、抽屉、第四导航、收入或评分入口；不以DoorDash深色截图作为强制改深色的依据。

## 2. 保留的基础与唯一来源

| 项目 | V3.2目标沿用 |
|---|---|
| 变量源 | tokens-v3.json及现有生成流程；不手改生成CSS或原生令牌 |
| 色彩 | 品牌#1467D8、按下#1054B3、浅选中#EDF4FF；现有文字、错误和成功语义保持 |
| 排版 | 系统字体；正文16/24、标签14/22、元信息12/18，卡标题20/28；不缩小密码/门牌迁就布局 |
| 操作尺寸 | 按钮最小52、热区48×48、图标24；长文案/放大字号允许增高 |
| 形状与边距 | 通用卡圆角16、弹层顶角24；页内容/固定操作区20，紧凑卡内16 |
| 公寓业务例外 | 独立卡圆角24、标准字号收起192逻辑高度；放大字号统一适配 |

新增图层颜色使用既有中性与蓝色变量，不把红色Busy变成一种新常驻业务颜色。状态同时有文字/数字/边界，不能只靠颜色。

## 3. 三模式地图规则

| 项目 | H01公寓 | H02找活 | H03找人 |
|---|---|---|---|
| 主对象 | 已核对建筑、门牌和当前公寓 | 公开配送服务区域和需求 | 司机声明愿去的区域 |
| 默认范围 | 真实位置附近200米候选 | 全部区域；允许主动筛选 | 全部区域；不显示司机精确点 |
| 首轮绘制 | 建筑/门牌与既有独立卡 | 区域点＋当前结果 | 区域点＋当前声明结果 |
| 有来源对照 | 不影响查码范围 | 一处区域面与点方案同数据比较 | 同上，区域面不代表司机轨迹 |
| 近景 | 选中建筑/门牌清楚，其余弱化 | 保持区域含义，不编造任务精确位置 | 不生成车点/头像点或精细密度 |
| 底部 | 横向独立卡，仅当前卡展开 | 一条活动需求摘要，可看列表 | 一条活动司机摘要，进入档案联系 |

相机以公寓约17级、支援约14级为当前测试起点；选区按有效几何和实际剩余可视高度适配。手动拖缩不被连续GPS打断。缩放不改变200米业务半径，不改变对象空间依据。

图层顺序：底图 → 有来源服务区填充/线 → 建筑/相关对象 → 标签和选中对象 → 本人蓝点 → 产品工具/卡片。公寓模式关闭支援区域统计层。列表隐藏地图后不留下浮动地图工具或底图归属悬空；地图显示时归属和比例尺须可见。

## 4. 区域与对象选择

点区更新浏览区域及结果；原对象属于该区则保留，否则在加载新结果时清除旧对象，避免旧卡配新计数。对象选择、区域筛选和本人蓝点是不同状态。

- 点区域：选区→读取→列表/卡更新；没有边界使用区域点，不随意补圆或描摹竞品区域。
- 点卡/列表项：H01仍在同一卡片展开/收起，不跳页；H02/H03选同一对象并进入D01/D02。二级页返回保留筛选、选中、列表滚动和相机上下文。
- 模式切换：三模式状态隔离，清除前模式可见卡/错误/数字，不能借迟到响应回填。
- 定位：公寓解除阅读锁并恢复推荐；支援仅回本人蓝点，不静默清除区域筛选。
- 刷新：同对象仍有效时保持阅读；对象确认终止才展示终止状态，不因暂不在某页就捏造已结束。

首轮标签只表达当前已加载结果；数字紧邻“当前结果”口径。有全量聚合后才能使用“区域共N条”等目标文案。跨区总人数去重。失败、未加载与0分别处理。

长区域名：所选区最高优先级，未选区减少标签，支持列表读完整名称；标记需碰撞避让。区域名不与街道名/比例尺/蓝点争夺层级，不以全图铺标签证明信息丰富。

## 5. 公寓卡与贡献入口的保护规则

独立白卡、透明轨道、卡间透地图；多卡宽W−64、间距12、两端32，侧露约20；单卡W−32，不复制假邻卡。底距导航12。保持完整门牌＋同行街道、原样密码、贡献时间＋用户名。

不恢复“附近公寓”、页码、“门禁密码”标签、名称主标题、卡外反馈条、密码放大页；长街道尾省略，展开读完整地址，长密码保留符号/前导零并可换行。收藏图标和详情在展开层，不抢主要贡献入口。

无码时在收起卡给添加入口，展开后添加仍在前部；读取失败保留地址并提供一次重试，不显示暂无密码。首页/我的贡献为同一菜单，截图优先、快速填写次要；不增加人工审核、普通撤回、跨次续填或工程术语。

### 5.1 取件位置：复用详情和地图面板

[仓库取件补充](../product/Abasong_V12.1_仓库取件地址与导航补充.md)纳入目标版。P03区分配送区与取件仓库，完整地址必填（途中交接例外）、名称选填。D01以取件时间/名称/完整地址组成短区块，地址可点、复制/导航为次级动作；详情原主动作仍报名。完整仓库地址可换行，不套公寓收起卡单行省略。

点地址进入D01内地图覆盖层：仓库标记、完整地址、主按钮导航，复制为次操作；既有比例尺、归属保留。默认约16级核对仓库，不改变首页近景/区域规则。关闭及外部导航返回保留原需求上下文；不自动报名或到场。H02不为每张需求加载小地图；仓库点不替代配送区域层或司机所在地。

无码地址/无坐标/底图失败分开；可读地址、复制和外部地图不因定位拒绝而禁用。距离若仅直线须标直线，不伪装车程。沿用现有颜色、图标/48热区、Sheet和状态组件；不引入深色主题、仓库工作台或新的集合点卡。

## 6. 组件增量与状态

| 复用 | 补充目标状态 |
|---|---|
| HomeChrome/SearchBox | 模式相关搜索/筛选名称、筛选摘要、清除筛选及选中语义 |
| 区域点/既有Mapbox图层 | 有边界/仅点、选中/未选中、长名碰撞、当前结果/未加载/上限 |
| RequestCard/DriverSummary | 明确日期、未来声明、刚到期、对象终止、件数与报价单位 |
| BottomSheet/StatusPanel | 切模式加载、区域空结果、业务失败、底图失败、定位失败分别表达 |
| PageFrame/NativeDateField/Switch | 今天/明天快捷、跨日说明、关闭保存、版本冲突及失败保留 |
| B02/B04–B06/U06 | 确认范围、部分成功/重试、本人纠正、私存/共享边界保持 |

一层一个主动作。相同故障只显示一处，不将多条错误/备注堆成首页说明书；需展开的规则放详情或设置，产品界面不出现批次ID、置信度、查询计数或开发备注。

## 7. 日期、声明和通知

U03仅一个起止时段、1–5区域及可选件数；今天/明天快捷和系统选择器协同，取消不改值。跨午夜有明确次日日期。未来声明表达何时可接；关闭App不自动关闭，结束后停止推荐，关闭动作不受旧日期错误阻碍。

常跑区是未来私人的填写默认值，不等于开启声明；浏览筛选不修改两者。机会提醒本轮只作外壳中的未来说明，不放入产品页的可用开关，不宣称已真实送达。通知仍使用已有M01及U11结构。

## 8. 文案、平台与无障碍

目标文案统一见[文案与状态规范](Abasong_界面文案与状态规范_V1.md)，同一状态只引用一份。V3.1保留原有来源和范围，V3.2不得通过换词扩大业务承诺。

两平台同信息优先级和状态，系统日期、键盘、权限和返回手势允许平台差异。目标热区48×48；普通文字4.5:1、大字/关键图形3:1，在真实地图背景验证；200%字号、长地址/密码、固定操作区均可达。VoiceOver/TalkBack能读模式、区域、数量口径和上一/下一公寓；列表提供地图的等效操作。焦点进入/返回、取消保留、系统返回和减少动态效果要分别记录，不能凭截图宣称无障碍通过。

## 9. 交付与版本启用

R2a已制作[独立原型](../../design/abasong-independent-v1/v12.1-experience/index.html)，[浏览器验收记录](../../design/abasong-independent-v1/v12.1-experience/验收记录.md)覆盖核心流程；待用户体验确认，App仍V3.1。按[原型升级计划](../product/Abasong_V12.1_原型升级制作与验收方案.md)先制作核心页面和状态，再做任务观察。区域点/面对照、标签密度、日期快捷及当前结果语义均待验证。原型通过后逐项修改共用组件与tokens必要增量；设计版本进入执行状态的日期、提交和证据要登记，V3.1历史保留，不能产生两份都自称唯一现行的规范。

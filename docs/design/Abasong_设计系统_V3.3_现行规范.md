## 品牌与颜色

正式来源为[品牌资产原件](brand/README.md)。浅底使用官方小写字标。首个 a 固定为 `#1769FF`，basong 固定为 `#000000`。核心品牌白为 `#FFFFFF`。字标等比使用，至少 120 px/逻辑单位宽，四周留出约半个小写字母高度，常用组件宽 144、留白 14。缩小尺寸或制作深底、新启动图和商店图标时，先取得对应正式资产及批准。

| 界面用途 | 令牌 | 颜色 |
| --- | --- | --- |
| 主操作、已选地图标记和定位蓝点 | `color.brandPrimary` | 蓝 600 `#1769FF` |
| 主操作按下 | `color.brandPressed` | 蓝 800 `#0B3D91` |
| 浅蓝选中底 | `color.brandSurface` | 蓝 50 `#EEF4FF` |
| 选中文字、文字链接和焦点 | `color.brandText`、`color.focus` | 蓝 700 `#0E4EBA` |
| 主要正文、浅色卡片 | `color.ink`、`color.surface` | `#101114`、`#FFFFFF` |

按 WCAG 相对亮度计算，主按钮白字约 4.67:1，浅蓝底搭配深蓝选中文字约 6.75:1。色板十级蓝阶与五种状态样本完整保存在 `palette`。成功与警告的浅底提示使用现行较深的前景色。危险操作使用色板的 `#C2261B`。状态用文字或明确图标辅助表达。Help 和 Rescue 暂作参考色。

## 图标与组件

- 操作图标采用 Lucide 1.70.0。语义名称与官方路径集中在 [icons-lucide.json](icons-lucide.json)，[上游许可](lucide-LICENSE.txt)随仓库保留。App 通过 `Icon` 和 SVG 渲染器使用，当前原型由同一份源生成。系统位置服务、Mapbox 归属和操作系统图标按原生规则保留。
- 常用图标 24、紧凑操作图标 20，24×24 坐标系线宽 2，圆角线端与连接。同行补充信息的既有 17/18 等小尺寸随页面迁移。交互热区至少 48×48。按钮提供可读名称，装饰图标不重复朗读。模式切换提供可读选中态。
- 首页白色地图控件圆角 16，内部分段圆角 10。搜索、消息及单图标地图按钮以 52 为基准，列表/地图及发布按钮最小高度 48，随字号与文案增高。搜索按当前模式显示，发布继续用主色，模式选中用浅底深蓝，位置繁忙时明确保持可用回位或显示加载。
- 正文 16/24，标签 14/22，辅助信息 12/18。主操作最小高度 52，常规操作圆角 10，通用卡圆角 16，底部面板及地图独立卡圆角 24。首页现行目标采用 V3.5 的纵向 `HomeResultCard` / 列表结构，旧 `MapCardCarousel` 为历史组件。V3.5.1 DTL-01 补充规定三模式共用槽位与普通内容180高；正式原型与DTL-02原生均已实现；大字分区标题与操作分行、顶部采用紧凑搜索组合。
- 所有加载、空结果、失败、权限不足和可重试场景使用各自状态。首页地图的选区、真实位置和选中对象分别表达。地图状态统一使用以下规则。
- 门别使用一组常驻单选按钮「行人门」「车库门」「大堂门」，最小热区 48×48，选中采用浅蓝底、深蓝文字及描边，窄屏或大字号允许换行。选填时可再次点击取消选择，历史门别在编辑时作为辅助文字保留。

## 首页空态、加载与失败

| 场景 | 文案与操作 |
| --- | --- |
| 附近查询成功且无公寓候选 | 「附近未匹配到公寓」与次级「共享门禁码」。状态条无拖拽手柄。普通住宅不会因此成为公寓卡，顶部地址搜索仍可用。 |
| 已选公寓，查询成功且无共享资料 | 保留门牌、地址和地图选中建筑，显示「暂无共享门禁码」及「添加门禁码」。 |
| 已选公寓，暂停共享 | 保留地址和地图选中建筑，显示「该公寓暂不共享门禁码」，收起添加入口。 |
| 附近查询失败或缺少有效地图查询结果 | 「公寓资料暂时无法加载」与「重新加载」。仍有可信候选时，继续提供对应公寓卡。 |
| 已选公寓，门禁码读取失败 | 保留地址，显示「门禁码暂时无法加载」与「重新读取」。 |
| 定位等待、定位异常、权限不足 | 分别呈现进度、定位操作或查看资格状态。 |
| 找活／找人，默认范围内无结果 | 「暂无开放配送需求」或「暂无可接活司机」。 |
| 找活／找人，筛选后无结果 | 说明没有符合筛选的结果，提供单个「清除筛选」。清除当前模式筛选并重新查询。 |
| 找活／找人，读取失败 | 说明对应资料暂时无法加载，提供「重新加载」，保留查询条件。 |

地图与列表共用同一查询结果和状态文案。结果数量只在已加载且有结果时显示。地图浮层使用紧凑白底状态条，操作文字采用深蓝，失败文案用危险色并提供可读提示。触区至少 48，文字放大时可纵向排列。已选公寓状态使用相同组件，保留卡片信息和尺寸规则。

## 工程入口与本轮范围

[令牌源](tokens-v3.json)及[图标映射](icons-lucide.json)由 `./scripts/dev tokens:generate` 生成共用包、CSS 和原型资产。品牌原件固定，生成副本可重建。日常新增控件优先使用 App 的 `src/ui`，地图控件使用 `MapControls`，原生实验室 `/design-system` 提供品牌、地图控件和原有组件样板。组件规范同时约束原型及 App 的选中、按下、禁用、等待与无障碍状态。

原生全屏弹窗在自己的呈现层测量安全区。顶部关闭按钮完整置于状态栏下方，触控区至少 48，关闭后返回打开弹窗的页面。底部弹窗、选项面板和日期面板也按各自的呈现层计算底部安全区。[Expo 安全区文档](https://docs.expo.dev/versions/v58.0.0/sdk/safe-area-context/)

本轮范围为共用颜色与图标、地图首页工具、底部导航视觉、登录和邀请字标。本地首页三种模式的空态、加载、失败和操作样式已接入。全站逐页组件收敛、放大文字及读屏完整回归分批验收。历史依据保留在 [V3.1 归档规范](Abasong_设计系统_V3.1_现行规范.md)及 [V3.2 地图体验方案](Abasong_设计系统_V3.2_升级方案.md)。

依据 [Lucide React Native](https://lucide.dev/guide/react-native)、[Expo SDK 58 SVG](https://docs.expo.dev/versions/v58.0.0/sdk/svg/)及 [WCAG 2.2 最低对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

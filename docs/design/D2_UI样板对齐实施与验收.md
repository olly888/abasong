## 本批结果与边界

保留React Native/Expo、Mapbox原生SDK、现有三导航与V3黑白/蓝色品牌。没有全面改写SwiftUI，没有安装`@expo/ui`。采用Expo58推荐的系统日期/时间组件，iOS底层为系统日期选择器，Android为系统对话框；这不是SwiftUI迁移。API、数据库、云部署、业务资格和公开需求不变。

选择器取消不提交新值；iOS滚轮临时值仅“完成”时确认。业务时间始终使用America/Los_Angeles，保留既有DST歧义/版本/幂等约束。日期随动只移动原本同日的截止日期，不覆盖明确跨日设置。编辑和发布仍走原有真实API，不以新UI绕过校验。

DEV专用`/ui-review`复用真实发布/报名字段组件，数据和动作只在内存，不发业务请求、不授予资格；非DEV重定向首页。它用于同状态视觉/控件核对，不能代替真实报名、权限或云验收。首页复用既有design-lab/arrival-lab合成场景。

## 原生构建中修正的本机问题

本次正常prebuild复用了先前现场/内测构建生成目录，遇到RNCore/Hermes及四个Expo预编译模块的Debug标记与实际二进制不一致。初次链接失败、随后启动异常均没有当作通过；只在生成产物中让供应商官方配置替换脚本重新取相同版本Debug工件，最终签名构建及启动通过，没有编辑node_modules源码或关闭新架构。

同时发现独立版严格ATS设置会在非clean prebuild后残留到普通开发版：普通开发配置现在明确只允许本地网络、仍不允许任意HTTP；pilot-dev和field-review继续明确HTTPS-only/禁止本地网络，并扩充既有profile回归。普通开发版标识不变。没有放宽独立内测环境、云加密或API权限。

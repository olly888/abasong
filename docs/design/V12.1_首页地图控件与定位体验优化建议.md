# V12.1 首页地图控件与定位体验优化建议

日期：2026-10-30。状态：用户已批准，扩展原型与原生页面已实施。双端核心补验及后续场景见[验收记录](../technical/D1_首页地图与定位体验修正验收.md)。下文保留评审时事实，不代表外部顾问访谈。

## 当前事实

- `8765/v12.1-import/` 是合成原型，地图为 SVG，定位按钮切换预设状态，不获取真实 GPS。
- 原型首页右上是消息；“我的”顶部及底部均有设置，重复。原生当前“我的”没有顶部设置；若原生界面看到开发齿轮，需与产品按钮区分。
- 原型找活/找人用列表按钮替换定位按钮，确实导致返回位置入口丢失。
- 原生 `HomeChrome` 的消息和发需求明确 disabled，业务属于 D2，未完成；找活/找人仅展示暂未开放，MapTools 没有 onLocate，因此定位也不能使用。
- 原生公寓页已接前台单次定位和候选 API；首次访问不自动请求未授予的权限，点击后才请求；20秒超时。定位与候选查询共用 catch，会把部分查库错误显示成无法获取位置，需要拆分。不能从当前截图或代码断言用户本次失败原因。
- 原生 Web 地图目前忽略位置/候选 props，不能用作原生定位联动验收。

## 建议布局

| 元素 | 位置 | 规则 |
| --- | --- | --- |
| 搜索 | 顶部左侧，占主要宽度 | 随公寓/找活/找人改变查询对象 |
| 消息 | 搜索栏右侧 | 首页主入口，进入独立二级消息中心；私信和系统通知在中心内分类 |
| 公寓/找活/找人 | 搜索栏下方左侧 | 不增加第四个底部导航 |
| 列表/地图 | 模式栏右侧 | 仅找活/找人显示图标+文字；同一位置双向切换，保留条件和选择 |
| 回到我的位置 | 可见地图右下角 | 三种模式一致；距右边16，距底部卡片顶部12–16；独立48×48点击区 |
| +发需求 | 定位按钮上方 | 短胶囊，与定位垂直间隔8–12；仅一个入口，不放公寓密码卡内 |
| 设置 | 我的页面底部菜单 | 移除原型我的顶部重复入口；首页不放产品设置 |
| Mapbox标识/归属 | 可见地图左下区域 | 跟随卡片避让，持续可见可操作，不被发布按钮或卡片遮住 |

以上尺寸为 Abasong 建议值，不是 Mapbox 强制规范。视设备安全区、字号和卡片高度自适应；卡片全屏展开时收起地图操作，收起后恢复。空间不足优先保留定位和卡片内容。

贡献共享仍是第一优先级：无密码卡直接添加，展开后添加置顶，“我的”突出截图贡献；发布按钮不扩大为首页最抢眼元素。

列表采用同一首页下的全高列表呈现。列表工具栏保留“地图”切换及筛选；返回地图保留原视野、选中项及列表滚动位置。列表无需悬浮定位按钮，可用区域筛选中的当前位置。地图视图不得用列表入口替换定位。

## 定位行为

1. 首次尚未授权时，卡片提供使用当前位置与搜索；明确拒绝且不能再请求时，提供打开系统设置与搜索，不能死循环请求。
2. 系统定位失败与附近查询失败分开。已取得位置但查库失败时保留位置点，显示附近资料暂不可用；附近无数据不等于 GPS 失败。
3. 定位按钮获取/确认新鲜位置后让相机回到可见地图区域中心；不能只依赖坐标值变化，因为同坐标也需要重新居中。
4. 手动拖动后不强制持续回中；再次点击才回到本人位置。当前查码场景不需要导航式持续追踪或后台定位。
5. 切换三个模式保留会话内当前位置和地图视野。本人位置不等于公开司机位置；找人仅显示自愿开放的可用司机大致区域，不展示所有司机实时坐标。
6. 点击回位不应先清空正在阅读的密码再等待 GPS；保留原卡，明确选择或新候选确认后更新。相邻公寓和精度不足时不自动绑定错误公寓。
7. 模拟器合成位置、真机GPS、服务器公寓覆盖分别验收，不互相替代。

## 消息决策

推荐首页搜索右侧作为主入口，点击进入二级消息中心。司机/DSP身份不拆成不同聊天入口。同一消息中心可由需求详情中的联系操作进入；返回时保留原上下文。我的顶部无需再放设置或消息；若需要全局发现，可在我的列表增加同源消息行，但首版不必重复。

消息服务未开发期间，内部验收版允许明确禁用；试点版应隐藏未开放入口或按可用范围发布，不能让不可点击的蓝色按钮暗示完整可用服务。不得用虚构对话替代真实业务验收。

## 开发顺序与验收

建议在下一批导入后端前，插入首页基础交互修正批次；D2发布/报名/消息业务仍按总计划，不因控件调整提前承诺完成。

1. 原型：去重设置；三模式统一定位；列表切换移到模式栏右侧；明确卡片/全屏/列表布局。
2. 原生：统一会话内定位/相机控制；拆分GPS与候选查询错误；补拒绝后设置恢复和同坐标回位；动态计算相机padding/卡片避让。
3. 双端：首次权限、拒绝恢复、超时、精度不足、有位置无数据、查库失败、手动拖图回位、同坐标回位、模式切换、卡片展开收起、大字号/安全区，以及Mapbox标识可见性。
4. D2实现后：列表/地图同步筛选与选择、发布保存/取消、真实消息收发与未读状态，另行功能验收。

## 官方依据与适用边界

- [Mapbox iOS User Location](https://docs.mapbox.com/ios/maps/guides/user-location/)：权限、降低精度、位置点及相机跟随是不同能力；有底图不等于已获得设备位置。
- [Mapbox Android Camera](https://docs.mapbox.com/android/maps/guides/camera-and-animation/camera/)：camera padding 调整中心在屏幕中的渲染位置，可避开顶部工具栏和下方卡片。
- [Mapbox Attribution](https://docs.mapbox.com/help/dive-deeper/attribution/)：品牌标识及地图归属应按对应SDK要求保留、可见。

Mapbox没有把本项目定位/发布/列表按钮的位置规定为上述布局；布局是基于司机查码和支援场景的产品判断。项目通过 React Native 包装集成，具体可用属性还需对照已锁定包装库版本；不直接照抄 SwiftUI 或 Kotlin 示例。

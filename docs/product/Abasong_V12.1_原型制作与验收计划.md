## 3. 核心演示数据

所有姓名、地址、密码、报价与对话均为合成数据；数据来源说明放原型外，不在实际首页叠备注。不复用用户截图里的个人联系方式、二维码或任何真实住户/面单。

| 场景 | 数据约束 |
|---|---|
| 密码排序 | 至少4条：较新无票、较旧有效有用、同组更旧、确认失效；验证分组后各按贡献时间排序 |
| 密码撤回 | 撤销最后有效有用后回普通组；撤销来源后不再显示正文 |
| 部分支援 | 300件，剩余150件，每人最低50件；司机可接50件，低于50阻止数量报名并可联系 |
| 整线支援 | 120件不可拆分；司机确认整线，不能用仅接30件偷偷提交 |
| 增加司机 | 明确某日某区域200件需2人，剩余人数由发布者确认，不是长期招募 |
| 双区域 | 取件在City of Industry，配送为另一选定区域；卡片和地图清楚区分 |
| 公开链接 | 只展示合成公开摘要；结束后不再展示详细条件；登录后条件已改变需重新确认 |
| 可用司机 | 有声明但当前App不在线、时段刚过期、未声明的历史联系人三种状态 |

## 4. 必须可操作的返回/失败

1. 手机系统返回、顶部返回、关闭面板都回正确来源；不是全部回首页。
2. 登录/补资料后回原公寓或原需求，重新取权限与当前版本；不自动报名。
3. 普通表单错误保留草稿；密码明文不持久化；退出/切账号清敏感内存。
4. 地图和列表选中同步；手动选择后GPS变化不换栋。
5. 反馈失败回滚；报名成功但发消息失败分别表达，不重新报名。
6. 到期/关闭/屏蔽立刻改变操作能力；引用卡和外部分享跟同一事实源。
7. 草稿删除、来源撤回、需求关闭、账号删除有具体动作名和适当确认，不统一写“确定”。
8. 没有长期招募入口、带教/试线表单、入职状态、钱包/支付、自动派单或POD。

## 5. 视觉与设备验收

按同一布局/组件在375、390、430宽度检查；系统字体200%时主要任务仍可达。密码/金额/单位/英文长地址不能关键截断。检查单手触控、键盘遮挡、面板与列表手势、地图候选替代操作、焦点返回、读屏命名和减少动效。

主动作#1467D8，密码深字，中性地图，反馈留卡内；地图归属可见。原型中的品牌与样式一致不等于实际设备户外验证已通过，真机仍有独立检查。

## 6. 冻结与进入开发

按真实任务一次评审一个闭环，而不是每页重复问同样控件。记录问题、修改结果、截图/交互证据、对应节点/接口和版本。核心流程与关键异常通过后冻结该批原型，更新工程任务；业务编码以通过的原型和契约为基础。

Mapbox原生兼容、数据库迁移/权限测试等纯技术验证可与原型并行。完整业务实现不在本轮页面文档阶段悄悄启动；生产上线仍需真实后端、真机、授权与现场验收。后续新需求进入变更记录，不以“最终版”承诺永不修改。

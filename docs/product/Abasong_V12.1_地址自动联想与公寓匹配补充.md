# ADD-14 地址自动联想与公寓匹配

日期：2026-10-31。依据：用户同意接入完整 Mapbox 联想、候选去重、点选定位与公寓资料匹配。影响 S01、L01、H01；[本批实施与验收](../technical/D1_Mapbox地址联想接入验收.md)。

搜索作为首页自动识别的补充。首页仍以持续蓝点和到达公寓后的资料卡片为核心，输入目的地不代表用户已经到达那里。

## 搜索页

- 入口沿用首页顶部搜索。标题“搜索”，一个输入框、清空按钮和候选列表；无需额外选择搜索供应商。
- 输入至少2字符，停顿300毫秒后同时查询 Abasong 公寓目录和 Mapbox Search Box；每路最多5条。本地结果先显示；外部查询失败不遮住已有公寓结果。
- 每行展示名称或门牌街道，第二行展示完整地址/城市/州，整行可点。保留供应商归属说明；不增加业务提示备注。
- 同一完整门牌街道＋城市＋州合并，兼容常用方向和道路缩写、大小写、标点。保留不同门牌、不同城市、单元地址，以及目录中不同公寓实体。没有完整地址依据时只按供应商 ID 去重，不凭相似名称合并。
- 修改或清空输入立即撤去旧候选并取消旧请求；迟到响应不能覆盖新输入。点选期间禁重复点选，仍可修改输入取消本次定位。成功后收起键盘。
- 空输入不显示历史；无结果显示“未找到匹配地址／试试门牌号、街道或城市”。部分服务失败显示简短错误和“重试搜索”；过期候选需重新搜索。

## 点选后的三个结果

| 结果 | 地图与卡片 | 下一步 |
|---|---|---|
| 已收录公寓，或外部地址唯一明确匹配 | 镜头转到公寓；已有合法建筑映射时高亮/门牌；显示其原有资料卡片 | 由原权限接口加载密码 |
| 同一地址对应多条公寓实体 | 定位该地址，显示“请选择对应公寓”和候选名称/地址 | 用户选择后再加载该公寓资料 |
| 地址没有匹配到目录公寓 | 菱形目的地标记；卡片展示地址、“暂未匹配到公寓资料”、“搜索其他地址” | 可重新搜索或点定位回到自己 |

外部地址不自动获得公寓类型，不把附近一栋公寓的密码放上来，不自动变为新增公寓或私人收藏内容。第一版暂不提供从供应商临时地址直接建档的入口。

## 匹配与定位边界

手动地址匹配同时要求规范化街道门牌、城市、州一致，且目录点距返回坐标不超过250米；超过候选保护上限则不自动匹配。250米仅为手选地址的数据核对边界，不是到达阈值，也不是自动识别开关。

搜索只控制相机和目的地标记；GPS蓝点始终来自设备定位。连续GPS不抢走用户已选地址/公寓；点右下角定位后清除临时目的地，回到真实位置并恢复原有到达匹配。未经现场核对的样本不能因搜索成功就开启自动认定。

## 临时数据与验收

Mapbox 搜索数据仅在本次交互内存使用，不保存搜索历史、不写公寓库/私人库、不进入URL参数/持久缓存。切后台、退出账号、回位清理目的地交接；路由只传随机交接键。记录归属随结果显示。

验收覆盖：完整与部分地址输入、去重、快速修改/清空、点选唯一/多候选/未匹配、错误重试、过期会话、后台清理、回蓝点，以及双端键盘、卡片和地图控件。模拟器、公寓现场及真机验收分别记录。

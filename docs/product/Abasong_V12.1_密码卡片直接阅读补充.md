# ADD-15 密码直接在卡片阅读

2026-10-31。用户真机反馈：点密码可以放大，但返回有延迟；卡片已能看到密码，放大和返回没有必要。按此反馈取消 B01 密码大字页及点击放大，覆盖早期 PRD、逐页规格和设计验收中的相关要求。

- 首页收起卡片直接完整显示排序第一条密码；展开卡片直接显示各条密码、门别、时间及反馈。
- 密码是文本，不伪装成按钮；点击不打开页面或弹层，不增加复制、分享、菜单或解释提示。
- 保留清晰字号、数字对齐和系统字体缩放。长密码换行、可在卡片内滚动，不能用省略号或限制行数隐藏字符；`0`、`#`、`*`等字符按原值显示，不插入分组字符。
- 展开/收起只由地址标题、手柄和记录入口控制；添加/反馈仍在卡片内。权限不足、读取失败时不显示旧密码。

页面目录移除B01，当前39节点/284状态；旧原型与历史验收保留其原始范围，当前扩展原型同步移除大字入口。密码贡献直接共享、反馈排序、资格与定位规则不变。

验收：短值与32字符值均在卡片完整可读；点击密码没有跳转；展开/收起保持公寓；添加页返回可操作；无资格时密码不残留。iPhone报告的大字返回延迟属于旧路径失败，不记为通过，也不据此断言其他页面存在相同问题。

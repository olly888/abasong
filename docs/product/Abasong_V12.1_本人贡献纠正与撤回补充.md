# ADD-19 本人贡献纠正、撤回与共享管理

最新产品反馈：双端技术验证后，用户提出不建议提供常规“撤回已贡献密码”。当前实现与下述验收规则保留技术事实；是否取消普通列表撤回入口、仅保留纠正及误共享处理，正在本轮讨论，不能把技术通过视为该功能最终产品认可。

2026-11-01。承接用户批准的共享管理任务，覆盖旧文中逐条人工审核、仅创建者可撤回整条记录的描述。不新增运营审核。

## 页面与操作

“我的 → 我的公寓 → 我共享的”按本人首次贡献时间倒序分页。每条显示门牌与街道、门别、本人贡献时间、共享/已纠正/已撤回状态、有用与不能用反馈；具备查看资格且本人来源仍有效时直接显示密码。未实现的查看人数不显示为0，不展示查看者身份或位置。

有效贡献可“纠正密码”“撤回我的贡献”。纠正页固定所属公寓，填写正确密码和门别，核对共享来源，确认后直接共享并回共享列表。取消不写入；未确认内容只在当前页面内存。撤回先确认，只停止本人的共享来源。

## 多人同码

一个公寓、门别和相同密码可以由多名司机独立贡献。每个司机有独立、带版本的共享来源；不能修改、撤回他人来源。纠正为新增或复用正确密码，再结束本人的旧来源。旧密码、贡献时间和反馈历史不覆盖，旧票不迁移到新密码。

仍有其他有效来源时旧码继续按既有规则展示；最后一个来源结束后停止公开展示。反馈不是独立发布授权，不因存在有用票而要求运营人工处理。原创建人来源结束后，公开署名与时间来自仍有效的最早来源。相同密码的重复贡献不刷新首次时间、不自动投有用票。

再次明确共享可恢复本人的来源；过去纠正/撤回事件保留。平台全局失效或禁止的记录不能通过恢复绕过。

## 权限、失败与一致性

本人列表仅元数据，无需查看/贡献资格；正文要求本人归属及access.read。纠正是发布动作，要求access.contribute。有效账号即使资格已到期，仍可撤回本人有效来源。其他账号猜ID返回404。

所有修改使用版本和幂等键。弱网重试同一意图不重复写入；版本冲突先刷新，不把旧编辑覆盖到新状态。成功写入后列表刷新失败只重试读取。分页稳定，切账号/后台不保留明文编辑。多人同码、同时纠正/撤回、重复点击、旧请求重放必须纳入真实HTTP/数据库验证。

实现与验收事实以DEVELOPMENT_STATUS及本批技术报告为准；文档不代表已经双端通过。

# ADD-12：统一贡献入口与单次截图添加

2026-10-31，用户认可并要求实施。以“我的”贡献入口为准，覆盖旧文档中截图草稿列表、保存进度、跨次继续与跨端续填的产品要求；不改变 ADD-11 确认后直接共享及反馈排序。

## 统一入口

首页通用“＋贡献公寓密码”、“我的”及“我的公寓”通用贡献按钮使用同一个菜单：截图识别、快速填写、取消。名称、选项、默认共享范围一致；取消不改页面，完成或退出返回原来页面。首页不再跳过菜单直达截图添加，也不根据当前 GPS 自动绑定公寓。

已明确目标的公寓卡片内“添加密码”仍直接打开这栋公寓的填写页面。私人导入保留在我的公寓，默认仅自己保存，不与通用共享入口混用。

## 单次添加

流程固定为：选择截图 → 核对结果 → 确认共享 → 完成。

- 每次重新进入从空白“选择截图”开始；不查询历史草稿，不显示“继续上次添加”或加载旧进度失败。
- 移除“保存进度/更新已保存进度/稍后继续”和我的公寓中的导入续填列表。
- 本次内可继续添加图片、编辑、返回选图、停止识别、继续识别剩余图片及失败重试。
- 有未提交资料或未处理图片时，退出整个流程只提示一次：“未提交的内容将清除，已保存或共享的资料会保留。”空流程或全部处理完退出不弹提示。
- 打开系统相册、取消选图、短暂切到后台、接电话或临时网络错误，不视为主动退出，不清空当前会话。关闭流程或重启应用后，不提供跨次续填。
- 已成功保存/共享的资料保留；部分失败在本次内重试只补失败项，不能因取消草稿误删除已完成记录。

## 工程边界

本批撤去客户端发现/恢复/手动保存草稿的产品入口。确认提交时已有的批次、逐项结果及幂等标识继续用于同次失败恢复；不是向司机提供历史草稿功能。既有服务端草稿按当前有限保留策略到期，暂不删除旧数据库表、服务契约或用户历史资料，不做云迁移。

## 验收基准

1. 首页与我的通用按钮显示相同菜单，两条路径分别测试截图识别与快速填写。
2. 已知公寓添加密码保留公寓信息；通用贡献不擅自带入蓝点附近的公寓。
3. 即使旧账号存在历史批次，截图添加页也无续填列表和历史加载请求。
4. 选图→返回/后台→继续，内容保留；确认退出→重新进入，内容为空。
5. 没有未提交内容直接退出；有内容退出仅一次提醒，取消退出仍可继续。
6. 本次停止/继续、失败重试、部分成功结果保持正确；已完成记录不重发或删除。
7. 原型与 iOS/Android 分别验证，未完成的真实设备范围据实记录。

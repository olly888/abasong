# V3.2 司机圈定位与最小社区补充

2026-11-05。用户已同意司机圈优化建议；本批更新C01/C02/C03规格、文案、独立原型及B5差异；最新[图片发布补充](Abasong_V3.2_司机圈图片发布补充.md)覆盖此前纯文字限制。实际App仍显示“司机圈尚未开放”，本批不接业务服务或提前启动B5。UP13/UX11。

## 1. 定位与边界

司机圈是围绕配送工作的同行交流与互助社区：休息时交流经验、提问、分享路上见闻，逐步认识同行并形成重复合作。首页解决当下查码/找活/找人；消息用于具体联系；司机圈的信息流不复制一个找活列表。

内容采用配送提问、经验分享、路上见闻三个轻量可选标签，单条最新发布信息流，不设三个空频道或推荐算法。车辆使用、租车及保险经历可作为普通经验；不建设租房、车辆交易、保险报价或商家专用市场。首版文字可配最多3张图片、基础文字回复，不新增视频、图片回复、点赞、收藏、关注、热门榜或商业专区。

公寓密码留在统一贡献链路；面单/住户资料不作为动态内容。临时缺人、代跑和车辆求助使用现有结构化需求，动态只引用同一个需求ID，不能通过发文字生成另一套报价、报名或已找到状态。

## 2. 三页规则

| 页面 | 内容与交互 | 状态/验收 |
|---|---|---|
| C01司机圈 | 根页无返回箭头；右上“发布”；作者/可选地区/时间、轻标签、正文、可选引用卡、回复；长文约4行展开 | 单信息流按最新；空、加载、失败分别表达；屏蔽后内容消失；返回恢复列表位置 |
| C02动态与回复 | 全文/图片、同ID需求、基础文字回复；作者进入D02最小资料，私聊/常联系复用既有功能 | 发送中禁重复，成功才新增；失败保留、同一动态草稿隔离；删除/不可见/被屏蔽不可继续回复 |
| C03发布动态 | 正文＋可选0–3张图/标签/配送地区/本人需求引用；一个“发布”主操作 | 空/长度/发布中/失败保留；关联需求提交前再核对；退出可继续编辑、保留本次草稿或放弃 |

地区是作者主动选择的内容参考，不是作者当前GPS；不展示距司机多少米。未选地区不伪造位置，也不因没有地区隐藏其有效内容。标签不改变需求类型或发布权限。

草稿只说明普通文字动态，不恢复已取消的截图跨次续填入口。首版仅保留当前账号会话内存，注销清除；原生会话保留和清理在B5实现，不新增服务端草稿或跨设备保存。

## 3. 需求引用与联系

引用摘要采用自然高度的SourceCard：类型/当前状态、配送区域、报价与单位、接手日期/时间、剩余件数/人数及取件大致地区。内容来自当前同一请求对象，不复制到帖子正文；需求更新或结束时同步，历史动态可保留但不能继续报名。无权限/已移除时显示“关联需求暂不可查看”，不残留旧报价或仓库完整地址。

点击进入同一D01；完整商业仓库地址/地图/复制/导航按详情既有权限展示。帖子作者是交流发起人，不被声明为DSP、已认证或已承诺接单。点头像/姓名进入最小资料；私聊和常联系使用已有关系规则，沟通后自愿加入，信息流不堆多个联系按钮。

回复通知进入现有M01通知，点开重新核对C02及评论可见性；删除/屏蔽后不泄露旧正文。锁屏通用文字，不含密码/住户/评论正文；本批只演示站内合成通知，真实远程推送仍B6待凭据/送达验证，不新增圈内消息图标。

## 4. 视觉与内容管理

沿用V3.2黑白灰/皇家蓝/系统字体。信息流自然高度、20边距、细分隔线；正文16/26，作者15/600，地区时间12/18；长文4行展开，保留48热区。引用卡用SourceCard紧凑变体，不套地图192高度或横滑。无回复时“回复”，有回复时“回复 N”；计数不含不可见作者内容。

首版举报、屏蔽、本人删除必须可达，失败保留本次文字。正常内容不建立逐条运营审核工作台；删除/举报的服务端处理仍按对象权限和已有报告模型。不能把客户端隐藏或正则演示当作安全控制。用户误将门码发到文字时，指向贡献入口，不替其自动发布或猜绑公寓。

## 5. B5技术落点与体验出口

D15：原生C01/C02/C03、帖子/回复真实服务、可选topic/region_id、本人request_id引用及并发/幂等/分页。D17补私有媒体/图片发布和读取权限；D16：复用报告/屏蔽/作者资料/常联系/通知，补circle_reply目标的可见性和删除回跳，不另建聊天系统或推送平台。实际契约和迁移尚未修改，详情见[差异清单](../technical/V3.2_原型到代码差异与实施批次.md)。

[新版原型](../../design/abasong-independent-v1/v12.1-experience/index.html?v=r3-circle&task=circle)使用合成人物、动态、需求和通知，所有发布/回复只进当前内存。工程检查见[司机圈报告](../../design/abasong-independent-v1/v12.1-experience/circle-checks.json)；真人/原生/远程送达仍未验。

给原5名司机的B5观察增加T10“读一条相关经验并发布动态”、T11“回复后查看作者并联系”；另用[10条空模板](../usability/V3.2_司机圈任务记录模板.csv)记录。只观察是否找到入口、正确发动态/临时需求、回复失败恢复与理解；不把浏览时长或假活跃人数作为价值证明。本批未招募或进行新观察，也不以此额外阻挡独立R4准备。

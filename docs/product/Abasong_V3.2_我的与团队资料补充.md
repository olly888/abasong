# Abasong V3.2 我的、常联系与DSP团队资料

2026-11-05。用户已批准[RM01–04评审](reviews/Abasong_V3.2_我的菜单与DSP身份商业模式评审.md)中的首版方向。本补充是目标规则；本轮仅更新文档和[独立交互原型](../../design/abasong-independent-v1/v12.1-experience/index.html?v=r3-account&task=me)，不是实际App、服务或权限已实现。RM05成员系统、RM06收费保持后置。

## 1. 统一账号与使用用途

同一手机号账号可配送，也可代表DSP找人。注册仍是短信登录和显示名，不强制选择司机/DSP，不为查码要求车型、团队或联系方式。U02可选“我接临时配送”“我代表 DSP 找人”，可同时选择、随时修改；二者均不选仍可使用已有查码、贡献和交流能力。

用途仅调整填写内容和次级入口，不授予团队代表权限、资料查看/贡献资格或商业权益。配送经验、可接活声明分开；改经验不自动声明可接活。关闭接活用途时若已有有效声明，先确认是否同时关闭，取消则不改已保存资料。没有声明的DSP不必填车型、容量，也能个人发布需求。

原型的已存在TEST账号预设双用途和一个团队，方便审查；不代表新注册者默认拥有团队或任何真实权限。

## 2. U01 我的：顺序与入口

1. 头像/显示名整块进入“个人资料”，辅助文字“个人资料与联系方式”。
2. 蓝色唯一主要操作“贡献公寓密码”，复用首页同一个贡献菜单。
3. “我的公寓”：我保存的/我共享的，不再另建重复根菜单。
4. “可接临时支援”：接活用途或存在有效声明时显示，进入已有U03。
5. “我的发布”“我的报名”。
6. “常联系”；已有团队或选择代表DSP用途时显示“我的团队”，无团队者添加资料。
7. 底部“设置”。顶部不另放设置/消息图标。

保留首页/司机圈/我的三导航，不加司机端/DSP端切换、工作台、会员、钱包、收入或“即将开放”占位。普通司机可从个人资料或首次代表团队发布时添加自己的团队；不要求加入别人的DSP团队。

## 3. U02 个人资料

| 分组 | 字段与交互 | 规则 |
|---|---|---|
| 个人 | 显示名、简短介绍 | 显示名必填；团队名与个人名字分开 |
| 使用用途 | 接临时配送/代表DSP找人 | 可多选，非角色权限或核验 |
| 配送经验 | 配送过的快递公司多选＋其他、熟悉区域最多5个、可选车型 | 仅接活用途展开；明确自填，不称“所属快递公司” |
| 联系方式（选填） | 电话、微信号 | 默认仅自己可见，不读登录手机号；可在聊天中自愿提供 |
| 团队资料 | 添加/编辑团队资料 | 转U10；保存后回实际来源，原草稿保持 |

底部固定“保存资料”；失败保留输入、不假装保存。未改直接返回；有改动可继续编辑、保留本会话草稿并返回或放弃。退出账号清除未保存输入和迟到保存；无跨设备草稿功能。自填字段不能覆盖服务端核验记录。

## 4. U08 常联系：私人保存与重复联系

保留轻量常联系。已有站内会话后，手动加入同行账号，不要求互加好友或对方同意；陌生消息不自动收录。列表显示名字、自填经验、当前有效且对方主动声明的时段，以及本人私人备注。可看资料、继续原会话、改备注、确认移出。

移出只影响本人名单，不删聊天、不通知对方、不取消既有报名。备注只本人可读，不转成公开评分、合作次数或DSP成员档案。空列表与加载失败分开，失败可重试；备注失败保留输入。已屏蔽/注销状态明确，保留本人的备注但不能借保存联系人绕过屏蔽继续联系。

常联系不自动解锁电话、微信或密码，不导入通讯录、不搜手机号、不导出名单。首版B5最小必需；复杂标签、共享司机库、群发和团队名单不做。

## 5. U10 我的团队／团队资料（DSP）

面向司机的菜单改“我的团队”，编辑标题“团队资料（DSP）”。内部可保留organization命名，避免为改文案重命名全部数据库。首版仅维护本人有权代表的一个团队资料；无加入、邀请、成员、审批或多管理员功能。

| 字段 | 要求 |
|---|---|
| 团队名称 | 必填，独立于个人显示名 |
| 联系人 | 当前账号本人；改名字转个人资料，不冒用同事 |
| 合作快递公司 | 可多选＋其他；不代表承运商官方或认证 |
| 主要配送区域 | 最多5个；不是GPS或实时运力 |
| 业务电话、微信号 | 选填，需有权提供；不继承Auth手机号的核验标识 |
| 向登录用户展示业务联系方式 | 默认关闭；主动开启至少填一项有效联系方式 |

线路、取件仓库、包裹数量、报价和日期属于当次需求，继续用P03填写；不放到团队资料当全局条件。DSP的管理仍是我的发布→看报名→联系→手动改缺口/已找到/关闭；复用复制需求，不建设新后台或线路管理页。

## 6. 联系方式在哪里展示

| 信息 | 本人 | 其他登录用户 | 地图/列表/公开H5/锁屏 |
|---|---|---|---|
| 登录手机号 | 既有账号设置 | 不返回 | 不返回 |
| 个人自填电话/微信 | U02、会话操作“我的联系方式” | 本人自愿在现有文字会话提供后才可见 | 不自动附加 |
| 团队业务电话/微信 | U10 | 仅主动开放后，在相关个人资料/需求详情点“业务联系方式”查看 | 不返回 |
| 常联系私人备注 | 本人U08 | 不返回，即使同DSP | 不返回 |

原型联系方式面板只展示/复制，不发短信、拨号或自动发送聊天。复制失败保留可选择文字；未填写可去本人资料添加。微信不加二维码或自动加好友；以后原生拨号必须由本人主动调用系统确认，不自动拨号。

关闭展示、屏蔽、账号停用后停止新读取；打开的面板同步隐藏旧值。已被对方自愿接收或复制的内容无法远程追回。原型的客户端开关仅演示，真实服务必须逐请求执行对象/可见性授权，不能靠客户端隐藏保护。陌生账号、跨账号、缓存、退出和权限变化测试在B5实现/B6真实出口分别记录。

## 7. 发布身份与历史来源

新需求选择“个人”或“代表XX团队”。首次添加团队，保存后回原发布草稿，仓库/线路/数量/报价不丢。团队和联系人在详情清楚展示；自填无认证勾，地图不堆“自报组织来源”术语。

已发布需求保留发布时团队/联系人来源快照；改团队名称不覆盖旧需求，编辑旧需求不能悄悄换发布身份。当前联系方式按团队ID与当前开放状态另外鉴权读取，不能因为旧快照含团队名就返回已经关闭的号码。复制为新需求时重新核对当前身份。个人私存、收藏、常联系与贡献身份不转归团队。

## 8. 首版商业边界

本轮不启用收费、订阅或付费展示入口，不售号码库、不付费解锁私人信息，不按工资抽成。司机核心功能、DSP基础找人继续免费内测；配送费线下结算。后续DSP专业订阅仍是待真实验证的商业假设，尚无价格、套餐或计费实现。用途、代表权限、公寓资格和商业权益四套语义分别维护。

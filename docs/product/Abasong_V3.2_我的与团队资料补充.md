# Abasong V3.2 我的、接活状态与DSP团队资料

2026-11-05简化定稿。用户已确认前轮评审并指定接活开关在个人资料下方、共享主按钮上方。覆盖上一版保留常联系的建议；[上一版](../archive/my-simple-20261105/我的与团队_上一版.md)仅历史。[当前原型](../../design/abasong-independent-v1/v12.1-experience/index.html?v=r3-simple&task=me)仍是独立合成体验，实际App/服务未改。

## 1. 我的顺序与信息分组

1. 头像/显示名整块进入个人资料。
2. 接活状态：紧凑开关行；所有登录账号均可保持关闭，不要求DSP填写司机资料。
3. 蓝色主要按钮“共享门禁码”，仍是页面唯一主要CTA。
4. 同一白色分组依次为“我的公寓、我的发布、我的报名”。
5. 次级分组拟增加“邀请司机”；同组“我的团队”在已有团队或代表DSP用途时显示，无团队者可从资料/首次代表发布添加。邀请项仅方案，当前原型尚未加入。
6. 底部设置；无顶部重复设置/消息。

三导航保留。首版移除常联系菜单、加入/移出名单、联系人私人备注、团队共享名单等整套功能；不换名恢复司机库。既有一对一消息、本人自愿提供电话/微信仍可用，司机建立联系后可自行转到微信/电话。历史会话不因取消名单而删除。U08从当前页面目录退役，保留历史编号/已有数据库，不做回滚迁移。

## 2. 接活开关

开关位于个人资料下方，视觉低于共享蓝色按钮。关闭显示“暂不接活”；点击开启进入已有U03，填写本次起止时段、1–5个愿去区域、可选容量。保存成功才显示开启，取消/失败不提前出现在找人地图。当前与未来时段均明确日期；未来时段不叫在线。到期显示关闭，停止推荐。

已开启的辅助文字显示时间/区域，可点修改；关闭操作直接停止本次推荐，失败保持原状态并可重试，不改报名或历史聊天。真实端必须用既有版本检查/请求状态；原型仅合成成功/失败。用途只是资料偏好，不授资格，也不限制账号使用接活开关；关闭接活用途时若已有有效声明，仍须本人确认是否一起关闭。

## 3. 个人资料与联系方式

统一账号，注册仍为短信登录＋显示名，不强制司机/DSP二选一。U02可兼选接配送/代表DSP找人；显示名、可选简介、接活用途下的多快递自填经验/最多5区域/可选车型，保持字段层级。用途、团队代表权、公寓资格、未来商业权益分别判断。

个人电话/微信选填、默认仅自己可见，不从Auth预填。现有会话“更多→我的联系方式”可查看/复制后由本人自愿提供，不自动发消息/短信、拨号或加微信。复制失败仍可选择文字。无电话号码搜索、通讯录同步、号码库或付费解锁。资料失败保留、回实际来源、本会话草稿/放弃及退出隔离继续保留。

## 4. DSP团队及需求来源

菜单“我的团队”，编辑“团队资料（DSP）”：独立团队名称、当前本人联系人、多合作快递＋其他、最多5个主要配送区域、可选业务电话/微信。显示开关默认关闭，主动开启需至少一项有效联系方式。自填不标认证，不代表快递公司官方。

团队业务联系方式仅在对方主动开放后向有权登录用户在相关资料/需求详情查看/复制；地图、列表、帖子引用、公开H5和锁屏不返回。关闭、屏蔽、停用后停止新读取并清旧面板；已被复制的内容无法远程追回。真实服务逐请求鉴权，原型开关不是安全实现。

首次代表团队发布时可添加团队，保存回同一草稿，仓库、线路、数量、报价保持。已发布来源身份固定，改团队名称不覆盖历史来源；当前联系方式按团队ID与当前可见性另外读取，不存进历史快照。个人公寓/贡献不归团队。

DSP仍复用发布、看报名、联系、改缺口/已找到/关闭和复制需求。首版无成员加入、邀请、多管理员、长期招聘、排班/派单/结算后台；不启用收费或订阅。

## 5. 屏蔽与设置

保留会话/个人资料/司机圈的举报与屏蔽能力，处理骚扰和垃圾联系；它不是好友系统。设置默认不显示空“已屏蔽用户”菜单，有记录时在低频“隐私与安全”组提供解除入口；不在我的主菜单增加一项。

Abasong保留公开用户内容和一对一互动，依据[Apple 1.2](https://developer.apple.com/app-store/review/guidelines/#user-generated-content)与[Google用户内容政策](https://support.google.com/googleplay/android-developer/answer/9876937?hl=en)保留必要能力。本次仅核对产品入口，不声称已完成真实平台审核或所有服务授权。

## 6. 名称、共享及卡片规则

用户界面统一“门禁码”：共享门禁码、添加门禁码、暂无共享门禁码、纠正门禁码。用词是准确表达，不是规避审核的保证；共享授权/承运商内容许可、受控查看和投诉停显仍须落实。正常确认直接共享，不增加逐条人工审核。住户私人门锁、收件人和无权传播内容不作为可共享资料。

配送界面用找活/找人/配送需求/部分包裹代送/整条线路代送/车辆求助；接活开关不称自动接单。正式范围仍是单次、明确日期/件数的灵活配送合作，不做长期招聘。

卡片第一行只强调门牌＋常规字重街道；下一条既有辅助行显示“城市 · 约25 m”，不增加卡片高度。内部距离与排序同源，前台不显示“至边界/直线”；不是步行/入口/到达承诺。近处以m展示，粗略位置弱化、过期隐藏数值；完整州/邮编/公寓名展开查看。详见[地图卡片补充](Abasong_V3.2_地图卡片与距离体验补充.md)。

## 7. 手动添加统一B02

统一共享菜单保留“从截图添加”“手动填写”。手填立即进入添加表单，不打开公寓目录或全量下拉：公寓地址→门禁码→可选门别→核对来源→确认共享。

通用入口地址为空，输入后仅显示匹配候选；首页公寓卡入口预填当前卡地址，能更换。两者同一表单和保存规则；更换地址保留门禁码/门别但清除来源确认，未核对目标不允许共享。没有候选可在同页手动核对完整门牌/街道/城市/州/邮编，不猜绑最近点。未收录地址只建合成业务关联，不伪造附近坐标/距离；真实新地址永久保存沿用已有许可与鉴权规则。

删除手填表单中的“截图贡献多个公寓”大按钮，截图仅从统一共享菜单进入。失败保留正确目标和填写，成功回到相应公寓；截图的选择→核对→确认共享、无跨次续填和本人纠正不变。

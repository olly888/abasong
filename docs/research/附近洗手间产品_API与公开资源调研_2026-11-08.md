# 附近洗手间：产品、API 与公开资源调研

日期：2026-11-08，America/Los_Angeles。范围：Abasong 洛杉矶地区，优先 West Covina。

本次为公开资源研究与少量只读接口核验，不是功能交付。没有复制第三方门禁码、导入业务库、联系服务商、建立云资源或修改 App。保持 [P1 候选范围](../product/Abasong_P1_附近洗手间候选与验证方案.md)，M7 冻结候选和验收顺序不变。

## 1. 结论

已有洗手间查询产品，也有专门共享洗手间密码的产品。可接入的公开地点数据和 API 确实存在；本次未找到可确认覆盖洛杉矶、允许 Abasong 直接商业集成、持续维护有效密码的标准公开 API。

应分别判断四层信息：地点在哪里、是否有洗手间、什么条件下可使用、具体进入方式。门店存在或营业，不足以证明后三层。公开网页可读、数据有开放许可、接口允许长期接入，是不同条件。

推荐顺序：OSM 与当地官方设施资料评估覆盖 → REFUGE 作为补充候选 → Mapbox 保留地图及搜索 → Abasong 积累独立确认的使用条件与获准共享的进入信息。先验证信息是否足以减少白跑，不立即扩大产品范围。

竞品存在说明已有相关供给，不足以证明 Abasong 的司机会高频使用，也不构成必须增加收费、排行、商户工作台等功能的依据。

## 3. API 和数据源

### 3.1 OpenStreetMap / Overpass：优先做覆盖探测

OSM 不只记录独立公共厕所。两类对象都应查询：

- 独立设施：`amenity=toilets`。
- 门店等场所：`toilets=yes`，并核对 `toilets:access`、`toilets:wheelchair` 等属性。

资料可包含位置、使用条件、费用和无障碍信息，完整度由各地贡献决定。缺失字段表示未知；`toilets=yes` 不等于所有人可免费进入。门店营业时间与洗手间开放时间不能无条件等同。[独立设施标签](https://wiki.openstreetmap.org/wiki/Tag:amenity%3Dtoilets)、[场所内洗手间标签](https://wiki.openstreetmap.org/wiki/Key:toilets)。

Overpass 支持空间范围和标签查询，适合研究与受限覆盖探测。官方明确提示不要把共享公共实例当成大众 App 的持续后端；生产阶段应评估受许可的数据供应、区域快照更新或自托管，而不是每次司机移动都直连公共服务器。[官方资源规则](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html)。

数据采用 ODbL，需落实署名及适用的数据库共享义务。实施前界定来源数据、派生数据库和独立司机贡献之间的关系，不能用“分表”直接宣称免除许可要求。[许可说明](https://www.openstreetmap.org/copyright)。本轮未查询 OSM 地点数量，未验证 West Covina 覆盖；不把开放许可等同无限免费 API 或有效密码库。

### 3.2 REFUGE Restrooms：真实 API 可用，West Covina 有检索结果

[REFUGE](https://www.refugerestrooms.org/)主要服务跨性别、双性及性别不符合传统规范的人群，提供安全洗手间信息。其[公开 API 文档](https://www.refugerestrooms.org/api/docs/)与[官方接口源码](https://github.com/RefugeRestrooms/refugerestrooms/blob/develop/app/controllers/api/v1/restrooms.rb)列出全文、位置、日期查询与无障碍/通用洗手间筛选。

本次实际发起一次无凭据 GET：

```text
https://www.refugerestrooms.org/api/v1/restrooms/search?query=West%20Covina&per_page=10
```

结果为 HTTP 200，返回 5 条记录，5 条的 city 字段均为 West Covina。只输出数量和字段名，未记录评论、进入说明或任何密码正文。可见字段含 `id/name/street/city/state/latitude/longitude/accessible/unisex/changing_table/created_at/updated_at/upvote/downvote`。

这只是一次文本查询的返回数，不是市内设施总数、有效设施数或覆盖率。`updated_at` 是记录更新时间，不等于最近成功使用时间。接口不是专门的密码服务，也不应用通用评论字段充当结构化、已获准共享的密码。

[项目代码](https://github.com/RefugeRestrooms/refugerestrooms)采用 AGPL-3.0；这不自动证明其业务数据允许无条件商业批量复制。本次未确认独立数据授权、限流承诺或 SLA。可作为下一步核对线索，稳定接入前核实使用与保存条件。附近接口已从源码确认，本轮没有实测位置查询。

### 3.3 洛杉矶官方地图：确有机器可读文件，但不能推断全县完整覆盖

[LA City and LA County Bathrooms and Water Fountains](https://bathrooms.lacontroller.app/)提供市/县设施地图。本次读取页面公开脚本所引用的六个 CSV，HTTP 获取成功；字段涉及设施名、地址、洗手间/饮水设施类别，部分文件另有坐标或设施数量。

| 公开文件 | CSV 解析数据行数 | 字段检查 |
|---|---:|---|
| [city-other.csv](https://bathrooms.lacontroller.app/data/city-other.csv) | 1 | 设施名、地址、洗手间/饮水分类 |
| [county.csv](https://bathrooms.lacontroller.app/data/county.csv) | 129 | 设施名、地址、洗手间/饮水分类 |
| [libraries.csv](https://bathrooms.lacontroller.app/data/libraries.csv) | 71 | 地址、城市、设施数量、坐标等 |
| [metro.csv](https://bathrooms.lacontroller.app/data/metro.csv) | 72 | 设施名、地址、分类 |
| [parks.csv](https://bathrooms.lacontroller.app/data/parks.csv) | 437 | 公园设施信息、洗手间类型等；首行存在空/重复列名，需清洗 |
| [streets.csv](https://bathrooms.lacontroller.app/data/streets.csv) | 4 | 地址、洗手间数量、坐标等 |

这些是原始解析行数，不是去重后的可用洗手间数，可能混有饮水设施、表头或说明行，不能相加作为覆盖宣传。六文件文本扫描未发现字面值 West Covina，不能据此断言全无当地地点；仍需坐标范围和逐条核对。地图名称含 County 不代表覆盖县内所有城市。

本次只验证公开读取与文件结构，尚未确认这组六文件的具体再分发许可和更新约定；不能因挂在官方页面就默认 CC0。

另一个明确带开放许可的数据集是 [Port of Los Angeles — Restroom](https://catalog.data.gov/dataset/restroom)：提供 JSON、CSV、GeoJSON 等，目录许可为 CC0。其范围是洛杉矶港管理边界，不能替代 West Covina 数据。目录载明数据更新时间 2024-04-10，目录检查日期不是现场核实日期。本次核对目录，没有测试该数据集下载接口。

### 3.4 West Covina 与 Covina 官方设施目录：本地起步更直接

[West Covina Facilities](https://www.westcovina.gov/Facilities)有 Restrooms 设施筛选。其 [City Hall 页面](https://www.westcovina.gov/Facilities/Facility/Details/City-Hall-25)列出公开地址、设施开放时间和洗手间设施，适合作为当地样本线索。开放时间仍是设施级信息，不能证明洗手间当前无条件开放。

邻市 [Covina 官方公园设施表](https://covinaca.gov/residents/activities/parks-and-maps-with-amenities/)也明确标注部分公园有 Restrooms。**Covina 与 West Covina 是不同城市**，样本和覆盖需分开记录。本轮没有发现这些设施页面的正式对外开发者 API，不把网页目录视作已批准批量复用的数据集。

### 3.5 Mapbox：继续承担地图和地点查询

现有 [Search Box](https://docs.mapbox.com/api/search/search-box/)可查询地址、品牌地点及类别，适合补充发现店铺、地图定位和搜索。它不是专门的洗手间使用条件或密码接口；返回某家星巴克不等于该店有可用洗手间。

Search Box 默认结果仅允许临时使用；持久化需适用授权，其他地理编码接口的永久设置不能替代该服务的许可。本次没有调用项目 Mapbox token，也未新增地图计费。

## 4. 对 Abasong 的实际取舍

| 目的 | 建议来源 | 现在的状态 |
|---|---|---|
| 地图、地址搜索、店铺定位 | 现有 Mapbox | 可沿用；洗手间业务尚未实现 |
| 初始厕所候选点 | OSM、有明确许可的官方数据 | 下一步做受限覆盖与字段检查 |
| West Covina 本地样本 | 当地官方设施目录＋REFUGE 返回线索 | 有线索；未逐条或现场验收 |
| 近期可用、顾客条件、进入方式 | 司机或设施方的明确确认 | 需独立记录来源和时间 |
| 获准共享的洗手间码 | 自主贡献或有书面许可的合作 | 不从竞品或社交帖子直接批量搬运 |
| 第三方密码服务合作 | 优先进一步评估 FlushPin | 未联系、未授权、未取得 API |

不需要另造一套地图，也不应把已有公寓门禁库直接扩成混合密码库。可以复用地图、卡片、反馈和访问保护组件；设施分店、具体洗手间、适用条件、最近使用确认须独立建模。一个分店里不同洗手间不能因门店名相同而共用同一密码。

可借鉴的产品细节为：点选使用条件、区分无需密码与需询问、显示最近确认而非仅累计票数、报告关闭/错位、明确导航目标。首版不增加排行榜、Wi-Fi 分享、商家营销后台或新的收费模式。

## 5. 下一步最小工作与证据边界

1. 先做 West Covina 10–20 个候选的来源比对，区分品牌 POI、已记载有洗手间、近期确认可使用三个等级。已有 5 条 API 结果不抵扣现场验证数量。
2. 核对可持久化许可、同店去重、营业与洗手间时间、未知状态；先完成资料表，再决定是否有足够数据制作 P1 原型。
3. 如仍缺可靠代码信息，可保留“询问前台/顾客可用”等使用方式，不为填满卡片引入未经确认的密码。
4. 第三方合作先形成可审查问题清单，未经用户授权不对外发消息或申请付费服务。

已执行：官网/商店与官方文档阅读；REFUGE 一次公开城市检索；洛杉矶官方地图六个 CSV 的字段/行数检查；本地文档检查。未执行：竞品 App 安装实测、密码提取、OSM 地方数量探测、地点开放现场核对、合作或授权确认、功能原型/代码开发。**可用地点现场核实仍为 0。**

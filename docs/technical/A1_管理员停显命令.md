# 内测管理员停显命令

2026-11-01。仅处理误共享或绑错公寓，不新增逐条审核流程，不对普通司机开放。当前执行器只允许隔离本地D0，云管理身份将在A2单独审查。

先 `./scripts/dev build`。由已具备有效 `ops.review`、完成MFA的管理员自行准备当前访问令牌文件，所有者为当前用户、权限0600、非符号链接；不要放在命令行或聊天。操作者必须核对环境、来源UUID、版本和原因；不需要解密密码。

```sh
./scripts/dev exec tsx scripts/d1/stop-contribution-source.ts   --environment d0 --token-file /private/tmp/abasong-operator.jwt   --source-id SOURCE_UUID --expected-version 1   --operation-id NEW_OPERATION_UUID --reason wrong_apartment
```

默认dry-run无写入，另一个原因值为 `accidental_share`。只有重新核对结果后给相同命令增加 `--apply` 才执行。相同操作编号仅能重放相同目标、版本、原因与操作者，不得用于其他来源。成功输出仅 applied/replayed/applied_version；不输出令牌、密码、SQL或连接串。

脚本不授予任何管理员权限，不接受云连接，也不复用普通API角色。版本过期、MFA或资格无效均拒绝。错误不自动尝试更高权限。用后由操作者移除临时令牌文件。正式内测需使用独立受限管理任务，并保留同样的业务校验/审计，禁止把D0 postgres连接移植到云API。

## 公寓级暂停与恢复

物业要求暂停或共享授权待复核时，按已经核对的公寓 UUID 暂停共享。处置覆盖该公寓当前与后续的共享来源，包括历史自由门别和未注明门别。地图地址及本人私存仍可读取。暂停期间，已保存的截图私存可以保留，尚未成功的共享需由用户在恢复后主动重试。

迁移 `0023` 为公寓共享状态保存只追加的操作历史。先构建，再使用现有管理员令牌文件预览公寓地址、当前版本和预计影响记录／来源数。预览不读取门禁码，也不写入操作。

```sh
./scripts/dev exec tsx scripts/d1/apartment-sharing.ts \
  --environment d0 --token-file /private/tmp/abasong-operator.jwt \
  --apartment-id APARTMENT_UUID --operation-id NEW_OPERATION_UUID \
  --action pause --reason property_request
```

确认地址后，在同一命令增加 `--expected-version CURRENT_VERSION --apply`。无操作历史时版本为 `0`。暂停原因还可使用 `authorization_review`。恢复前由操作者重新核对物业许可和资料有效性；另用一个操作 UUID，以 `--action resume --reason property_confirmed` 预览，再按返回版本执行。恢复只让仍有效且有活跃来源的记录按原规则参与查码。重放旧操作只返回旧回执和当前状态。审计保存操作者、对象、动作、原因及操作编号。暂停和恢复复用 `ops.review` 与 MFA 校验。

司机端重新读取时显示「该公寓暂不共享门禁码」。App 已经显示过的值不会由服务端主动推送清除，切换公寓、离开敏感页面或重新读取时按原生命周期更新。当前按公寓 UUID 执行；遇到多个目录记录指向同一物业，管理员需核对每个关联 ID。

云环境启用前，先确认迁移与新版 API 已部署，并验证所有仍接流量的实例都执行共享检查。存在有效暂停时，回滚必须保留同等拦截能力，或者停止提供共享读取和写入。云管理身份与执行入口另行验收。

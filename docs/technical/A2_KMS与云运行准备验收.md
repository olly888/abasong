# A2 KMS与云运行准备验收

2026-11-02。独立分支 `codex/d1-kms-runtime`，父基线A1 `972e2d9`。依据ADD-20，目标是使云端完整业务可部署；**本批本地工程验证通过不等于AWS或蜂窝现场已上线**。

## 实现

统一EnvelopeCrypto异步端口，覆盖私人公寓字段、私人密码、共享密码和导入候选。所有服务调用await；列表/去重/纠正等同步旧路径一并适配。D0继续读取旧本地信封，KMS采用AES256数据密钥与AES-GCM/AAD绑定，使用后覆盖明文DEK；异常不回退。云端HMAC为独立新Secret，明确版本；共享SQL不再硬编码local格式/密钥。0009扩展三个JSON载荷表的格式约束，不更改0001–0008或转换旧数据，版本清单要求到0009。

新增严格运行校验：指定DevWest/北加州、TLS verify-full、非管理员服务登录、KMS及生产环境。云镜像固定cloud.js入口，拒绝通过环境标签切成本地；worker不接收敏感连接/KMS/HMAC。保留普通本机启动入口，不影响现有开发预览。

Dockerfile/白名单上下文、环境模板、KMS任务策略模板、独立运行角色SQL、离线迁移SHA清单与只读云预检、回滚和资源费用材料已经准备。实际部署权限/密码/账号仍未配置，预检没有apply模式。部署细节与边界见[runbook](../../deploy/pilot-dev/README.md)。

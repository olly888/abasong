## 用户准备

1. 用自己的邮箱通过[AWS官方Advanced入口](https://signin.aws.amazon.com/signup?request_type=register)创建账号（指定区域与细分IAM要求见[注册指引](A4_AWS注册与短期访问准备.md)），亲自处理条款、身份/付款信息；开发先选基本支持即可，不需要购买商业支持。
2. 开启root MFA，保留本人恢复方式。日常开发通过IAM Identity Center/短期会话连接，不在聊天发送root密码、access key或验证码。
3. 账号可用后告知，届时核对账号ID/区域并配置受限部署身份；资源创建、具体策略/费用和DevWest迁移在方案确认后执行。不要把现有D0连接改成云库。
4. Mapbox付款方式已由用户添加，临时接口及本机永久保存已复核；部署时再核对云环境所用token与永久配置/预算，不盲目批量调用永久结果。
5. 保持Spaceship域名账户可用；本次公开DNS检查确认NS在Spaceship。AWS证书/ALB就绪后再新增明确的api-dev及验证记录。

这些准备不阻挡本地KMS/容器、样本清单和Release构建配置工作；它们阻挡实际云端双账号与离开Mac的完整业务验收。部署材料：[pilot-dev runbook](../../deploy/pilot-dev/README.md)。

## 本批可用结果

Mapbox发现的明确公寓地址，如果能够唯一匹配既有业务公寓，就直接进入该公寓的有权查码卡片。此前仅在司机200米目录查询中去重：目录代表点在范围外、附近屋顶在范围内时，即使已经有该地址的业务资料，Mapbox候选仍未关联。本批复用既有完整地址及250米空间匹配，不用距离单独绑定密码；250米为关联核对窗口，不是首页发现半径。

- 仅唯一匹配返回业务公寓ID及公开元信息；同址歧义、错门牌或远处同址仍为待确认候选。不注册公寓，不读取密码，不持久化供应商地址、点或瓦片ID。
- 临时Mapbox点和feature ID保留在本次候选中供地图使用；业务密码仍通过独立授权接口按业务ID读取。已核对地图范围继续优先。
- 自动推荐在地图慢响应补出更近公寓时选择最近卡片。滑卡、点选或展开后保持阅读，GPS和补充结果均不抢走；定位按钮恢复自动推荐。
- 无候选时区分“正在查找”、成功无结果与“公寓资料暂时无法加载”。失败可重新加载；已有有效目录卡继续使用，失败不伪装为没有密码。
- 保持200米、5次Tilequery和4次反向地址上限；最多增加4次现有数据库地址关联。既有速率限制、有效期、位置新鲜度与迟到请求隔离继续生效。

## 服务与数据库证据

先新增3项API回归，复现修复前失败，再修正服务并通过：唯一关联、歧义不绑、关联错误明确不可用。全仓`./scripts/dev check`为242项测试／43文件，lint、工作区和脚本类型检查、构建通过。接口仅更新字段/操作说明，无新字段、依赖或迁移；生成器、OpenAPI和生成类型同步。

`./scripts/dev verify:library-api`执行291项真实HTTP/隔离数据库检查，既有97组空间与8组地址匹配检查，以及来源、KMS合成网关配合真实PostgreSQL服务回归。新增8项`mapbox-password-chain`执行已编译生产服务及真实PostGIS：

| 场景 | 结果 |
|---|---|
| 目录点距司机300米，附近屋顶150米 | 原200米目录查不到，Mapbox候选仍唯一关联既有业务公寓 |
| 发现与密码读取分离 | 发现无密码正文，独立读接口返回该公寓TEST记录 |
| 相邻错门牌 | 不绑定原公寓 |
| 同址但距离超出关联窗口 | 不绑定原公寓 |
| 合成账号查看资格撤销 | 新读取403；地址发现仍不泄露正文 |
| 重复地址业务记录 | 歧义不选第一条 |
| 合成账号被停用 | 真实账户服务403，供应商传输零调用 |

上述8项包含目录排除、关联无正文与授权读取三个独立断言场景。外部Mapbox传输是测试替身；账户元数据使用测试连接，密码方法继续使用受限敏感连接池。仅在名称受保护、用后删除的临时库运行，不是本机D0真实账号授权或云端验收。

## 双端原生证据及边界

复用既有development build，加载本批JS；iOS、Android及Web JS导出通过，未新增原生模块、未重新声称原生二进制编译。双端运行同一个首页组件，替换数据通道为TEST场景：

| 场景 | iOS模拟器 | Android模拟器 |
|---|---|---|
| 目录为空，地图候选关联102 | 近邻补全场景验证关联卡 | 地图查码场景显示102、TEST-02#和TEST102高亮 |
| 慢补充结果比原卡更近 | 自动选102、对应密码与高亮 | 自动选102、对应密码与高亮 |
| 已展开100，12秒后补近邻 | 保持100和TEST-01#，阅读不被抢走 | 本批未新增手势补验，既有阅读锁证据范围保留 |
| 地图返回不可用且无目录 | 明确加载失败；点重新加载后仍无TEST密码 | 明确加载失败；重试按钮被SDK调试条遮挡，本批点击未验收 |

截图和日志仅存忽略目录`.tooling/mapbox-password-chain/`。iOS模拟位置已停止并清除。Android镜像触控不可靠，未将尝试点击记成通过，也未要求重复已验收手势。真实Mapbox样式接口本批复核仍HTTP401，底图可能来自缓存；TEST图形/传输不代表实时覆盖、建筑分类质量或iPhone现场通过。

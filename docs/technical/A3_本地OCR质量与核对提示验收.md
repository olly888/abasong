# A3 本地OCR质量与核对提示验收

2026-11-02，基于D1集成`49a38c3`，分支`codex/d1-local-ocr-quality`。用户明确暂缓云部署，本批仅本地实现、隔离数据库与模拟器验证；A4保持暂停，D1／A3未完成。

## 问题与最终行为

用合成OCR行复现三项缺陷：密集的“地址→密码→下一地址→密码”被误判多地址歧义；低置信度地址没有核对提示；含不确定符号的密码可能没有提示。

当前解析器按同列已标注密码与新地址分段，保留同段多个地址的歧义；重复密码字段仍归同一地址，跨列不混配。前导零、大小写及#/*不替换、不猜补；地址／城市行低置信度提示核对地址，不确定字符／低密码置信度提示核对字符。无效几何不静默绑定附近地址，输入上限600行／100条。

新增可选`review_issues`，端侧只传三个白名单提示；保存为原有加密候选的一部分。请求重试、重读或编辑都保留提示，只有明确`fields_confirmed:true`的核对操作可清除。不改变账号／对象权限，不新增迁移、不放宽发布条件。正常流仍是选图→检查→确认，未增加页面或审核。

## 离线质量工具与实际实验

[工具说明](../../scripts/ocr/README.md)。实际调用生产解析器，逐图哈希绑定，拒绝重复样本、越界路径与不完整声明；摘要只有计数／失败ID，无密码和地址。声明不代替授权与真值人工核对。真实数据留本地忽略目录。

实际macOS Vision运行10张合成图片，而非预置OCR断言；当前结果：

| 范围 | 实际结果 |
|---|---|
| 已授权脱敏真实样本 | 0张，30–50张目标未满足 |
| macOS主机合成图 | 10张，Apple Vision |
| 完整密码精确 | 7／8张有确定密码真值的图 |
| 地址配对及核对提示完全匹配 | 9／10张 |
| 无密码负例 | 1张，误提取0 |
| 识别耗时 | P50 55ms，P95 203ms；仅该主机实验 |
| 失败 | SYN-010混合字母数字识别不一致，已给核对提示 |

不把这些结果称为手机准确率或生产识别率。不可辨认值用null、从完整密码分母排除；失败不能靠改真值或猜字符消除。

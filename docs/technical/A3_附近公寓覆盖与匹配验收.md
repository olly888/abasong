# A3 附近公寓覆盖与匹配验收

2026-11-02，基于D1集成`03f5b0f`，批次分支`codex/d1-nearby-coverage`。用户继续暂缓云部署；本批仅本地代码、隔离PostgreSQL/PostGIS与合成地图传输验证。不是新增真实地区覆盖或现场验收。

## 最终行为

1. 附近200米发现和搜索后250米地址匹配，共用地址点／有效边界／有效建筑轮廓的距离计算。大型社区的代表点不再是搜索唯一空间依据；仍须完整门牌、街道、城市和州的规范地址一致，不能靠最近建筑绑定密码。
2. 边界来源须允许持久使用、已核对且未过期；建筑还须自身核对时间不晚于当前。无效、自交、未核对、未来生效或过期几何不扩大查询范围。既有目录地址点保留原有兜底，不因此新增贡献审核或屏蔽整条地址元信息。
3. 移除“只要建筑落入已收录社区，就在核对地址前隐藏”的逻辑。临时地图候选先取建议地址、再按规范地址去重；独立门牌保留独立候选，不把社区密码套过去。地址不明仍是临时待核对候选，不读取附近其他地址密码。
4. 地图建筑按距离排序后再去重，同一ID选择最近结果；随后最多反向查询4栋。house／detached／普通residential及未分类建筑不能自行变成公寓；已收录公寓不依赖供应商补分类。50个地图要素达到上限时保留truncated，不能据此断言附近没有公寓。

卡片、排序、阅读锁、密码权限、贡献入口和反馈没有增加页面或按钮。仅当前卡读密码的规则不变；没有新增API字段、迁移、依赖或原生模块。

## 实际覆盖矩阵

测试复用2026-10-30已许可ODbL轮廓；所有观测点由几何或TEST形状生成，不是司机GPS。数据许可和地址依据见[公开数据说明](../../data/public-apartments/README.md)。

| 范围 | 实际检查与限制 |
|---|---|
| 原6处公寓 | 6个目录地址点均可发现；One Santa Fe、Del Mar、Woodside、Tower48有建筑轮廓，Colony与Park La Brea主地址仍仅地址点 |
| 4处有建筑样本 | 各从轮廓外约140–150米的合成位置能发现，不要求进入建筑／G1G2／停稳 |
| Woodside | 54个真实轮廓各取合成观测，均只出现同一社区一张目录卡；搜索末端楼栋仍匹配2547；不同门牌不误绑定 |
| 独立门牌 | TEST父社区与不同门牌子地址同时保留；社区范围内的地图建筑不能在地址核对前被吞掉 |
| 大型社区距离 | 用代表点距600米、边界／轮廓在观测处的明确TEST形状验证搜索；不把它说成Woodside实测距离 |
| 200米边缘／失效 | TEST199.8米保留、200.2米不入卡、按距离排序；withdrawn地址不出现 |
| 来源与几何 | 有效几何可补代表点不足；过期、未来、未核对、自交边界不扩范围；未来建筑核对时间也不能生效 |
| 分类负例 | 合成Tilequery的house／detached不出公寓，50个负例仍标截断；这不是供应商真实house现场结果 |
| 新6个研究地址 | 仅有公开邮政事实；无新坐标／边界，自动检查未进运行目录 |

实际执行79组生产服务／真实PostGIS场景，其中包括54个Woodside轮廓观测；不是79处新公寓、79次HTTP或现场通过。代码：[覆盖回归](../../scripts/d1/verify-nearby-coverage.ts)。

## 验证过程与结果

- 修正前，附近补充单元用例中独立地址、社区去重和未明确地址3项失败，证实核对地址前空间隐藏会吞候选；修正后全部通过。
- 初版测试假设Woodside最远屋顶距代表点超过250米，实际数据不支持，已去掉该假设。600米长社区缺口使用TEST形状；公开样本不改造来凑通过。
- 新边界查询使旧搜索合成点与真实Del Mar轮廓落在同一范围，正确产生歧义。将合成测试点移到独立测试区域，保留多地址歧义保护；未缩减生产范围来适配旧断言。
- PostGIS测试参数曾缺少明确double类型，新增UUID夹具也曾触发类型推断错误；均已修正后重跑，没有绕过失败项。
- `./scripts/dev check`：215测试／41文件、lint、workspace及脚本类型、API／worker构建通过。
- `./scripts/dev verify:library-api`：291项真实HTTP／数据库回归，另有地址匹配8组、附近覆盖79组、来源管理及合成KMS网关／真实PG隔离回滚场景；不混加为HTTP总数。

新代码在生产编译后的服务上以受限测试角色执行；一次性数据库由既有防护runner创建和清理。没有修改本机唯一真实账号资格，没有向D0持久资料或Supabase写入测试公寓／密码；没有调用真实Mapbox、AWS、DNS或计费操作。

## 代价与后续出口

反向查询上限仍为4次，受现有每账号25秒及全局速率限制；与旧逻辑相比，在已有社区里也可能产生有界反向查询，以避免漏独立门牌。Mapbox恢复后还须实测命中率和成本，不把返回的建议地址当作已验证门牌。临时结果不落库。

本批没有改动移动页面／UI或导航，不重复要求已验收手势，也不把JS／服务测试写成新原生或iPhone现场通过。当前无需用户真机补验；此前Mapbox401限制本批未做实时探测，合法新增几何、真实供应商覆盖、Woodside入口／密码适用范围与获授权真实截图仍待。云部署继续按用户决定暂缓；不启动A4或提前宣告D1完成。

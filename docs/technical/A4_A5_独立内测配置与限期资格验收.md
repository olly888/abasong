## 限期内测资格命令

新增内部 `PilotAccessCommand`，没有HTTP控制器或司机端管理入口。复用既有capabilities/audit表，无新增迁移。操作者须真实验签、有效会话、MFA `aal2` 和数据库中当前有效的 `ops.user_manage`；`ops.review`不足以授权。不能管理本人资格，UUID统一规范避免大小写绕过。

只成对授予 `access.read` / `access.contribute`；要求目标已激活且有资料，明确填写未来不超过七天的绝对到期时间。七天是此受控工具的上限，不是产品商业资格规则；通常按实际内测时段更短设置。已有未撤销/未到期（含预定生效）同类资格时拒绝重复授权。操作号幂等和用户事务锁避免并发重复；相同号不得改变目标、期限、原因或操作者。过期后重放不会续期。

当前CLI仅隔离D0，默认dry-run；令牌文件须本人所有、0600、非软链接且有大小限制，同一文件描述符核验并读取。不要把真实令牌放命令行或聊天。先构建服务端：

```sh
./scripts/dev build
./scripts/dev exec tsx scripts/d1/pilot-access.ts --environment d0 --token-file /private/tmp/abasong-operator.jwt --action grant --user-id DRIVER_UUID --operation-id NEW_GRANT_UUID --valid-until ISO_UTC_TIME --reason invited_pilot
```

核对dry-run后才给同一命令增加 `--apply`。提前终止时使用新的操作号并引用该次grant操作号：

```sh
./scripts/dev exec tsx scripts/d1/pilot-access.ts --environment d0 --token-file /private/tmp/abasong-operator.jwt --action revoke --user-id DRIVER_UUID --operation-id NEW_REVOKE_UUID --grant-operation-id ORIGINAL_GRANT_UUID --reason pilot_completed
```

另一撤销原因是 `access_removed`。只处理这次授权的两条资格，不改其他授权；账号已被暂停时仍可撤销。到期由业务请求实时检查，不依赖清理作业。审计只记录操作/目标UUID、动作、原因与期限，无密码/电话/GPS正文。输出仅applied/replayed/count/期限。工具不创建管理员，也不扩大普通API/worker权限；云操作仍需独立受限角色和明确目标的执行器，不能移植D0 postgres连接。

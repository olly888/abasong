## 双真实账号验收步骤

1. 本人登录账号A、B；会话仅存0700目录内0600文件，最多一小时，无refresh token、不进入浏览器存储或页面响应。
2. 精确资格初始化后，真实HTTPS执行A贡献、B读取及反馈、A纠正；相同幂等键重复不重复发布，B不能修改A来源。
3. 同一真实任务角色/KMS下验证私存读写、跨账号404、截图批次及候选加解密；只使用新生成的TEST合成值，保留前导零与符号，不使用真实门禁密码或快递截图。
4. 核对数据库中的实际KMS格式、范围和审计；限期资格撤销后，新请求必须拒绝读取。受控清理本批合成记录，保留公开地址与必要审计。

`verify-business-live.ts` 只调用固定HTTPS API，不签测试JWT、不连接数据库、不输出业务响应正文。其合成候选不能作为真实截图OCR质量证据。

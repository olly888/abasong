# A4 内测镜像扫描与运行限制

2026-11-03。首次实际 ECR 基础扫描：API 和 worker 均 `COMPLETE`，各 0 Critical、5 High、5 Medium、2 Low。**这不是零漏洞镜像。** 当前稳定版基础系统尚无这些 High 的修复；本轮不切换未锁定的 Debian unstable 或下载自编译补丁。

| High 项目 | 官方依据与条件 | 本次内测控制 |
|---|---|---|
| glibc CVE-2026-84243 | [Debian](https://security-tracker.debian.org/tracker/CVE-2026-84243)：gettext 需可控 LANGUAGE、非 C 语言环境和可放置的消息目录 | 镜像固定 LC_ALL/LANG 为 C.UTF-8、LANGUAGE 为空；云启动拒绝覆盖；HTTP 不接收环境变量或启动外部翻译程序 |
| util-linux CVE-2026-78410 / CVE-2026-53613 | [源路径问题](https://security-tracker.debian.org/tracker/CVE-2026-78410)、[目标路径问题](https://security-tracker.debian.org/tracker/CVE-2026-53613)：受限的特权 mount、fstab 和可写路径条件 | 两个运行镜像移除全部 SUID/SGID 位；任务 UID1000、Drop ALL capabilities、只读根目录；没有主机卷、块设备或用户配置的 fstab；仅私有 scratch 卷 |
| util-linux CVE-2026-53615 | [Debian](https://security-tracker.debian.org/tracker/CVE-2026-53615)：探测恶意磁盘分区及后续消费 | 服务不探测磁盘或可移动设备，不调用 blkid/mount，不映射主机块设备 |
| zlib CVE-2026-85091 | [Debian](https://security-tracker.debian.org/tracker/CVE-2026-85091)：非阻塞 gzwrite 后 gzprintf/gzvprintf 路径；版本范围讨论仍需跟踪，不声称误报 | API/worker 不调用这些文件压缩函数或外部命令；云截图流程接收已确认候选，端侧 OCR，不将上传内容交给本机原生文件压缩工具 |

这是对当前固定用途和已核对利用条件的工程缓解评估，**不表示库已修复**。限定当前 pilot 单 API/worker，复核期限为 2026-11-18 UTC；在更新系统包、改变入口/挂载/用户/语言环境或增加服务能力时重新评估。不要将这张表推广到任意 Debian/Node 镜像。

部署门槛：实际扫描必须 COMPLETE，Critical 必须为 0；High 仅可匹配本页五个已核对 CVE 及确切包版本，其他/缺失明细/过期全部拒绝。`scripts/cloud/image-scan.ts` 不提供命令行跳过开关。镜像实际运行检查另外核对无 SUID/SGID、固定语言环境、UID、只读文件系统和健康状态；Fargate 仍需使用审查过的 capabilities/卷配置。扫描计数不会被改写成零。

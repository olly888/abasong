# B5-01 本人资料、配送经验、自愿联系方式与我的

2026-11-06，洛杉矶。分支 `codex/b5-01-self-profile`，依赖 R4-13 / PR101。只在本地实施和验收；不迁移云库、不发送真实短信或消息、不授予真实账号资格。双端最终交互、清理和最新提交 CI 以本报告末尾及执行证据为准。

## 产品及页面对齐

依据[我的补充](../product/Abasong_V3.2_我的与团队资料补充.md)、[V3.2设计](../design/Abasong_设计系统_V3.2_升级方案.md)和[认可原型 account.js](../../design/abasong-independent-v1/v12.1-experience/account.js)。

- U01：整块身份区进入个人资料；紧凑接活开关在身份下、蓝色“共享门禁码”上；白色分组保留我的公寓/我的发布/我的报名，底部设置。没有重复顶栏设置、常联系或资格说明占据主操作。我的团队和邀请司机按 B5-02/05 接通，当前普通页面隐藏未实现操作，不放空按钮。
- U02：显示名、可选简介；接配送/代表DSP可兼选、也可均不选；接配送时显示快递公司多选及其他公司、最多5个熟悉区域、可选车型。经验始终标明本人填写，不与认证、代表权或资格绑定；取消用途不删除过往经验。
- 电话/微信选填且只由本人接口读取，不从 Supabase Auth 手机号预填，不放进 Profile 公共DTO。会话“更多→我的联系方式”仅供本人查看/复制，由用户自行决定是否提供；没有自动发送、号码搜索、通讯录或联系人名单。
- U03复用现有单次时段；从关闭开关进入时只开启草稿，保存才生效；取消、失败及冲突不提前生效。我的关闭使用最小版本化请求，未来时间明确，到期关闭显示。取消接配送用途且有有效声明时，明确选择保留时段或一起关闭；一起关闭与资料更新在同一事务中校验版本。
- 草稿仅本会话内存保存，按账号隔离；退出登录清除。离开编辑可继续、保留草稿返回、放弃；恢复时若服务端版本变化先要求明确重读。后台/离开会取消旧请求，迟到结果不覆盖新页面。

## 契约、数据库及权限

`GET /v1/me/profile` 新增本人资料；既有目标 `PATCH /v1/me/profile` 正式接通。完整白名单包括 `expected_version`，修改需 Idempotency-Key；重复同意图读取当前本人状态，不重放已删除的旧联系方式；不同内容使用同编号拒绝。`close_availability_expected_version` 仅显式同时关闭时提交，任何版本不符整体回滚。保存不更改 capabilities、认证经验、团队代表权、报名或会话。

公共 Profile 只增可选 `familiar_regions`（id/label），没有电话、微信、用途或私有元数据；司机详情显示声明的熟悉区域，不是实时位置。本人 Profile 单独返回版本、用途、区域ID及 PrivateContact。生成源、OpenAPI与TypeScript一起更新。

增量0018/0019：新增 `self_profiles` 一张表，联系方式使用现有 EnvelopeCrypto（本地/KMS）加密；仅 sensitive 角色且 actor_id 匹配可读写。profiles 仅授必要本人字段更新；availability 仅为显式关闭授受限列更新，均受owner RLS。普通API和worker不能读取 self_profiles。无本地密钥云端回退；加密失败不得保存一半资料。审计只记录动作与对象，不含电话、微信或简介正文。D0现在19次迁移/55张表，旧迁移不回滚。

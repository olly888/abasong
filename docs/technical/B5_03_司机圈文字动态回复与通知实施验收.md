# B5-03 司机圈文字动态、回复与通知实施验收

2026-11-06，洛杉矶。基于 B5-02 的 `c7d5906`，关闭 D15/D16 的本地文字范围。产品依据为 [V3.2 司机圈补充](../product/Abasong_V3.2_司机圈定位与最小社区补充.md)和[交互原型](../../design/abasong-independent-v1/v12.1-experience/index.html?v=r3-circle&task=circle#circle)。

## 实施

- C01–C03 接入登录后的最新动态列表、文字发布和回复。正文必填，标签、声明地区和本人已发布的配送需求引用选填。发布和回复失败保留本次输入，重试沿用同一请求编号。草稿在当前账号的 App 会话内保留。本人动态也可从「我的发布」打开。
- 需求卡始终引用同一个需求 ID，每次读取摘要时核对权限和最新状态。摘要只提供配送决策需要的信息；完整仓库地址和联系方式沿用需求详情的权限。删除、不可见或屏蔽后，旧详情链接和通知无法读取对应内容。
- 回复进入「消息 → 通知」，作者回复本人动态时不新增通知。站内未读、已读和点击回到同一动态均复用现有消息链路。推送队列复核目标可见性，载荷用通用文字及对象 ID。
- 动态和回复的举报、屏蔽及本人删除从详情的「更多」操作进入。设置中的屏蔽管理仅在已有记录时出现。识别到常见门禁码格式时引导至贡献流程。该规则覆盖可识别的格式。
- 增量迁移 0021 复用现有动态和回复表，为站内通知关联回复并去重。D0 共 21 个迁移、56 张强制 RLS 表。接口服务校验所有权、会话及双向屏蔽，投递角色无正文读取权限。

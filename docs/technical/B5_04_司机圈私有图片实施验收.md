# B5-04 司机圈私有图片实施验收

2026-11-06，洛杉矶。范围为 C01、C02、C03 和 G03。按 [V3.2 图片补充](../product/Abasong_V3.2_司机圈图片发布补充.md)与[图片原型](../../design/abasong-independent-v1/v12.1-experience/index.html?v=r3-images&task=circle#circle)核对。

## 发布与阅读

- 正文必填，系统相册多选与拍照可混合追加，最多 3 张，顺序与发布前预览一致。确认前可移除或补选。取消系统选择保留本次编辑。
- 图片在点击发布后上传。任何一张失败都保留正文和全部选择，主按钮变为「重新发布」。继续使用仍有效的已上传图片。若发帖响应丢失，保留原提交内容与编号以先核对结果。
- 动态内顺序为正文、图片、关联需求、回复。单图 16:9 且最高 220 逻辑像素，多图等宽方格。大图用独立黑底层查看，支持上一张／下一张、放大、缩小、滑动和双指缩放，关闭回原页面。回复入口与契约继续仅支持文字。

## 接口与权限

| 操作 | 规则 |
|---|---|
| `PUT /v1/me/circle-media/{upload_id}` | 登录后上传单张静态图，最多 5 MiB。以账号与上传编号匹配同一次上传。同编号的不同文件被拒绝。服务端校验并解码，输出最高 2048 像素查看图与 640 像素缩略图，移除 EXIF、GPS、XMP 等元数据 |
| `POST /v1/posts` | 选填有序的 `media_ids`，最多 3 个。所有图片必须为本人、未绑定、未过期且两份处理图已就绪。帖子与图片绑定同事务，提交重试使用原幂等编号 |
| `GET /v1/posts/{post_id}/media/{media_id}/{variant}` | 每次读取都复核当前账号、帖子、图片绑定和双向屏蔽。未发布图片没有读取入口。返回处理后的 JPEG 和 `Cache-Control: private, no-store`。帖子 DTO 只有图片 ID 与尺寸 |
| 过期与删除 | 未发布图片保留 24 小时。删除动态立即拒绝新读取。Worker 只见符合清理条件的媒体元数据并持锁删除两份处理图，存储失败留待重试 |

0022 新增强制 RLS 表 `circle_media`。本机使用隔离目录；云端适配器使用北加州私有 S3 和任务角色。实际开通前需为 API 和 worker 配置同一个私有桶、封锁公网访问、按 `circle-posts/` 前缀分配最小权限，并为启用版本的桶配置非当前版本清理。正式照片与存储凭据留在受控环境，云桶和 IAM 未开通。

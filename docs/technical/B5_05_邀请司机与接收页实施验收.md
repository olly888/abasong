# B5-05 · 邀请司机与接收页实施验收

2026-11-06（洛杉矶）。依据 [V3.2 邀请方案](../product/Abasong_V3.2_邀请司机功能方案.md)与 [U15 / X02 原型](../../design/abasong-independent-v1/v12.1-experience/index.html?v=r3-invite&task=invite)。范围为本机实现和双端模拟器验收，真实分发由 B6-03 验收。

| 场景 | 结果 |
| --- | --- |
| 我的 → 邀请司机 | iOS、Android 使用同一真实「我的」组件及本机合成资料，邀请行在业务分组之后、设置之前；有团队时邀请排在团队之前。 |
| U15 视觉 | 两端核对主标题、皇家蓝主操作、两项文字次操作、通用建筑图、二维码和资料来源。复用 PageFrame、ListRow、ActionButton 及 V3.2 tokens，保留小屏滚动与系统字体。开发预览多一项「预览接收邀请页」。 |
| 系统分享 | 两端实际调起系统分享面板并取消，回到同一页，无发送成功提示；没有选择任何联系人或分享应用。Android 面板显示完整 TEST 文案及链接。 |
| 复制 | 两端复制后显示成功。iOS 模拟器剪贴板的实际文本及链接独立核对；Android 原生按钮、系统写入成功反馈已核对。复制失败可长按选择文案或重试，未强制模拟 OS 剪贴板故障。 |
| 相册 | iOS 仅点保存才提示「添加到照片图库」；拒绝后仍有分享、复制，允许后实际相册新增 PNG。Android 现代 MediaStore 保存无需请求照片读取权限，实际新增 PNG 为 1050×1269；合并清单没有 Android 13+ 读取照片、视频、音频权限。较旧 Android 系统的写入分支未实机验证。 |
| 同一地址 | 用 Vision 解码页内二维码、源海报及双端实际落盘海报；目标为同一固定本机路径，与复制和系统分享一致。 |
| X02 | iOS Safari、Android 模拟器的 WebView 浏览器均能打开。无登录、表单或假下载；显示「内测准备中」。320px 浏览器检查无横向溢出，隐私说明可展开；页面查询参数不能切换下载地址，无跨域资源。 |
| 发布隔离 | 只有开发模式＋显式本机预览＋原生设备同时满足才提供 TEST 操作。正常页面显示「内测准备中，暂未开放邀请分享」。发布导出检查读取双端 Hermes 包和资产哈希，排除本机 URL、TEST 二维码及海报。 |

使用 Expo SDK 58 的 Asset 与 MediaLibrary 保存合成 PNG；iOS 使用添加权限，Android 10+ 使用 MediaStore。系统分享和剪贴板均为现有原生能力。接收页是可独立部署的静态文件，未新增 API、数据库迁移、账号资格或邀请归因。未配置域名、商店或内测下载、App Links / Universal Links，也未验证真实微信或真机。

复跑本机接收页：从仓库运行 `python3 -m http.server 8795 --bind 127.0.0.1 --directory deploy/invitation`。Android 模拟器增加 `adb reverse tcp:8795 tcp:8795`，两端开发包打开 `abasong://invite-lab` 后点「邀请司机」。模拟器预览使用合成资料，无需登录。正式导出复跑命令见 [CI](../../.github/workflows/ci.yml)。工程检查覆盖 lint、类型、504 个测试及构建。

## DTL-05 复核

- App 邀请海报插图按内容宽度等比缩放，窄屏或字体放大时次级操作改为纵向排列。
- 接收页明确说明可以仅自己保存常跑公寓的资料，也可以共享给同行。未开放分发时显示「内测准备中」。

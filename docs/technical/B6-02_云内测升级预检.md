- **私有图片。** 在 `us-west-1` 准备专用私有 S3 桶，启用 Block Public Access、桶主强制所有权和 TLS，使用现有客户端要求的 SSE-S3。API 任务角色只对 `circle-posts/*` 取图和写图，worker 任务角色只在同前缀删除。API 与 worker 的 `CIRCLE_MEDIA_BUCKET` 绑定同一桶。若启用版本控制，配套清除旧版本与删除标记。部署后用双账号和合成图片验证上传、鉴权读取、屏蔽、删除及过期清理。若需回退，保留现有桶和对象，先恢复 API 和 worker 的前一任务版本，再按合成对象清单核对清理。[S3 公共访问控制](https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-control-block-public-access.html) · [S3 生命周期](https://docs.aws.amazon.com/AmazonS3/latest/userguide/intro-lifecycle-rules.html)
- **远程推送。** 单独生成带推送能力的候选包。现有本机构建会剔除 Expo 项目配置，且签名包无 APNs entitlement。推送候选需要受控 Expo 项目 ID、iOS 的 APNs 凭据和匹配签名，Android 另需 FCM v1 凭据及匹配的应用配置。开 worker 的 `PUSH_PROVIDER=expo` 前重新核对可投递设备和积压，只用已授权的测试设备和合成事件。验收记录需包含系统送达、正确跳转、锁屏无消息正文、退出或换号后停止旧账号推送。回退时恢复 worker 的关闭配置。[Expo SDK 58 通知](https://docs.expo.dev/versions/v58.0.0/sdk/notifications/) · [Expo 推送设置](https://docs.expo.dev/push-notifications/push-notifications-setup/)
- **邀请分发。** iPhone 先备 Apple Developer Program 团队、App Store Connect 对应应用及分发签名，冻结源码后生成新的构建号。首批外部测试走 TestFlight 具名邀请并经 TestFlight App Review。发出安装邀请前，用预定测试号码确认短信送达和应用资格。现有试用接收人规则以 Twilio 项目配置为准。接收页再绑定第一方 HTTPS 地址和核实有效的安装入口，复测二维码、安装后登录及邀请收回。Android 单独核对签名产物及真机安装。[Apple 账号说明](https://developer.apple.com/help/account/basics/about-your-developer-account) · [TestFlight](https://developer.apple.com/testflight/) · [Twilio Verify 试用限制](https://www.twilio.com/docs/verify/quickstarts)
- **OCR 真实版式。** 获授权且已脱敏的截图仍为 0 张。收到首批样本后按 B6-01 的编号、真值与设备记录分别统计，单列现场和真实样本结果。[B6-01 执行包](../usability/B6-01_可用性与现场测试执行包.md)

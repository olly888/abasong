# B6-03 私有图片 S3 变更方案

2026-11-07（洛杉矶）。范围为北加州 `us-west-1` 的 `pilot-dev` 司机圈图片。部署前已核对数据库迁移 0022 和现有 API 图片接口，DevWest 动态、图片元数据和屏蔽关系各为 0。[分发预检](B6-02_云内测升级预检.md#b6-03-分发预检)

## 已批准的变更范围

| 层 | 变更范围 |
| --- | --- |
| 存储 | 单独的 `abasong-pilot-dev-circle-media` 栈，创建一个通用 S3 桶和一条强制 HTTPS 的桶策略。启用四项 Block Public Access、BucketOwnerEnforced 和 SSE-S3，桶采用 Retain。内测阶段桶保持未启用版本控制，现有删除流程可移除对象，发布中的图片由业务状态决定保留期限。 |
| API 任务角色 | 仅对该桶 `circle-posts/*` 授予 `s3:PutObject`、`s3:GetObject`。上传图由 API 解码和重编码后保存，客户端通过现有鉴权接口读图。 |
| Worker 任务角色 | 仅对同一前缀授予 `s3:DeleteObject`，清理过期草稿和已删除帖子的两种图。部署身份与 ECS 执行角色维持各自用途，运行任务使用自己的 AWS 角色。 |
| ECS 服务 | 将同一个桶名作为 `CIRCLE_MEDIA_BUCKET` 绑定到现有 API 与 worker，沿用当前镜像摘要、网络、密钥和任务数。将这个环境变量变更单独与现有部署快照比较，变更集只允许两份任务定义和对应服务。 |

新存储栈由单独授权的临时管理员会话应用。已有运行栈由项目部署角色通过审查后的 CloudFormation 变更集更新。运行模板用可选参数 `CircleMediaBucketName` 将同一个私有桶传给两个任务，空值表示关闭云端图片存储。后续镜像更新可保留已部署参数。[已应用的存储模板](../../deploy/pilot-dev/circle-media.json) · [运行模板](../../deploy/pilot-dev/runtime.json) · [部署角色限制](../../scripts/cloud/runtime-identity.ts) · [CloudFormation 桶属性](https://docs.aws.amazon.com/AWSCloudFormation/latest/TemplateReference/aws-resource-s3-bucket.html) · [S3 公共访问控制](https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-control-block-public-access.html) · [AWS TLS 控制](https://docs.aws.amazon.com/controltower/latest/controlreference/s3-rules.html)

## 增量费用

按 AWS 北加州公开价测算，使用 5 GB·月、2 万次 PUT 类请求和 10 万次 GET 类请求作为示例。

| 项目 | 单价 | 示例月费 |
| --- | --- | --- |
| S3 Standard 存储 | 0.026 美元／GB·月 | 0.130 美元 |
| PUT 类请求 | 0.0055 美元／千次 | 0.110 美元 |
| GET 类请求 | 0.00044 美元／千次 | 0.044 美元 |
| S3 小计 | 按实际用量计费 | **约 0.30 美元／月** |

示例小计为 0.284 美元。每张上传图生成两种尺寸，重试和重复读取会增加请求量。同区域 S3 到 AWS 服务的 S3 数据传输适用 AWS 同区域规则。现有 API 对外流量和负载均衡用量另计，示例金额为测算值。[AWS S3 定价](https://aws.amazon.com/s3/pricing/) · [北加州官方价格目录](https://pricing.us-east-1.amazonaws.com/offers/v1.0/aws/AmazonS3/current/us-west-1/index.json)

## 执行与回退

1. 确认上述资源和按量费用后，核对北加州目标账号、部署身份、两服务当前任务定义及镜像摘要。保存原始模板、IAM 策略和服务基线。
2. 创建桶和 HTTPS 策略，核对公共访问关闭、所有权与加密，绑定两份最小对象权限。审阅 ECS 配置变更集后滚动更新现有服务，核对固定 HTTPS 和 worker 健康。
3. 仅用合成图片和两个已验证内测账号验证上传、鉴权读取、跨账号绑图拒绝、错帖和屏蔽访问、删帖与过期清理。核对桶内只出现对应缩略图和查看图，拒绝匿名读。验收结束清理本轮对象和元数据。
4. 健康检查或授权行为异常时，先恢复 ECS 原任务版本关闭图片入口，保留桶供核查。按本轮对象清单收尾后收回角色对象权限。桶保留策略用于避免跟随回退误删数据，最终退役另按保留对象核对。

## 执行记录

- 私有存储栈已创建。逐项核对桶所在区域、四项公共访问限制、桶所有权、默认 SSE-S3、未开启版本控制、拒绝非 TLS，以及两个任务角色的动作和对象前缀。验收前对象前缀为空。
- 运行栈的变更集仅更新两份任务定义和两个现有服务，API 与 worker 镜像摘要和原有参数逐一比对。按现有单实例配置替换任务时，HTTPS 就绪检查一度返回 503。新修订均已达到 ECS 稳定状态，`/health/live`、`/health/ready` 返回 200。CloudFormation 最终状态为 `UPDATE_COMPLETE`。两份旧任务定义因项目部署角色的注销请求被拒而保留。
- 两个已短信验证的内测账号通过 29 项图片业务 HTTP 检查。覆盖上传重放、同键换图冲突、跨账号绑图拒绝、错帖读图拒绝、匿名访问、越权删帖、屏蔽与恢复、回复拒绝附图、作者删帖后拒绝读图。缩略图和查看图分别为 640 和 2048 像素宽，均已去掉 EXIF／XMP，响应为 `private, no-store`。
- S3 中只出现两张合成图生成的四个 JPEG 对象，逐项核对 AES256 和私有缓存标头。绕过 API 直接匿名读取对象返回 HTTP 403。
- 首次清理被 worker 角色原有的全量拒绝规则拦住。角色栈只原地修正了 worker 策略，明确拒绝除本桶 `circle-posts/` 对象删除之外的操作。实际生效权限通过六项 IAM 模拟和四个运行角色的精确比对。
- 修正后，原有 worker 自动清除删帖图片和本轮提前到期的合成草稿，共四个对象。S3 前缀为空。DevWest 核对动态、图片元数据、屏蔽关系和本次幂等记录均为 0。本机测试页、两份临时登录文件和 AWS 临时管理员会话已清理。
- 本机 lint、类型、512 项测试和构建均通过。云端验收使用真实 HTTPS API 和合成图片。iPhone 与 Android 的云端发图界面尚待单独核对。

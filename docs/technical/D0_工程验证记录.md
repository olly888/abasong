# Abasong V12.1 · D0 工程验证记录

日期：2026-10-29（America/Los_Angeles）。本次范围为工程启动。正式业务页面、认证、公寓密码与临时支援闭环尚未实现。

## 已落地

- 单仓：Expo/React Native 移动端、NestJS API、独立 worker、契约类型包、V3 设计令牌包。
- 使用已有 Node24 LTS，固定 pnpm 和直接依赖，保留 pnpm-lock 与 iOS 原生依赖锁。
- Expo Router 三导航应用壳；原生 Mapbox 模块接入。无 token 时显示地图不可用空状态，不伪造地图或业务数据。
- OpenAPI 全量生成 TypeScript 类型；设计令牌从源 JSON 生成并解析语义引用。
- API live/ready 健康检查、worker 独立受限账号连接、优雅退出。
- 隔离 PostGIS 数据库；随机本地凭据；API/worker 非管理员账号；数据库校验拒绝远程、未知数据库和连接参数覆盖。
- Git 开发分支 `codex/d0-engineering`、项目规则、启动说明、依赖记录、GitHub Actions 检查定义。

## 可复现命令

见根 [README](../../README.md)。本机详细日志在 `/private/tmp/abasong-d0-*`，运行截图在忽略的 `artifacts/d0/`；它们不是长期归档或生产审计存储。可执行脚本和本记录纳入版本管理。

iOS 本次 Debug 编译命令：

```sh
xcodebuild -workspace apps/mobile/ios/Abasong.xcworkspace \
  -scheme Abasong -configuration Debug -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,id=592DEF35-ADBB-4543-8E90-C7990AF00F91' \
  -derivedDataPath /private/tmp/abasong-d0-derived CODE_SIGNING_ALLOWED=NO build
```

用户已亲自完成 Xcode 许可处理。系统模拟器启动报告过 Data Migration Failed，后续应用安装、Release冷启动与页面渲染成功。iPhone Duo为双屏，默认截图可能取到黑色副屏，最终明确选择 --display=1，见[冷启动证据](evidence/D0_iOS_首页冷启动.png)。截图右侧时钟/网络图形为模拟器系统覆盖层，不是产品元素。此证据只验证D0壳启动，不是V12.1完整业务或真机验收。

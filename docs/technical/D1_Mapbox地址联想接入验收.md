日期：2026-10-31；分支 `codex/d1-iphone-validation`。产品依据：[ADD-14](../product/Abasong_V12.1_地址自动联想与公寓匹配补充.md)。覆盖此前[搜索修正方案](D1_地址搜索修正与联想接入方案.md)中的“外部联想尚未接入”；保留该记录的历史验收范围。

## 实现

- 已有契约 POST `/v1/search/addresses/suggest`、`retrieve` 接入 NestJS，真实登录身份与实时账号状态校验，JSON严格输入，所有响应 no-store。DTO明确标题、副标题、结构化地址、供应商归属、匹配状态和最小公寓候选；不会返回密码或联系方式。
- Mapbox 固定官方 HTTPS 主机，禁重定向，6秒超时，响应上限512KiB，字段白名单及经纬度校验，错误统一处理不输出请求/令牌。美国范围＋公开洛杉矶城市中心排序偏好；不发送设备精确GPS。
- 客户端会话 UUID 与服务端供应商会话 UUID 分开，绑定用户。只允许取回本用户本会话已返回的供应商ID；同ID重复取回复用内存承诺，其他ID或过期会话409。服务端150秒/45次上限，客户端140秒/40次轮换；容量上限1000会话，按时清除。没有持久搜索记录。
- 开发环境单进程节流8次/秒全局＋每账号60次/分钟，上游429保留；多实例部署前须集中限流/会话存储设计，当前不宣称生产分布式可用。
- 原生搜索并行读取目录与供应商候选，300ms防抖、取消/版本保护、部分失败可用、去重、点选取坐标、选择后收键盘。外部未匹配地址通过内存随机键回首页，蓝色菱形目的地与GPS圆点分开。
- 公寓匹配复用真实对象授权事务：完整规范化地址＋250米核对，active目录，最多读取101条，超过100条或匹配超过20条安全降为未匹配。一个实体直接选中；多个实体让用户确认；不推断公寓类型/最近公寓/进入资格。
- 已配置忽略文件中的 `MAPBOX_SEARCH_TOKEN`，沿用用户已有公开token，不写入版本库。未新增依赖、原生模块、系统权限、DDL、云迁移或真实资格授权。iPhone原授权局域网API3002已刷新用于本批验收；用户确认完成后已关闭专用API3002、桥接与真机Metro8082，模拟器服务保留。

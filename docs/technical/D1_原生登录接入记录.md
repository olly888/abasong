# D1 原生登录接入记录

更新：2026-10-30；分支：codex/d1-apartment。此批是账号入口与安全会话基础，不代表 D1 公寓业务闭环或真实短信验收完成。

## 实现范围

- 保留首页、司机圈、我的三导航；登录流程位于导航之外，通过“我的”进入。
- 手机号地区选择、号码规范化与校验、验证码输入/重新发送、首次显示名、真实账号状态及本机退出。
- Supabase Auth SDK 验证短信；没有固定验证码、模拟登录用户或客户端授予资格。
- 原生会话使用 Expo SecureStore；读取/写入/删除失败时显示错误，不回退明文。Web 会话只保存在内存中，刷新后不保留。
- 账号 API 使用契约类型与 Bearer，超时10秒，401最多刷新一次且要求刷新前后用户一致；正式构建要求 HTTPS API。
- 登录变化与退出使旧账号请求失效；失败不显示旧资料。回到前台重新查询当前资格。资料提交对同一意图复用幂等键。
- 验证码只存在页面内存，切换号码/失败时清除；完整手机号不显示在验证码页；不记录凭据、手机号或验证码。
- 重发60秒是界面节流，不能替代短信供应商及 Supabase 的限流与防滥用策略。

## 配置

项目 URL 与公开 publishable key 保存在忽略的 apps/mobile/.env.local，文件权限600。服务端 issuer/audience/算法配置在忽略的根 .env。移动端不得放 service_role、secret key、数据库连接串。示例字段见 apps/mobile/.env.example。

2026-10-30已切换到用户新建的AbasongDevWest，实际区域us-west-1（北加州），状态ACTIVE_HEALTHY，ES256 JWKS与公开Auth设置读取正常；Phone仍关闭。旧美东项目保留。只切换本地公开配置和服务端issuer，未应用云端SQL、更改Auth设置或迁移旧项目数据。新旧项目storage key不同，旧会话不会作为新项目登录凭据使用。

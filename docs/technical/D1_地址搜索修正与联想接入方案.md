# D1 地址搜索修正与联想接入方案

2026-10-31。用户在实体 iPhone 搜索 `2445 E Del Mar Blvd, Pasadena` 没有结果，故上一批门牌/尺度真机补验未完成；不能把此反馈记为高亮或比例尺通过。

## 已确认的问题与修复

旧原生页面只调用 `/v1/apartments` 检索自有公寓目录，需按搜索按钮。服务端将名称、街道、城市用空格连接，再用整段连续子串比较；用户输入地址里的逗号并不存在于连接后的字段中。因此样本已经收录也搜不到，不是 Mapbox 地图没有此地址，也不是用户操作错误。

本地只读复现：同一完整公开地址旧查询返回0条，新查询返回 Del Mar Apartments。未读取密码、用户位置或更改样本数据。

本批实现：

- 自有地址按字词匹配，兼容大小写、英文/中文逗号、多空格及跨名称/街道/城市/州/邮编输入；末词支持前缀，完整数字词不混淆相邻门牌。不是拼写纠错或所有道路缩写等价算法。
- 输入至少2字符，停止输入300毫秒后自动显示已收录候选；修改/清空输入中止旧请求，迟到结果不覆盖新输入。键盘搜索仍可触发重试。
- 点选候选沿原有路由打开该公寓，地图高亮、查看资格与共享密码接口规则不变。
- SQL仍参数化、active过滤、最多20项；自有检索不返回密码。没有增加依赖、DDL、云配置或真实账号资格。

## Mapbox 能力实测

官方 [Search Box API](https://docs.mapbox.com/api/search/search-box/) 提供交互联想：`/suggest` 返回名称/地址候选，用户点选后 `/retrieve` 返回位置坐标。同一次输入/点选使用同一 `session_token`；搜索会话独立于地图显示计量。

使用已有公开 token，仅将公开地址片段 `2445 E Del`、完整公开地址及 Pasadena 公共城市中心用于有界探测。两次联想均HTTP200、均返回5个候选；一次取详情HTTP200且包含Point。返回归属字段存在。没有发送手机GPS、保存供应商坐标或回显token；首次沙箱网络不可达后在已授权开发范围执行成功。现有账号能调用，当前不需要新注册账号或更换地图SDK。

**接口可调用不等于已集成到产品。** `/v1/search/addresses/suggest` 和 `/retrieve` 已在原契约设计中，但当前API/原生页面仍未接通这些路径；本批上线到本机的输入候选来自Abasong已有公寓。不得把公开供应商探测当成原生全地址联想验收。

## 下一批实现顺序

1. 按既有契约接入认证后的服务端 Mapbox suggest/retrieve；限制输入/频率、超时、响应大小和固定供应商域名，保留归属信息。输入防抖与取消旧结果沿用本批行为，处理清空/离开/选中后的会话生命周期。
2. 一个搜索列表显示公寓名称或门牌街道、第二行完整城市/州/邮编；自有公寓与外部结果去重，优先明确地址匹配。首发以美国地址为范围、洛杉矶为初始区域偏好，不把结果限制死在洛杉矶边界。
3. 选择已收录公寓后直接显示该公寓卡片；选择外部地址后先定位，再查询是否对应已收录公寓。不能以“最近一个公寓”自动替换目的地；多候选要求选择。
4. 外部地址尚未建立公寓关联时显示地址及当前资料状态；不能假称已经确认是公寓，也不能把缺少关联说成“密码错误”。外部地址坐标不能移动用户蓝点；只移动相机和目的地。
5. Search Box 返回仅限临时用途，按官方[限制说明](https://docs.mapbox.com/api/search/search-box/#search-box-api-restrictions-and-limits)与既有 `use_mode: temporary` 契约处理；不自动永久写入公寓库。共享密码仍来自司机贡献。

完整接入需要更新服务实现、归属/错误契约细节、临时目的地状态、原型及双端验收；这不是增加一个输入框就完成。暂不增加导航规划、历史搜索存储或账号购买。

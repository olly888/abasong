# D1 建筑门牌与地图尺度验收

2026-10-31；分支 `codex/d1-iphone-validation`。需求见 [ADD-13](../product/Abasong_V12.1_建筑门牌与地图尺度补充.md)，自动识别继续遵循 [ADD-10](../product/Abasong_V12.1_首页自动查码场景补充.md)。本批不宣布 D1 整体或现场识别通过。

## 本批交付

- 明确使用 Mapbox `light-v11`，从既有 `composite` 源的 `housenum_label` 读取 `house_num`。普通门牌从 zoom16 起显示；没有供应商数据时留空，不逐栋反向地理编码、不猜号码。
- 选中公寓沿已核对的实际轮廓以品牌蓝填充/描边，保留中庭空洞；内部标注点显示加粗门牌。去掉覆盖门牌的选中圆点；仅选中轮廓内同值普通门牌让位给强调标注，社区其他号码及邻栋继续显示。
- 原生动态英尺/英里比例尺放在左上模式栏下。首次定位/回位 zoom17，找活/找人概览 zoom14；主动选择按实际可视区容纳建筑，最大 zoom18，无轮廓退回18。用户手动最大20；自动识别不重置相机，触摸地图后不因几何迟到再次拉回。
- 原型同步普通门牌、建筑内强调门牌和比例尺位置；原型仍是合成 SVG，比例尺数值仅为版式示意。原生比例尺由 SDK 按实际视口更新。
- 未增加依赖、系统权限、业务接口、数据库迁移或生产配置。未向实体 iPhone 注入模拟坐标、未录入真实密码或开启默认自动认定。

## Mapbox 文档与公开样本核对

已读取官方 [Streets v8 数据字典](https://docs.mapbox.com/data/tilesets/reference/mapbox-streets-v8/#housenum_label)、[原生图层指南](https://docs.mapbox.com/ios/maps/guides/styles/work-with-layers/)和 [within 表达式](https://docs.mapbox.com/style-spec/reference/expressions/#within)。已安装 rnmapbox10.3.16 支持 `existing` VectorSource 和原生比例尺属性。

对实际 `light-v11` 样式的一次定向检查返回200：源含 Streets v8，样式本身的 `housenum_label` 图层数为0。因此本批增加符号层；单纯放大旧样式不能补齐这一层。

可复验脚本：[probe-map-presentation.mjs](../../scripts/d1/probe-map-presentation.mjs)。每次最多1次样式请求与6次 Tilequery；读取本机公开 token，不输出 token、坐标或完整响应，不保存供应商几何。使用仓库已有公开样本轮廓首顶点作为探测锚点，半径100米、limit50；此点不是核实的入口。

## 回归发现及修复

首轮159项业务接口检查在“刚反馈有用后立即重新读取”失败。只读诊断显示数据库时钟比 API 主机约快13毫秒；此前查询使用主机 `new Date()`，刚写入的数据库时间可能被误判为未来反馈。

读取排序现以 PostgreSQL `statement_timestamp()` 同源计算时点与有效窗口，并保留字符串中的微秒精度。规则仍为有效有用优先、同组贡献时间倒序；未改变资格、适用范围或贡献审核策略。增加真实 PostgreSQL 微秒前后边界两例，验证不是将所有未来反馈放行。

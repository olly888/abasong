## 实现

1. 新增18个设计操作及23个schemas，源生成器模块与OpenAPI/TypeScript一起更新（82路径/107操作/123 schemas）。全部新操作标记planned；权限、版本、mode锁、确认失效、原图处理与双阶段结果见[契约](V12.1_截图导入接口契约.md)。没有假装服务端批次/迁移已实现。
2. 我的→贡献公寓密码选择截图或快速填写；手动添加页有“从截图添加”，私人库入口可选择截图私存。原生页选择/追加/移除多张图，支持系统取消，不请求全相册授权或相机/麦克风。
3. 新增本地Expo模块AbasongOcr：iOS Vision，Android固定16.0.1随包Latin ML Kit。原图只从App缓存解码，拒绝远端/任意目录、超字节/超像素；逐张识别且限定输出行数。无云端OCR请求/训练/真实快递图片上传。
4. 保守提取明确标记的通行码和局部地址；前导零、大小写、符号原样保留。缺字段或多列不能强配；完整街道/城市/州且自有库唯一才预选，其余由用户检索/核对。门别缺失写“门别未注明”，不猜大门或行人门。
5. 确认页可编辑地址/密码/门别、选择公寓和范围、移除、勾选需提交项；来源核对后才能提交。编辑/改变选择或范围会清除确认；初次提交后固定范围。
6. 当前会话复用现有真实私人库→记录→共享接口，稳定幂等键；共享失败保留privateId及实际返回版本，重试不重复私存，服务端仍重新判资格。结果区分私存、待审核、同码、可展示及失败；未选择项标未提交并可继续确认。
7. 选图期间系统inactive/账号资格重查不会卸载本次会话，页面被遮盖；切账号/退出/资格错误清会话。图片复制到专用缓存，复制完成才删选择器临时副本；关页清理，进程异常残留下次打开按24小时开发值清理。照片库原图不删除。

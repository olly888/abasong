# D1 截图简化流程双端验收

2026-10-31（America/Los_Angeles），分支 `codex/d1-import-dual-qa`，承接 `e9a5017`。本批依据 ADD-09 和[简洁交互基线](../design/D1_截图添加简洁交互调整.md)补 Android 停止、续跑、异常恢复及双端页面核对。完整 D1、真实共享资格与真机现场门槛没有因此关闭。

## 本批修正

实际 Android 验收中，前后台账号重查遇到临时连接错误，导入页被卸载，未保存结果及照片丢失。现在同账号的连接超时、限流或服务端临时错误只遮住页面，保留当前结果、修改、照片和范围；重试成功后回到原页。遮罩期间禁止触控并从无障碍树隐藏背后内容。退出、切账号和明确的账号/权限失败仍清理会话，服务端授权规则不变。未保存工作仍不承诺跨 App 进程结束或开发热更新恢复。

导入结果页移除每行的选择、编辑控件，只显示资料和实际提交状态；需要补充时进入“继续确认未完成资料”。确认页继续保留选择和编辑。连接错误页文案改为“暂时无法连接”。没有新增主菜单、API、DDL、依赖或原生权限。

## 样本与环境

使用已有 iPhone18Pro / iOS27 和 Android17 / API37 Debug 模拟器、既有 Vision/ML Kit 原生构建及本地 API。全为自行生成的 TEST 图片和合成地址，没有真实快递截图、收件人、门禁密码或现场 GPS。相册选择由真实系统选择器完成；少量镜像无法可靠输入的系统操作由用户补做，结果另行观察，不把发出点击当作通过。

像素复核纠正：10 张密集 TEST PNG 的实际文件为 **3600×5200（1872 万像素）**，单图约 1.8MB、合计约 18MB；生成脚本的绘图尺寸是 1800×2600，Retina 输出放大了两倍。此前中断报告将绘图尺寸当成了实际图片尺寸，以本次文件头复核为准。仍在当前单图 2400 万像素、10MB、总 50MB 限额内；没有测到限额边缘，不据此声称低内存或耗电验收。

## 实际验收矩阵

| 场景 | 观察与结论 |
|---|---|
| Android 十图停止 | 零条完成时停止返回已选十图；另一轮实际处理中停止，保留一条结果和继续入口，剩余图片未继续发布 |
| Android 修改后续跑 | 将完成的第一条改为 TEST 编辑标记；仅续跑其余九图，最终十条，修改保留。后续 iOS 从 API 恢复并读取十个不同 TEST 值，未出现完成项重复 |
| Android 同账号连接错误 | 暂停本地 API 并切后台/前台触发重查；出现错误遮罩。恢复服务并重试后仍在原编辑页，TEST 修改、原照片及剩余九图可继续；没有发短信或重新登录 |
| Android 保存超时 | 账号已就绪时暂停本地 API，更新进度出现“连接超时，请重试”，原十条未清空；恢复后正常保存，错误消失 |
| Android App 强停恢复 | 主动保存后实际 force-stop / 重启 / 打开导入，再继续十条；编辑字段及 private_only 保真，选择和声明未自动复用 |
| Android 单图损坏隔离 | 对新选两图中一个 TEST 缓存副本备份后写入无效图像；实际 OCR 显示该图失败，另一图仍产生一条结果。恢复缓存副本并只重试失败图，最终两条不同结果，无重复 |
| Android 范围、确认与结果 | 私存选中一条；显式改共享后未匹配项取消选择，提示共享资格待核验，没有偷偷降级私存。改回私存、选择并完成一次来源核对，按钮启用；实际保存一条 TEST 私人记录，结果页显示已保存/未提交及继续入口。简化后的结果页无选择/编辑，完成正常退出 |
| Android 清理 | 通过本人原生页面正常软移除本次 TEST 私人记录及对应空公寓条目，列表恢复为空；没有删除真实资料或更改共享贡献 |
| iOS 跨端恢复 | 实际恢复 Android 保存的十条；编辑 TEST 值、其余九个不同值、private_only 以及初始未选择状态均核对 |
| iOS 同账号连接错误 | 对十条结果选中一条并做来源确认，暂停本地 API，切后台再前台；错误界面及无障碍树均无背后密码/编辑控件。重试后十条、已选一条、原确认状态和范围保留，没有自动提交 |
| iOS 多图实际识别与菜单 | 用户在系统选择器补选后观察到两条结果；更多→继续添加及后续第三图识别可用，原两条保留。历史十图停止/续跑及 picker 取消证据见前批记录，本批不把历史证据标成重做 |
| iOS 坏图与锁定批次续跑 | 既有三图结果后追加两张 TEST 图；临时损坏 TEST 缓存副本，新增一图失败、另一图继续完成，原三条未消失。坏图再次重试仍失败，完成结果未重复。私存一条完成资料后，结果页只读并显示继续入口；恢复缓存后，继续仅带入一张失败图，新进度识别成功为一条、未选择且保留私存范围，没有带入旧结果。新进度单独确认后完成保存，完成返回首页无 GO_BACK 错误 |
| Android 锁定批次续跑 | 另一轮两图中一图失败、一图完成；只保存完成项。恢复 TEST 缓存后，继续入口只带入一张图，新进度识别成功为一条，来源确认未复用。iOS 从实际 API 读取本人库，仅一条已保存结果，无续跑造成的重复提交；随后正常清理 |
| iOS 最终结果与清理 | 结果页实际观察不到行选择/编辑；新旧进度各保存一条 TEST 记录，正常本人页面逐条移除，私人库恢复为空。两次“完成/离开”出口分别观察，不使用旧导航单元测试替代本次操作 |

本地 API 以有限时间窗口暂停，带自动恢复并在重试前检查 ready=200；这是连接不可用/超时测试，不是移动运营商弱信号、丢包和带宽基准。损坏测试仅针对本轮 TEST 缓存副本，已恢复；相册原图未改。主动保存的 TEST 草稿及已完成提交结果仍按既有有限 TTL 处理，不声称立即物理删除。

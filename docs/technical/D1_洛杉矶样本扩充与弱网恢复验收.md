## 自动匹配与查码

- 原有明确配置开关、来源许可/有效期、精确定位、最大精度、完整精度圆包含、候选截断保护继续有效。
- 新增保护：精度圆只要触及另一建筑，或落入无边界公寓地址点的精度范围，就不自动认栋。原先只数“完全包住精度圆的建筑”会漏掉相邻小建筑；现用geography距离判定可能冲突，查询半径至少覆盖精度圆，避免小半径配置漏掉竞争建筑。
- 配置版本改变时客户端重新计算停留；重复/倒序定位不积累停留。手动阅读锁定仍不能被自动结果覆盖。
- 有建筑样本、仅地址样本、真实密码覆盖是三件事。匹配结果、建筑context和受控access-records依然分接口鉴权；没有有效共享项就返回空，不借用附近公寓的码。
- 已在随机可销毁测试库验证6处公开几何+模拟观测；4处可在合成验收配置下命中，2处只给候选；Del Mar内院不命中。公开来源核对不是现场验证。
- 日常开发库默认自动认定仍关闭；没有用公开网页代替现场停留/入口精度证据来开启它。当前真实账号无access.read，原生卡片正确显示受限，不以TEST内容制造覆盖。

## 导入弱网与异常恢复

沿用上批15个已实现端侧批次操作，云端上传/OCR三操作仍planned，无新API/迁移/依赖。手机原图和未提交OCR不上传，服务端仅保存本人有限留存的加密候选。

1. 已保存编辑或模式切换的响应丢失时，保留原路径/请求体/幂等键，下一次明确保存先补完原请求，再比较版本。模式切换后的返回读取如果混入另一设备修改，报冲突、要求重新打开，不静默吸收/覆盖。
2. 来源登记/提取原有幂等保护继续保留。提交丢响应后重新读取逐项durable result和client_commit_id，补未完成阶段，不重复私存或重跑已成功共享。
3. 请求10秒超时为NETWORK_TIMEOUT，离开/切账号的取消为REQUEST_CANCELLED；预取消不发请求，取消后不刷新账号。401仅刷新一次且必须同一user，重发使用同一业务请求体/幂等键；403不自动重试，不换成私存。
4. 草稿发现失败不再静默假装没有草稿，选图页提供“重试加载草稿”。没有错误时不常驻提示。原公寓404不会阻止恢复其他行，该行取消预选并要求重新选择；401/503仍报错可重试，不伪装为公寓不存在。
5. 仅有来源/移除完全部候选的空草稿恢复后回到选图页，明确提示尚无已保存识别结果；用户实际重新选择图片后才开始新的客户端批次，旧批次按TTL保留。取消照片选择不自动创建服务器替代批次。此分支代码已通过工程检查，尚未单独完成双端原生操作验收。
6. 进程退出后，只承诺重读已落库的字段和提交结果；未保存修改、未上传的照片与OCR不能凭空恢复。跨进程完整系统杀进程/长任务/低存储仍待专项测试。

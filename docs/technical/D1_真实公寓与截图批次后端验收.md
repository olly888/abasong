# D1真实公寓与截图批次后端验收

2026-10-30，分支 `codex/d1-real-apartments-import-batches`。用户批准先推进真实公寓/自动查码闭环，同时实现截图服务端批次；公寓采用公开地址，iPhone稍后连接。本文记录本批范围，完整D1和现场真机未验收。

## 1. 真实地图与数据关联

地图仍由Mapbox渲染。真实建筑、建筑类型和门牌号可来自地图数据；设备位置来自OS，司机共享内容来自Abasong权限服务。模拟器注入位置、TEST矩形与真实底图必须分开说明，不能让用户误以为Mapbox没有真实数据。

本批在本地D0接入一个可追溯的真实公寓：One Santa Fe，300 S Santa Fe Ave, Los Angeles, CA 90012。物业官网核对名称和地址；OSM way427628872提供独立开放许可建筑轮廓，数据与ODbL声明位于 [公开样本目录](../../data/public-apartments/README.md)。此数据不是从Mapbox临时地理编码结果永久复制。App不增加OSM运行时请求，底图继续Mapbox；保存的开放建筑样本不是司机定位或密码库。

OSM街道拼写为Sout Santa Fe Avenue、邮编90013，和[物业官网](https://osfla.com/)有差异。保存了差异记录，规范地址采用物业官网；这是公开资料交叉核对，不是现场核实或已知门禁类型。建筑范围只作为保守的楼内匹配范围，不声称覆盖社区入口、停车区和整片园区。

`data:public-apartments` 只允许postgres访问127.0.0.1:54329/abasong_d0；确定ID幂等录入，已有数据不一致则停止，不覆盖人工更新。公寓、来源、建筑分别存储，几何由PostGIS校验，标注点在建筑内，显示300。日常开发库无共享密码或资格变更，自动认定没有启用。

双端现有Debug构建已实际通过原生搜索/选中和业务API显示该名称、完整地址、真实建筑高亮与300；不是之前的TEST矩形。当前真实账号没有access.read，卡片明确显示受限状态，没有伪造共享密码。完整有权查码链路另在可销毁测试库中以该真实建筑、模拟位置、独立合成账号和TEST记录验证：resolve→map-context→受控access-records；无资格403，无有效共享项返回空列表，待审核不展示，合成审核后才返回TEST正文。

## 2. 端侧批次服务

新增迁移0004：`import_batches`、`import_source_usage`。累计50表；旧0001–0003不改写。批次必要元数据与owner关联，地址、码、门别、候选、确认和逐项提交计划整体信封加密；AAD绑定owner/批次/版本。正常API/worker没有密文表读取权限，敏感服务强制owner RLS；每个接口重新检查JWT、active账号、撤销时间和父子归属。

18个设计操作中15个端侧批次操作已实现并在本地实际运行；云端图片上传授权/complete/process三操作继续planned，未上传原图、部署对象存储或云识别。源登记状态新增registered，表示端侧来源元数据登记，绝不冒充原图已上传。正文响应no-store，不返回图片读取URL、上传权限或OCR全文。单条候选额外带owner受控commit_result及稳定client_commit_id，供跨设备恢复和共享补偿，元数据列表不带候选正文。

确认是显式用户动作。任何字段或模式变更使确认版本失效；整组选中确认要么全部通过，要么409回滚。公寓目标由服务端重查active状态和地址一致性，缺失/歧义不自动ready。第一版批次只正式支持keypad和门别label；时段等完整scope没有静默丢弃，而是在ImportScope契约中明确限定，其他方式待扩展。

提交先持久化计划/固定mode，随后逐项私存事务，再共享事务。复用既有私人库和共享事务规则；私存ID与结果在同一事务中写入计划，和短期HTTP幂等缓存分离。资格在两阶段间撤销、共享写入失败、重复/并发提交均不能制造重复私存。共享重试只补共享，新共享依旧pending，不因OCR或确认自动激活/投有用票。

取消比较generation，不撤销已经成功的正式记录；删除只处理未锁定草稿，保留删除幂等元数据。过期接口返回IMPORT_EXPIRED且不返回正文。受限worker函数只删除过期草稿/旧额度计数，范围1–500且拒绝NULL，固定search_path；worker不能读取候选。轮询代码接入此操作，没有实现云识别队列或假称处理outbox事件。功能已实际以worker角色执行验证，长期定时清理与宕机恢复不因此视为验收。

## 3. 原生接入

双端ImportScreen的保存/提交改接服务端批次。识别后可主动保存草稿；重新进入仅列本人未完成元数据，用户主动继续后再读取正文。原图仍在手机限期缓存，恢复的是已保存识别字段，不承诺原图或未保存修改恢复。

- 每张本地来源登记尺寸/字节/MIME元数据，服务端只把它们当声明限额；原图实际检查仍由本机选择/识别流程执行，不声称服务器解码过未上传图片。
- 截图提取/保存请求保留原始请求体及幂等键，响应丢失后先补完原请求再应用编辑；不因超时另造来源/候选。跨设备内容版本变化需重新打开，不静默覆盖。
- 新批次/保存/提交均有数量、字节、像素、日额度和有限留存；默认本地参数是开发保护值，不是生产阈值。
- 草稿内容编辑后提示未保存修改；手机原图不随草稿上云，不写普通本地存储。退出/切换账号清内存，signal取消请求。
- 新增“保存草稿”“继续未完成导入”，现有选中/来源声明/范围锁定保持。恢复时需要重新确认来源；没有共享资格不会暗改成私存。

已实际验证：iOS选择合成截图→端侧OCR→改为明确TEST地址/值→实际保存草稿→离开→iOS重新进入可继续；Android同账号发现并恢复该草稿→实际私存成功；iOS再提交同一草稿成功返回已有结果；两端我的公寓及详情观察只一条记录。随后通过正常UI删除本批TEST私人公寓，双端空列表已确认。完成批次的TEST加密候选仍按24小时草稿TTL清理，额度按既定窗口保留；不声称所有审计/草稿事实即时消失。系统相册合成图片未删除。

Android镜像鼠标事件不可靠，本批通过可见焦点的Tab/Return操作完成恢复和提交；不能把镜像输入问题当作真机触摸通过。iOS原生可访问性控件完成操作。两端均为模拟器，真机延期。

## 5. 当前限制与下一步

- 默认自动认定仍关闭；公开资料核对不能替代现场精度/停留/入口阈值。继续扩充公开公寓来源和映射，现场后再冻结适用区域与参数。
- 目前只有一个真实公寓已进入日常D0；此前5个物业地址加1个示例的覆盖探测不是6个都已收录。
- 真实可用共享密码需要有权贡献与审核，不能从公开地图取得，也不能用TEST数据制造覆盖。真实账号资格和运营审核流程仍待明确验收。
- 原生本批覆盖核心草稿恢复/私存/跨端重试；全部异常、iOS/Android真机、弱网/进程终止/多图长任务/耗电/读屏大字仍待完成。
- 云业务迁移、生产KMS/服务、对象存储和云OCR没有实施。协议15操作本地可用不表示108个设计操作全部实现。
- iPhone按用户决定稍后连接；Android真机尚无设备，不将模拟器验收升级为现场验收。

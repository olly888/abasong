# D1 真实定位、公寓识别与自动卡片

更新：2026-10-30。用户明确批准纳入D1核心验收。状态：首批已开发，公开地址接口探测及本地逻辑/权限验证完成；现场真值、自动认定启用、原生视觉与双端真机验收待完成。不是生产上线报告。

## 产品与设计基线

首页公寓模式：设备前台位置 → 识别当前公寓/社区 → 已核对建筑轮廓高亮 → 对应门牌号 → 同一底部卡片自动展示地址和有权访问的共享密码。当前位置不是地图相机中心，不把默认洛杉矶中心当成已定位；不采用Mac IP推断作为司机GPS。

建筑采用品牌蓝浅填充、蓝色轮廓；门牌号位于经过核对且确实落在轮廓内的标注点，放大后显示并避让。不在地图层传输密码、联系人、精确司机轨迹。轮廓/标注缺失时保留地址卡片，不绘制猜测的建筑或把社区中心号码复制到所有子楼。社区边界用于空间匹配，建筑足迹用于视觉展示，二者独立。

无共享资料：地址卡片直接添加，截图贡献入口维持P0；不能以无密码推断无门禁。无资格/读取错误独立于无密码。多候选/粗略位置/过期位置/来源过期均不自动揭示别栋资料，保留选地址、搜索和手动纠错。

地图已选/卡片展开后锁定阅读；只有用户主动定位解除锁定。后台、离开首页或退出账号停止采集并取消在途任务。普通刷新只移动蓝点，不持续抢相机；主动回位保持上一批已验收的显式相机命令。自动卡片在后续匹配不再指向该公寓、位置失效或查询失败时清除，手动锁定卡不被GPS抢走。

## 数据职责与接口

- OS提供设备位置；Mapbox提供底图/建筑/地址候选；Abasong提供公寓ID、经过核对的社区范围、建筑关联与有权限的共享资料。
- Streets v8的 `building.type=apartments` 只是候选依据，不能推断需要密码或完整公寓覆盖；`housenum_label.house_num` 是独立点层，不能直接拼成完整建筑地址。
- `POST /v1/apartments/resolve` 保持输入和响应结构。范围覆盖整个位置精度圈、唯一命中、来源有效、记录已核对、精准权限且版本化配置明确开启，才返回matched。最近点/类型/单次位置都不能单独启用自动认定。候选截断到20时不自动匹配。
- 新增 `GET /v1/apartments/{apartment_id}/map-context`：经过当前账号状态检查，只返回active公寓对应的已核对建筑、门牌号、标注点与核对时间，不返回来源凭据或进入信息；HTTP no-store。来源未核对、过期或建筑核对时间在未来则过滤。缺失映射返回空数组；公寓不可见返回404。失效接口不阻断密码读取。
- 新增本地迁移0003 `apartment_buildings`：持久许可来源、MultiPolygon足迹、轮廓内标注点、号码、核对时间。普通API/敏感服务仅SELECT，不能通过App自行创建“已核实”关联。没有公开写接口；后续需受控的数据审核流程。已有apartments.boundary继续作为社区范围，绝不默认当成单栋建筑。
- 导入批次尚未落地，其下一增量顺延0004；历史0003导入计划保留，不能再占用当前迁移号。不修改已应用0001/0002。

当前客户端采用已有双端单次定位适配器串行刷新：每次结束后等待5秒，非后台服务，不是逐秒导航定位。无新依赖或原生权限变更。仅在已取得位置、首页前台且地图可见时刷新；地图详情展开/列表视图暂停；精准/粗略权限每次重新检查。手动锁定后仅刷新蓝点，不查候选。真实设备若发现耗电、更新延迟不达标，再按证据升级原生订阅，不声称当前已完成连续导航级跟踪。

客户端自动选卡需要多次matched同一公寓、观察间隔未失联且累计至少8秒；这只是开发稳定性保护，不是已冻结的生产现场阈值。服务端 `apartment_resolve.auto_match` 默认缺省关闭；启用配置需要enabled、evidence_ref、max_accuracy_m。未在持久D0/云端写入启用配置，测试启用仅限可销毁合成数据库。

| 批次 | 内容 | 证据/出口 |

| C，参数与审核 | 样本冻结、错栋分析、置信与精度/停留/时延/耗电预算、环境范围 | 版本配置关联证据；多候选保守回退；不能只看平均正确率 |
| D，iPhone真机 | 接入用户可用iPhone；真实定位、走近/离开、多楼漂移、锁定/回位、前后台、拒绝/粗略权限、弱网、无码贡献、授权读取 | 必须现场，不能注入位置冒充真机GPS；敏感证据留本机且脱敏 |

硬性出口：无静默错栋展示/越权；只在可信匹配和当前资格满足时展示；未知可快速搜索/选栋；没有密码可直接贡献；建筑失效不影响地址手动查阅。时延、耗电和命中率按真实样本报告冻结，不预设无证据的通过数字。iOS/Android分别记录设备、系统、构建、输入类型、通过/失败/未测和用户确认。

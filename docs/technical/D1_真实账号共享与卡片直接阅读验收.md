## 实现

- `ApartmentSheet`移除密码按压入口、独立 Modal 和相关状态。密码使用普通文本；短值清晰展示，32字符边界值可换行，不加省略号。
- 展开/收起、添加、收藏及逐条反馈保持独立操作。内容超高可在卡片内部滚动。
- 当前扩展原型移除 B01 与入口；旧 `large` 路由回首页。长值增高时限制收起卡片高度，避免地图工具与搜索栏重叠，卡片内滚动可到达时间和展开入口。页面生成器/规格/目录/制作清单统一为39节点、284状态，历史已认可原型保留。
- 无 API、数据库迁移、权限模型、依赖或原生模块变更。本批是 JS/交互变更，没有重新编译原生二进制。

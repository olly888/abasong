2026-10-31，`codex/d1-iphone-validation`。接续 [Mapbox 地址联想验收](D1_Mapbox地址联想接入验收.md)，产品行为沿用 [ADD-10](../product/Abasong_V12.1_首页自动查码场景补充.md)。本批调整服务端识别策略及集成验证，不增加司机端按钮、审批步骤或页面。

## 已实现

原有 `auto_match.enabled` 是全目录总开关。现在必须同时命中具体公寓的有效验证范围，才能自动认定；验证一栋不会顺带开放其他公寓。

内部版本配置 `apartment_resolve.auto_match` 保留 `enabled`、`max_accuracy_m`，新增最多100项 `scopes`，每项包含：

| 字段 | 规则 |
|---|---|
| `apartment_id` | 明确UUID，不允许通配符或重复公寓 |
| `match_bases` | `boundary`、`entrance`，至少一项；建筑内和门外分别验证 |
| `evidence_ref` | 该公寓的验证依据，非空；不能只引用全局开关 |
| `verified_at` | 已核对时间，不得晚于数据库当前时间 |
| `expires_at` | 必填，晚于核对时间；到期立即失效 |

旧配置兼容读取，但旧全局开启、没有范围、范围错误、尚未生效或到期均不能自动选中。仍正常返回附近候选供用户点选，沿用 `policy_disabled`，不把验证范围问题变成整页故障。证据字段和范围不下发给客户端。

建筑范围不能替代入口核对，入口范围也不能替代建筑内部核对。查询附近歧义时继续考虑范围外的公寓；不会为了让试点命中而忽略邻栋。定位新鲜度、精度圆、来源有效性、唯一命中、8秒稳定观测和手动阅读锁定继续保留。策略有效期用数据库时钟，与来源和配置生效时间一致。

到期或撤销后，下次位置解析使原生共用状态机清除自动卡片；手动打开的卡片维持阅读，其资料访问权限仍独立检查。正常贡献依然确认后直接共享，无逐条人工审核。

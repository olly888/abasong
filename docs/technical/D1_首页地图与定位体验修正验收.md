- 更新页面规格生成源及生成Markdown/JSON；没有增加导航、长期招聘或结算功能。
- 原生三个模式复用同一个首页Content，切换模式不卸载位置/选择；提供真实可操作的列表/地图呈现切换。找活/找人数据仍未开放，不能把布局切换当作D2完成。
- 显式回位使用相机revision触发Mapbox Camera.setCamera命令；不依赖组件重建或坐标变化。已有点时先立即回位，再异步刷新位置；刷新期间仍可回位。位置点与相机目标分开，手动拖动不持续抢回中心；保留原公寓卡直到另选公寓。
- 相机padding及Mapbox归属避让卡片；定位按钮48×48、右侧16、卡片上方16，发布位于其上方。全屏详情/列表遮蔽底图并禁用底图触摸，收起后恢复，避免几乎无可见地图时遮挡归属信息。
- 区分权限未决定、永久拒绝、系统定位关闭、设备获取失败/超时、定位成功后的公寓查询失败。已取得位置而查库失败时保留位置点；无资料不代表定位失败。不写入新的查库阈值或虚构公寓。
- iOS系统权限弹窗的临时inactive用不透明覆盖隐藏内容、保留请求；真实background/离开首页/账号切换仍清理敏感状态。没有后台定位或轨迹存储。
- 我的底部设置进入原生二级页，包含位置权限/系统设置及退出；返回前台重新读权限。开发齿轮通过现有Expo官方API隐藏，开发菜单仍可用系统快捷方式打开。消息/发布仍明确禁用，保留D2边界。

## 定位提供者

iOS仍用锁定版本Expo单次前台位置。Android旧API返回 `ERR_LOCATION_REQUEST_REJECTED`；同SDK内置next系统提供者也未得到有效样本。最终采用本地Android专用模块 `AbasongLocation0.1.0`，通过系统LocationManager/AndroidX兼容API明确向GPS请求单次位置；无精确权限时仅尝试可用网络提供者，不强制升级权限。GPS不启用时也可使用网络提供者；没有提供者则明确失败。没有引入外部依赖/GMS、新权限、后台服务或硬编码定位回退；没有把beta next API保留在最终应用代码中。

模块在原生侧再次检查本App权限、前台状态、请求代次；15秒超时，完成/取消/后台/销毁均取消系统请求并移除计时器。JS AbortSignal同步取消，晚到结果不写回。外层20秒上限、客户端拒绝超过20秒的旧结果及明显未来结果；服务端继续以版本化参数校验位置，客户端新鲜度保护不代替T23现场参数验收。室内/弱信号与粗略位置的现场表现仍待真机验证。

## 本批确认与后续门槛

1. iOS最初用户反馈不能回位；改用显式相机命令并分离立即回位/刷新后，用户复测明确确认“现在能回位”。Android随后明确确认“Android能回位”。手势由用户补验，不声称镜像自动drag可靠。
2. 本批核心布局、双端合成定位、回位、模式切换和设置入口已验证；不等于完整D1或现场可上线。
3. 授权多公寓/密码、全屏展开卡片与定位保持阅读位置的真实数据闭环、大字号/小屏、读屏、真机弱网及现场精度继续按D1/T23门槛；合成原型/单元测试不替代这些检查。
4. D2实现后另验真实列表数据/筛选恢复、发布与消息；本批未启用这些服务。原定下一批继续本地0003导入批次与权限/确认版本/两阶段接口测试。

本机证据仅保存在忽略目录 `.tooling/home-ux/`，不向公开仓库提交设备画面。测试只用公开合成坐标，未读取真实设备GPS。未放宽shell mock-location权限、未创建测试位置提供者、未重置模拟器或删除用户数据。

# B4 可用司机与地图找活、找人

2026-11-04。分支 `codex/b4-driver-discovery`，基于 `31c102a` / PR73（该父提交CI41955725951成功）。执行用户批准的B4范围，沿用V3.1、RN/Expo/Mapbox和三导航。最新提交CI在本批PR记录，父提交通过不代替当前提交。

## 本批可用结果

司机从“我的→可接活设置”或首页找人的“我能接活”，主动设置本次日期、起止时间、1–5个愿意去的服务区域及可选包裹量。关闭App不撤销声明；关闭或到期停止出现在找人结果。未来时段显示具体时间及“稍后可接”，不能解释为在线或已承诺到场。

首页找活展示开放临时需求，找人展示有效声明的其他司机；区域点选与当前摘要同步，地图/列表互切、查看详情后返回保留当前模式的筛选与选择。搜索栏展开同一底部筛选面板，找活支持配送区域、日期、支援类型和区域/承运商/线路文字，找人支持服务区域、日期及承运商经验。档案的“联系司机”进入已实现的一对一文字会话。

首版保持一个时段，不增加重复排班、评分、认证申请、自动匹配/派单、集合点模块、长期招聘或结算。本人资料/车型/经验的完整编辑仍未接，列B5首项；当前显示已有自报资料，不能把合成经验或测试直接写库当作真实司机已填过资料。

## 地图、隐私和状态

- 公寓模式默认保持原有附近滑卡。找活/找人**不使用公寓200米半径**；初始全部区域，用户主动缩小到服务区域。地图使用已有Region的公开展示点，初始14级俯视，真实蓝点与区域对象分开。
- 一个区域聚合当前已加载的需求/声明数量；司机可声明多个区域，计数不是全城在线司机总数。区域点不是司机精确位置，不收集或发布司机轨迹，不请求后台位置权限。
- 每页20项、最多5页；刷新重新加载已展开的页，最多100项，再引导按区域缩小。15秒前台刷新和回前台重读；最早时段边界触发局部到期更新。没有后台常驻轮询。
- 地图列表、筛选、选中ID、列表滚动及主动选中的区域中心按模式保存于当前账号会话内；账号变化清空。不会把完整司机或需求缓存跨账号复用。手动拖缩的任意镜头姿态尚未做跨卸载持久化，B6完整回程继续核对。
- 切模式/筛选时先显示加载；新结果未完成前不借用旧模式卡片和标记。请求世代和AbortController丢弃过时响应；失败清空旧列表并明确重试，不假装暂无结果。后台回来重读，关闭/到期声明不继续展示。
- 进入支援模式暂停公寓发现/密码读取回调；仍共用前台定位和回位。返回公寓重新读取所选对象或恢复附近发现，不把司机区域点当作密码地址。

## 契约和服务

| 方法及路径 | 实际行为 |
|---|---|
| GET `/v1/me/availability` | 本人当前记录；未设置404，已关闭/到期仍可编辑 |
| PUT `/v1/me/availability` | expected_version + enabled；开启补时段/区域/容量，关闭不要求旧时间合法 |
| GET `/v1/drivers` | 区域/日期/承运商经验和UUID游标；有效其他司机、双向屏蔽过滤 |
| GET `/v1/drivers/:id` | 最小公开资料和仍有效的可用时段；未声明不使已有档案404 |
| GET `/v1/requests` | 既有权限/到期/分页保留，新增LA日期重叠筛选；文字包含区域标签 |

开启时段须尚未结束、开始不晚于7天后、单次最长24小时。可填正在进行的时段；结束时间早于或等于开始时，客户端明确展示次日日期。容量留空为null，不猜配送能力。区域必须真实存在且具有有效展示点。严格输入拒绝user_id、坐标及未知字段，不能替其他账号声明。

所有接口经过JWT、当前账号/会话有效性和对象授权。同账号声明通过事务锁和版本控制串行更新；当前版本的相同内容不重复加版本，旧版本返回409并要求重读，未声称丢失响应后的旧版本重试会自动成功。区域成员关系与审计同事务提交。公开司机只白名单返回显示名、简介、车型、自报经验、可用时段和公开区域，不返回手机号、设备凭据、私聊或精确GPS。未接入专门经验核验，不能由客户端自标verified。

分页查询批量投影档案及区域，固定最多3次查询，不逐司机发额外请求。停用账号和任一方向屏蔽不显示；声明到期时档案可继续存在而availability为空。联系复用既有创建会话接口和屏蔽检查，不额外做司机定位分享。

生成源 `scripts/generate_v12_openapi.py`、OpenAPI与生成类型同批更新。复用现有availability/availability_regions、regions、profiles、blocks及audit_events；**无新增DDL或角色授权，D0仍14迁移/53张FORCE-RLS表**。未运行云迁移或部署，未发短信、真实消息，未改真实账号资格/声明。

## V3.1与原型差异修正

| 差异 | 修正 |
|---|---|
| 首页支援模式仍为未开放外壳 | 接真实区域/需求/司机API，加载、失败、空、非空分态 |
| 司机卡太高、重复“查看资料”说明 | 收敛为显示名、时段、区域/容量、经验；整卡进入资料 |
| 筛选行与比例尺重叠 | 筛选在模式栏下，比例尺在其下；地图归属与工具避让底部卡片 |
| 模式切换或返回瞬间出现假空态 | 按账号+模式+筛选隔离已加载结果，初始加载不提前判空 |
| 可接活表单重复“最晚结束时间” | 只保留本次结束时间；固定保存操作，系统日期/时间、Switch和区域多选 |
| 旧时段结束后仍沿用过期草稿 | 重新编辑默认关闭及本次时间，保留原区域/容量供修改 |

共用PageFrame/BottomSheet/ActionButton/Field/NativeDateField；不更换品牌、字体、框架。原型版本 `b4-discovery37`；原型只使用合成数据和示意地图，不证明真实服务/权限已经生效。没有外聘真人高级设计师签审。

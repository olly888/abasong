## 可用结果与产品规则

- 首页搜索右侧消息图标进入统一二级消息中心，总未读来自服务端；我的顶部不另加重复入口。
- 对话/通知分栏。对话显示对方用户名、时间、来源需求区域与类型、未读数；列表不预取或解密文字预览。进入中心不清空全部未读。
- 参与者能发送1–2000字符文字，保留换行。空白不可发送；发送中、发送失败/重新发送、已发送、对方已读分别呈现。
- 重试复用原消息编号和正文。服务端接受与对方已读分开；只有对方已读水位覆盖该消息，才显示“对方已读”。读取只确认本会话已显示消息，不跨会话。
- 来源卡保留沟通时版本和区域，点击读取当前需求；条件后来变化不改历史快照。整张卡可点，避免重复高按钮挤占消息空间。
- 被任一方屏蔽或对方账号不可用时只读；新请求仍校验登录、会话成员及账号状态。本人退出或换账号时卸载消息状态。
- 报名/条件变更/终态等站内通知按现有事务创建，点开仅标记该条通知；发布者报名通知进入报名列表，其他需求通知进入当前详情。

原型同步M01未读数字、M02明确“对方已读”示例、失败重试和文字发送按钮/空输入禁用。原型内仍是合成交互，不能视为服务投递。原型中的集合点、会话更多/常联系等后续功能继续单列，本批原生不提供无效按钮。

## 契约与数据库

源文件为 `scripts/generate_v12_openapi.py`，同步生成OpenAPI与contracts类型。新接8个操作：list/get conversation、sendMessage、listNotifications、getInboxSummary、readNotification、通知偏好GET/PUT；扩展已有listMessages与readConversation。偏好服务已接，系统推送投递尚未实现。

Conversation增加当前/对方已读水位、can_send及最后可见来源快照/区域；Message带稳定client_message_id和历史来源区域。MessageInput区分文字和需求卡，拒绝混合字段与冒充sender。消息支持增量after_sequence和历史before_sequence；首次取最新40条，更早消息独立分页，结果保持时间顺序。会话/通知列表使用有界游标，不输出正文。

增量迁移0011新增消息加密格式及内容HMAC，并给敏感服务最窄的会话/需求元数据、消息/outbox写入和序列权限；0012仅补历史区域标签读取。0011已在本机应用后新增需求，因此用0012而非改写已应用DDL。无新业务表，D0实际12迁移/52张FORCE-RLS表。DevWest仍9迁移/旧镜像，未改云库或云角色。就绪检查已要求全部12版本，缺迁移不能假就绪。

## 加密、权限与一致性

1. 现有普通请求事务持有账号/会话有效性锁；消息元数据、密文、幂等、outbox和审计的实际写入在同一个敏感数据库事务内完成，actor上下文用于审计和幂等策略。密文或加密失败整批回滚。
2. 复用已有EnvelopeCrypto，本地/KMS格式严格匹配，AAD绑定会话、消息、发送者及版本；KMS环境不回退本地密钥。普通API连接和worker不能读取message_secrets；敏感服务负责对象授权，RLS服务策略不是用户授权替代品。
3. header幂等键与发送者client_message_id双重防重；同编号改内容、改会话均409。内容HMAC包含会话，不在幂等表存文字。过幂等保留期仍利用消息唯一编号识别重试。事务内按发送者串行限频，新增消息上限60条/分钟，重放不另计。
4. 同会话行锁串行化B2来源卡与B3文字；分页、来源快照在读时重新校验参与者及可见性，敏感字段被过滤。密码/精确位置不会作为需求卡或通知预览附带。
5. 加密格式或认证标签不匹配返回明确503，地址/元数据不冒充空消息；列表仍不解密。outbox只含事件/对象编号，无文字、手机号或位置。没有把pending outbox标记成已投递。
6. 前台且页面聚焦时轮询：会话4秒，中心12秒，首页未读15秒；后台/离页取消请求。查看更早中心列表后暂停轮询覆盖，返回或主动刷新再获取最新列表。无后台推送、电量持续定位或WebSocket新依赖。
7. 同步水位与本人发送应答分开：本人seq12先到不会跳过随后peer11。可见已读也不跨未同步空档；迟到请求按当前页面scope隔离。未发送草稿与失败正文仅保留当前内存，不持久化到设备日志/缓存。

## 双端原生与原型核对

使用实际原生开发App加载最终业务组件；DEV-only messages-lab复用相同ConversationLayout/ChatHistory/Composer/列表组件，以内存适配器隔离TEST资料，不调用真实发送API。HTTP数据库事务证据与原生合成行为证据分开记录，未伪造真实聊天或账号资格。

| 项目 | iOS模拟器 | Android模拟器 |
|---|---|---|
| 会话/来源卡/文字、时间、状态布局 | 实际渲染并对照原型 | 实际渲染并对照原型 |
| 文字输入与发送 | 工具实际输入、单条发送、输入清空及已发送通过 | 输入实际可见；用户补测发送新气泡/已发送通过 |
| 失败重试与稳定编号 | 失败页点重试，仍同编号，只显示一条成功消息 | 失败页实际点重试→发送中→同编号已接受；未重复气泡 |
| 读状态区别 | 工具触发合成peer读水位，已发送→对方已读 | 同样实际观察切换；仅用于UI，不当作真人读取 |
| 只读状态 | 点击只读后输入栏消失，历史保留 | 用户补测通过 |
| 对话/通知切换 | 工具实际切换，点单条未读通知仅移除该条未读 | 用户补测两条合成通知通过 |
| 键盘 | 输入/硬件键盘可用；完整软键盘仍集中验收 | 发现遮挡并改为height避让，系统软键盘上方输入框/发送按钮实际可见 |

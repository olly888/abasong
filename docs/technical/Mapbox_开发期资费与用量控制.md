# Mapbox：开发期资费与用量控制

核对日期：2026-11-01（洛杉矶）。本文件仅估算Mapbox费用，不是整个项目的预算或账单。价格与账号适用条件以后续控制台/合同为准。

## 当前结论（2026-11-02续核）

用户已绑定付款卡，样式、临时搜索及地图服务恢复。官方Geocoding文档说明永久存储要求有效付款卡或企业合同；本批以公开Del Mar地址实测永久编码200/精确匹配，再用Acappella地址完成隔离库新地址共享链路。仅本机忽略配置已启用，云端仍须单独配置。[实测与调用限制](A3_新地址永久保存与贡献闭环验收.md)。不代表无限免费或所有地址都能精确解析。

## 历史试用限制记录（升级前）

要继续真实底图、外部地址联想和Mapbox建筑候选验证，当前账号需要恢复标准访问。代码、合成卡片和本地数据库验证可继续。建议先完成Android交互修正，确认以下价格后再由用户本人决定添加付款方式。当前没有升级、付款或更换token；本机公开token与控制台相同，样式接口独立复核401。

控制台显示账号处于受限试用，永久地理编码配额0，已有两次本项目公开样本验证。官方说明任一试用产品达到用量上限会暂停全部API，据此判断当前401与账号限制有关。此前仅凭两次HTTP200就开启永久编码是不充分的资格验证：本机.env已改为关闭MAPBOX_PERMANENT_GEOCODING_ENABLED。不能将旧“账号支持永久编码”的记录继续作为当前依据。

标准访问为按量计费，并保留各项免费额度；超过额度产生账单。官方说明升级后不能回到demo。添加付款资料与最终确认需要账号主人操作。[账号试用与升级规则](https://docs.mapbox.com/accounts/guides/demo-access/)

## 与Abasong直接相关的价格

以下为超过免费额度后的第一档，未展开更高量级的折扣。

| 产品 | 计量 | 每月免费量 | 第一档单价 |
|---|---|---:|---:|
| Maps SDKs for Mobile | 地图月活用户MAU | 25,000 | $4/千MAU |
| Tilequery | 附近建筑查询请求 | 100,000 | $1.50/千次 |
| Temporary Geocoding | 临时正向/逆向地址请求 | 100,000 | $0.75/千次 |
| Permanent Geocoding | 需要永久保存的地址请求 | 无 | $5/千次 |
| Search Box会话：预览价 | suggest/retrieve会话 | 500 | $3/千会话 |
| Search Box会话：标准价 | suggest/retrieve会话 | 2,500 | $11.50/千会话 |

来源：[官方价格页](https://www.mapbox.com/pricing)。Search Box同时列出两套价格，升级后的适用价格需核对账号，不能把预览价当长期承诺。由于免费量也不同，“按标准价估算”在低用量时不总是更保守，应按两种口径中较高的预算，直到账号口径明确。

项目使用社区React Native Maps封装；官方说明该类原生SDK封装通常按Legacy SDK MAU计量，免费量与Mobile Maps MAU相同。[混合框架计费说明](https://docs.mapbox.com/accounts/guides/pricing/#hybrid-frameworks)

Search Box的地址建议与点选按会话组织，不应每敲一个字都创建新的会话。项目已有同一用户的供应商会话复用及输入节流；不要把地址联想等同于按字符计费。[Search Box说明](https://docs.mapbox.com/api/search/search-box/)

## 可核算的例子

假设一个月只有10个地图活跃设备、200次Tilequery、800次临时编码、100个地址搜索会话：这些用量均低于上表两种Search Box口径及其他免费量。若再新增永久编码100个地址，Mapbox估算费用为100/1000×$5=$0.50。若不调用永久编码，该例为$0。这里假设对应产品权限已开通，不能用于证明目前试用账号可调用。

再举一个只按API量计算的试点：1,000地图MAU、50,000次Tilequery、200,000次临时编码、10,000次Search Box会话、1,000次永久编码。地图/Tilequery在免费量内；临时编码约$75，永久编码约$5；Search Box按预览价约$28.50、标准价约$86.25，总计约$108.50或$166.25。实际司机打开频次和停留时长尚未测得，不能用这两个数字承诺运营成本。

## 本批控制与后续工作

- 位置更新和本机目录查询不直接等于一次Mapbox查询；当前位置与选卡解耦，后台/离开页面停止前台观察。
- Mapbox补充保留最短30秒请求间隔；当前会话结果有效且仍在适用范围内时复用正在展示的数据，不再固定每30秒重复请求。到期/移动后重新发现；不跨会话存储临时供应商结果。
- 2026-11-02有限补查：未截断时1次Tilequery；达到50个要素时最多追加4次，总计最多5次。之后最多4个反向地址建议，因此一次发现最多9次供应商HTTP；不是每个GPS点都执行，仍保留客户端最短30秒／服务端每账号25秒保护。优先复用已收录资料、去重与单会话有效结果；补查仍标不完整，不是整区覆盖或月账单硬上限。原生已加载建筑直接查询不额外调用Tilequery。价格表保留上述核对日期，本次没有重新核价或开通产品。
- 永久编码仅用于用户明确确认的新地址保存，不用于每个GPS点、每次开App或每个包裹。2026-11-02完成官方条件核对及有界永久请求实测后，仅本机配置启用；默认模板仍关闭，部署环境单独确认。
- 当前限频是单进程保护，不是月度账单硬上限。扩大试点前须补齐用量记录、跨实例预算控制及提醒；尚未在账号设置提醒，也未配置付费服务。
- 不需要为首版购买车载导航、自动派单或整条线路优化产品；这些不在当前范围。

永久结果可持久化与临时结果的使用条件必须分开，标准账号也不能把临时搜索结果整批入库。[地理编码存储规则](https://docs.mapbox.com/api/search/geocoding/#storing-geocoding-results)

## 范围与修正

基准为[产品基线](../../产品基线.md)、[三模式卡片补充](../product/Abasong_V3.2_地图卡片与距离体验补充.md)及[已认可 V3.2 原型](../../design/abasong-independent-v1/v12.1-experience/index.html)。不改原型视觉、不扩业务；R4-01–04 已确认且未受影响的手势不反复要求负责人补测。

本次组合运行发现并修正：

1. 主首页的定位处理曾在找活、找人模式也清除公寓阅读选择。现在按当前模式执行副作用：协作定位只回蓝点、保留筛选和公寓上下文；公寓定位明确解除阅读锁并恢复附近推荐。
2. 自动推荐卡在切回公寓模式时可能沿用先前地址。现在自动模式重新按最新位置发现；主动滑卡、点选的公寓仍保持选择，并重新读取有权正文。
3. 首页为保护敏感内容，在路由失焦/后台时卸载正文组件，原先也因此丢失人工选择。现在按账号在内存保留公寓 ID、临时目的地随机键和视角；不保存门禁码正文。返回后重读服务。账号切换清空；临时供应商结果继续受原有会话期限及后台清理规则约束。
4. 首页导航参数消费后清除，避免以后点击定位仍被旧参数重新选回；初始地址请求增加代次校验，迟到响应不能覆盖定位后的新推荐。搜索目的地恢复时保留已有视角，不强制再次缩放。

5. Android重新挂载横向轨道时，初次`scrollTo`可能被尚未完成的原生内容布局夹回0；记录的对象仍正确但第一张预览占位。现设置初始offset并在内容尺寸确定后的下一帧重对齐，取消失效帧，不把程序回位当用户滑卡。修正前画面单列保留；负责人已确认长列表08详情返回及切地图仍为08。

共用 `MapCardFrame/MapCardCarousel`、地址数字/常规街道、城市/米距、完整符号、贡献人、无码/读取失败/无资格状态沿用 R4-01–04，不增加第四种首页结构。

## 运行方式与证据边界

新增仅 `__DEV__` 可用的 `home-integration-lab`。它使用实际 `HomeApartmentContent`、`ContributionForm`、`CollaborationHome`、共用卡片及原生 Mapbox；传输为内存 TEST，位置为公开洛杉矶合成坐标，详情是相同组件的卸载/返回回调。非开发构建重定向首页。注入位置、传输和贡献回调均受 `__DEV__` 保护。

该 Lab 验证组件之间的选择、请求和回程，不证明真实账号资格、实际路由鉴权、云端 KMS、真实贡献发布、GPS 实地覆盖或现场识别。HTTP/PostgreSQL 服务另在隔离本地库运行。没有发送消息、短信、真实密码或司机位置，没有新增资格、迁移、契约、依赖或云操作。

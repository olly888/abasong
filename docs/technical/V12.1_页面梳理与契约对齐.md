# V12.1 页面梳理与技术契约对齐

日期：2026-10-29。依据：[需求补充](../Abasong_V12.1_需求补充与原型决策.md)、[逐页规格](../product/Abasong_V12.1_页面功能信息与交互规格.md)。用户最终明确只做临时配送支援/灵活用工，先前准备中的长期招募字段已移除。

## 1. 已同步到机器文件

`openapi-v12.yaml`保留文件名以免断链，info.version升为12.1.0；初始0001迁移仍是未应用草案。更新不触碰任何真实数据库。

| 项目 | 变更 | 页面原因 |
|---|---|---|
| 支援字段 | accepts_partial、minimum_parcels、experience_requirement | 表达当次最低量、拆分、所需经验，非雇佣/招聘类型 |
| 取件地区 | pickup_region_id；pickup_area由可信区域标签派生 | 避免公开卡和分享把精确地址误当大致区域 |
| 当次日期 | 发布仍要求starts_at，报名仍要求expected_arrival_at | 无长期/不限时间的报名 |
| 类型边界 | 无engagement_type/ongoing/training/trial/cooperation_schedule | 不存在长期招募、试线、带教、入职模型 |
| 草稿 | discarded_at、discardDraft | 仅软丢弃本人未发布草稿；列表/发布排除已丢弃草稿 |
| 贡献列表 | ContributionSummary替代正文列表 | 资格过期仍可看本人状态，正文另鉴权 |
| 司机档案 | availability允许为空 | 未声明接活不等于档案不存在 |
| 本人组织 | getMyOrganization | 可恢复组织名称/核验状态编辑，不自授 verified |
| 消息中心 | getInboxSummary | 准确的消息与通知未读；不清空所有记录 |
| 报名记录 | 增加request_summary | 我的报名列表可展示当前需求，无需每行额外猜字段 |
| 密码贡献者 | 只返回contributor_display_name | 显示不同贡献者，不泄露手机号/原始身份资料 |
| 外部摘要 | request_shares表，create/revoke/getPublic/resolve四操作 | 游客白名单只读、登录后重新获取当前需求 |

## 2. 匿名接口的窄例外

仅健康检查与`getPublicRequestShare`不要求业务JWT。公开接口按高熵UUID4 token查已明确分享的需求，并校验撤销、时间和对象状态；不开放全站列表或完整Request。正常业务表仍不暴露给Supabase客户端。

公开DTO不含password、value、phone、微信、精确集合点、个人ID、报名名单、私聊、自由description/payment_terms等。取件标签从pickup_region_id派生，不能直接回传任意自由地址输入；结束后的summary为null，只显示非敏感标题/终态。分享token可撤销，访问/错误日志须掩码token路径；token只授权摘要，不等于账号身份。

生成链接只能由已发布需求的发布者主动确认，输入public_preview_confirmed=true；一次重试返回同一链接。token只是公开摘要标识，受限业务schema中保存，不在公开列表提供。登录后的`resolveRequestShare`才返回按正常权限过滤的当前Request，用户重新确认报名条件。

## 3. 跨字段与状态规则

- 配送发布：具体日期、当次包裹量/人数、配送/取件区域、报价或议价、理货/接手条件；车辆/其他求助继续简化。
- 整线发布：accepts_partial=false且minimum_parcels=parcel_count；SQL明确要求下限非空，避免CHECK的NULL语义绕过。
- 下限/容量不能超出当次总量/剩余量；剩余少于下限先联系或由发布者改条件。新报名须所见版本仍匹配。
- 移除长期字段后请求schema拒绝这些额外字段，不允许用description之外的暗藏招聘类型回流。自由说明是当次配送补充，不改变产品对象。
- 本人待审核/已撤回贡献列表不含正文；失效记录不能因从我的进入而解密。
- Driver基础档案可存在而availability为空；找人列表仍仅返回当前声明有效的司机。

## 4. 版本及验证边界

SQL和OpenAPI仍要执行静态检查；36节点中的operationId全部应能在契约找到，动作目标必须存在。现有运行时实现、数据库实际执行、角色/并发、推送/深链和真机没有因本次补充变成已完成。

V12原技术/数据库/API文档与本补充冲突时以本补充为准；原架构、字段加密、JWT、服务端对象权限、outbox、私下结算边界保持。本轮未在任何云项目应用迁移；若此前有其他人部署过旧0001，应编写新迁移而非覆盖历史。

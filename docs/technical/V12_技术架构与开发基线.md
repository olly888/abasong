## 2. 数据与授权边界

App可直连Auth和地图SDK；业务只走认证API。JWT检查签名、issuer/audience、有效期及subject，随后检查账号、会话、资格有效期和对象权限；不能信任客户端user_id或显示角色。资格不由登录自动授予。

业务schema不暴露普通客户端，角色/schema隔离及默认拒绝RLS只是纵深防护，不是逐用户授权。业务角色非owner、无BYPASSRLS，不以Supabase service-role处理普通业务。API、敏感服务、worker及迁移凭据分开；公开摘要DTO独立于完整业务请求，不带私人字段。

密码、私存、导入候选和消息正文按现有敏感边界加密；授权解密只返回当前对象所需内容。日志、审计和锁屏不记正文/密码/精确GPS；地图临时结果不能靠换ID永久化。来源、地址与共享范围分别管理。

## 3. 模块职责

| 模块 | 现有职责及限制 |
|---|---|
| Identity | JWT、本人初始化、账号状态、限期业务资格及员工MFA；不自授资格 |
| Apartments/Access | 地点、别名、范围、发现与唯一关联、加密密码/反馈/排序/本人纠正；无普通撤回接口，历史状态保留 |
| Library/Imports | owner私存、收藏、确认后共享，端侧OCR及加密批次/逐项幂等；无跨次续填入口、无逐条人工审核 |
| Requests/Applications | 临时需求版本、发布/截止/缺口/关闭、报名与来源会话；报名不自动扣缺口，不派单结算 |
| People | 主动单次可接声明、区域和容量、最小公开资料；经验自报，本人完整编辑/常联系仍B5，无位置轨迹库 |
| Conversations | 两人文字、来源、幂等、分页、参与者与屏蔽、已读水位；服务端成功不等于对方已读 |
| Notification | 站内事件、偏好、设备和回执；无独立集合点分享，未来机会提醒不从现有订阅自动开启 |
| Circle/Moderation | 最小互助及举报/账号管理设计；完整本人/社区/常联系待B5，不扩生活交易或长期招聘 |

## 4. 关键事务与客户端规则

- 公寓200米发现与精确到达分离；地址/空间唯一关联后才用该公寓ID查有权密码。活动对象、请求代次和账号一致再回填，切卡先清旧正文；GPS不抢主动阅读。
- 正常贡献确认后直接共享；部分成功按条目幂等，地址不确定先核对；本人纠正采用expected_version及幂等，保留其他来源/原贡献时间/反馈。
- 需求、报名、来源会话、通知outbox和审计在既有事务边界提交；并发资格/状态检查不能仅在客户端执行。报名与手动缺口独立。
- 消息加密与元数据、去重、outbox、审计原子提交。服务端ACK不推进对方读水位；本人发送ACK不跳过尚未同步的对方消息。
- 设备绑定、退出和换绑按owner处理；投递前检查当前偏好/账号/屏蔽与设备，推送只提示，点开重新读取事实。
- 声明单时段/1–5有效区/可选容量，有版本控制；未来明确日期，到期/关闭停止推荐，App退出不伪装下线。当前日期/区域查询的具体差距见目标增量，不默认为已修正。

普通密码撤回已取消，管理员误共享停显需环境、来源ID、原因、操作者审计及有效ops权限/MFA，不开放普通司机入口。独立集合点公开接口已移除，0013/0014历史保留，不能回滚已应用结构。

## 5. 规范、迁移与验证

实际契约源为[生成器](../../scripts/generate_v12_openapi.py)及[OpenAPI](openapi-v12.yaml)，生成类型与源同步；数据库规则见[设计与事务](V12_数据库设计与事务规则.md)。本轮新增技术方案不修改这些已运行文件。

使用./scripts/dev；check检查代码，db:verify只允许隔离本地D0，云迁移走独立预检流程，不通过更改环境标识绕过保护。已应用迁移不可原地改，未来增量独立审查权限与回滚。公开样本与TEST记录不复制进云；云秘密不写入Git或本地报告。

本地自动检查、实际HTTP/PG、原型合成、原生编译、双端交互、真实账号和真机/现场分别记录。当前B4已有本地核心证据，Android最终GOFO经验筛选及地图/列表结果一致性已获用户补验确认；仅TEST内存场景。B6集中真实业务KMS、双账号、远程推送、独立iPhone和现场，不因文档升级或合成补验标通过。

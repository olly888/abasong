## 4. 每项完成定义

1. 需求/页面/原型状态对应，并以真实门牌、取件、司机意愿和离线结算场景核对；设计目标不扩大功能边界。
2. 涉及接口时生成源、OpenAPI、生成类型、服务输入和输出一起改；必要迁移只新增，不改已应用迁移。D0检查只用于隔离本地库。
3. 通过有意义的单元、HTTP/数据库/对象授权检查；不为纯排版机械新增镜像实现的测试。核心未知量、时间、地址、幂等及异步切卡需要真实边界测试。
4. 双端按同一数据与页面状态核对功能和视觉：320/390/430等宽度、可见按钮、空/失败/无资格/加载、长地址及系统字号；必要手势/键盘分别记录。模拟器不写成真机，截图不写成权限验收。
5. 每批提交精确SHA、PR/依赖、实际命令、结果、证据路径和未验项；工程构建、原生编译、模拟器功能、物理现场分栏。不让旧绿色CI代替最新提交。
6. 只有新增/修复影响的真机场景才请求用户配合；无需重复已验且未变的回位/返回手势。遇错地址密码、非自愿共享、越权或重复发布，先关闭受影响路径并修复，再进入下一出口。

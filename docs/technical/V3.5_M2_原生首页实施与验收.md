## 1. 本批范围

- 首页采用真实 Mapbox 局部视口：上部约占内容区 42%，下部为纵向独立结果卡，系统安全区和底部导航另计。地图有自己的尺寸，定位及署名在地图内。
- 共用官方字标、搜索与消息顶栏；下方只有一处查码/找活/找人切换，取消当前首页重复的地图/列表开关。小高度屏收起字标，保留消息。
- 三模式共用 `HomeWorkspace`、`HomeResultList` 与 `HomeResultCard`。统一边框、选中底色、圆角和内边距，内容自然增高，不固定为 192。
- 公寓卡：门牌数字优先、街道次之、城市弱层级；完整门禁信息在主信息条，门别在右侧；贡献时间、用户名与可见条数在尾行。地址全文在无障碍名称中保留。
- 找活卡：区域、报价、件数/缺口、到场时间、仓库取件区域或途中交接。找人卡：时段、愿去区域、容量/车型、自报配送经验；未来时段标为待开始。不编造收入、实绩、司机位置或距离。
- 复用已有真实请求、区域、筛选、分页、详情、贡献和反馈。地图上下文仅跟随焦点；筛选不因滚动选中而改变。每模式分别保存读取位置、选中和镜头。

## 2. 可见行读取保护（M3 前置实现）

新 `visible-access-reader` 只读取可见公寓及已打开详情，最多两条并发、最多六个目标。账号/会话变化会创建新读取器；离屏即移除内存正文，不写入阅读位置缓存。权限撤销取消请求并清空正文。服务返回 401/403、共享暂停、传输失败、成功但空记录分别展示，不互相冒充。

每条返回记录都核对 `apartment_id`。离屏取消后到达、旧请求晚于新请求返回均不能重新填入正文。重试只针对目标行且不重复并发。403 不因视图刷新无限自动重试。API 对象鉴权仍由已有服务执行；合成客户端能力不构成服务授权测试。

扩展的阅读记忆仅含公寓公开资料、选中、镜头和滚动偏移，不含门禁正文。贡献从具体行进入同一表单并传递该公寓 ID；搜索结果地址未明确时仍先核对。本人纠正、跨账号 HTTP/数据库验证与精准目标失效后的完整回程继续在 M3 验收，不能用本批单测代替。

## 4. 解锁后按顺序补验

入口：开发容器 `abasong://home-integration-lab?layout=muse`，仅本机 TEST 资料；无需登录或申请资格。

1. 查码向上滚至 102/104：停稳选中对象与地图高亮一致；102 显示 TEST-02#，104 为暂无共享门禁码，其他卡状态不被覆盖。
2. 点击 102 打开详情、收起，仍保留选中和阅读位置；切找人再切回查码仍保留。定位恢复附近推荐。
3. 104 添加门禁码，使用合成 `*0012#` 和三选门别，成功回到 104；失败重试仍绑定同一公寓。本项为内存 UI，不计真实服务写入。
4. 找人滚至 TEST 司机08，详情返回、切找活再回找人，保留该对象与列表位置；筛选、地图区域点选不被普通滚动改写。
5. 各模式加载、空态；公寓读取失败、无资格、暂停，地址仍在且不出现旧码。可用 `scene=empty/read-error/denied/paused/discovery-error` 入口。
6. 双端补验模式切换、卡片操作命中区域与大字号；已重载并记录最终默认布局，图片不能代替手势验证。

这些是尚未完成的验收，不是要求用户重新执行历史 R4/B5 的所有旧手势。能够由工具完成的优先由工具完成。普通首页已经接入本批组件；测试入口用相同组件，底部导航仅为尺寸占位，测试按钮不进入 Release。

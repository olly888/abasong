# V3.5 M5-02 · 贡献、截图核对与三选门别

2026-11-08，America/Los_Angeles。**本地实现与自动回归通过；iOS/Android 原生键盘、返回手势和最终视觉待补。** 本批接续 M5-01，使用既有品牌 token 和 Muse 信息层次，没有新增业务流程或云资源。

## 页面与组件

| 页面 | 本批对齐 | 保护规则 |
|---|---|---|
| 手填贡献 | 公寓地址在前；门禁码采用24/32字号、60最小输入高度；下方点选门别和确认来源 | 首页与“我的”继续使用同一表单；更换地址保留输入，清除来源确认；成功返回提交的公寓 |
| 本人纠正 | 固定显示原公寓；复用门禁码、门别与勾选组件；统一“纠正门禁码”标题 | 改码或门别后重新确认；版本冲突锁定提交；只结束本人旧来源，保留他人来源与历史反馈 |
| 截图结果 | 每条独立地址卡；门牌优先、街道常规字重；浅灰码区；“选择”和“核对”分列 | 未核对地址不可选；编辑后清除该条选择及批次确认；部分成功只重试未完成项，不重复共享 |
| 截图核对 | 复用地址字段、门禁码及三选门别 | 保留前导零、#和*；已保存记录保持锁定；失败不丢失输入 |

共用 `AccessCodeFields` 和 `CheckField` 替代三处重复实现。门别只有**行人门、车库门、大堂门**三个点选项，再点当前选项可取消。不明确时允许留空，按既有契约使用“门别未注明”，不猜测为行人门。已有历史门别保留，用户明确改选后才替换；不恢复自由输入或增加第四个选项。

门禁码始终作为字符串处理，使用可输入符号的普通键盘，不使用数字键盘或数值转换。勾选控件复用同一图标与颜色，最小触控高度48；原生辅助功能状态与网页 aria 状态一致。截图硬件返回监听仅在 Android 注册，iOS 的既有路由返回保护保持。

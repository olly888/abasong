# V3.5 M6-01 · 司机圈与“我的”视觉收敛

2026-11-08，America/Los_Angeles。**本地实现、接口保护回归和浏览器核对通过；原生键盘、相册、返回手势及最终视觉待补。** 本批沿用正式品牌蓝、Lucide 图标、V3.3 token 与获准的 Muse/V3.4 信息层次，无新增依赖、契约、迁移或云资源。

## 实施范围

| 页面 | 本批实现 | 保留的业务行为 |
|---|---|---|
| 发布动态 | 正文在前，图片选填；三个内容标签直接点选、再点取消；地区和关联本人需求默认折叠，按需独立加载；空正文禁止提交 | 最多三张图片、文字回复；失败保留正文、标签和图片；不确定结果复用同一提交标识，先重试再修改 |
| 动态流／详情卡 | 作者、时间／地区、正文、图片及回复顺序；40头像、16正文／作者字级、20上下间距；发布选择使用“发动态／发需求” | 返回时重新核对访问权限；旧列表在核对完成前不可阅读或操作；私有图片仍走受权请求 |
| 动态流状态 | 加载／失败层以内容区为锚，不再把顶部写死为120 | 原列表保留滚动状态；失败不是空动态，重试仍重新鉴权 |
| 我的 | 移除已登录与未登录页的重复“我的”标题；身份行→接活状态→共享门禁码主操作→个人工具→邀请／团队→设置 | 开启只进入时段设置，保存成功才生效；关闭失败仍显示开启并允许重试；资格、私有联系方式、团队条件不变 |
| 个人资料 | 配送用途、公司经验、熟悉区域统一使用 `ChoiceChip` | 本人编辑、版本冲突、草稿和联系方式自愿提供规则不变 |

新增 `ChoiceChip` 统一字号、48最小触控、圆角、描边、选中／按压／禁用状态及辅助功能；`ComposerOption` 负责选填项折叠、已选摘要和清除。品牌色只用于主操作、有效选中项和必要链接，不增加“我的”横幅或品牌装饰模块。

地区与本人需求分别加载、分别重试；打开关联需求时也补取地区名称，名称未知明确显示“地区暂未加载”，不猜测。选填资源失败不会阻挡不带关联的文字动态发布。已带关联的草稿仍由服务端检查关联对象权限，不用客户端失败状态绕过检查。

原型同步 `.muse-v35` 下的资料字级、头像、菜单行、动态作者和正文输入尺度。没有加入点赞、评分、常联系、成员管理或收费。

## 原生补验与下一批

本轮Mac锁屏，未执行以下原生验收，解锁后集中补：

1. iOS/Android：正文键盘下发布按钮可见或可滚动到；标签可取消；可选项折叠后正文不丢失。
2. 相册选三张、取消、预览关闭和返回草稿；状态栏及安全区不遮挡操作；失败后图片不重复发布。
3. “我的”接活时段保存、关闭失败重试、超时、版本冲突；个人资料返回与保存；大字体不遮挡。
4. 动态详情返回滚动位置与失去权限后的正文／图片清除；M2–M5已有待验项继续保留。

下一批 **M6-02：消息与邀请组件、未读语义**。首页消息仍是统一入口，司机圈未读只计自己的子集；邀请不授予查码资格，不编造邀请人数和收益。统一候选、对应提交的远程CI、原生集成及新签名包在M7处理。本批未提交／推送、云部署、重签／安装或更改真实账号资格。

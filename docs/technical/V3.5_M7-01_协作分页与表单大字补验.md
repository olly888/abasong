## 大字检查发现与修正

最大系统字号下，固定标题出现截断，固定双按钮区压缩表单可读区域，报名按钮横排也造成文字挤压。本批采取布局适配，不限制系统字体放大：

1. `PageFrame` 在 `fontScale >= 1.6` 时将标题放进可滚动内容，保留固定返回入口；操作区移至内容末尾。标题置于既有 `contentRef` 内，保持错误字段测量坐标一致。
2. `BottomSheet` 同阈值下将操作区放入面板滚动内容；保留安全区及键盘避让。
3. `ApplicationSheet` 在大字下改为全宽纵排取消/提交，标准字号维持原横排。没有更改校验、幂等、版本和提交语义。

| 代表流程 | 结果与证据 |
|---|---|
| iOS 最大辅助字号：仓库表单、核对、返回修改 | 工具实际核对 1.86 保留，标题完整、内容可滚动 |
| iOS 报价为空时错误定位 | 工具实际触发，滚至报价字段并完整显示校验错误；标题移动未破坏锚点 |
| iOS 代送核对 | 工具选择待确认并进入核对：保留途中交接与数量待确认，不出现仓库地址 |
| iOS 大字报名失败重试 | 工具填写件数、首次失败保留、再提交成功到 TEST 回调 |
| iOS 软件键盘与最大字号 | 实际数字键盘展开后可滚到完整核对/草稿按钮，点击核对进入核对页 |
| Android 2.0 仓库表单 | 软件键盘出现时可滚到操作区；用户确认核对后返回仍为 1.86，文字和按钮均可滚动查看 |

| 标准字号复核 | iOS 核对页恢复固定操作区；Android 报名恢复横排按钮，视觉核对通过 |

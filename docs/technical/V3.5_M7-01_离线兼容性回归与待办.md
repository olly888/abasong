## 2. 新旧服务兼容性结论

历史服务源码 `cb8cde2` 仅用于确定旧契约；未重新登录 AWS 核对当前运行镜像，不能据此声称云端精确版本已复核。

| 项目 | 源码事实及本地验证 | 实际含义 |
|---|---|---|
| 附近基础发现 | 普通 `/discover` 不附带 `expand`；旧观察 DTO 为严格校验 | 基础目录请求不随扩围开关改变 |
| Mapbox 扩围 | 旧 DTO 不接受 `expand`，客户端保留 HTTP 400，不自动删字段重试 | 新版扩围仍需服务升级；不能把失败当作查遍范围后的零结果 |
| 两场景筛选 | 旧列表 DTO 不接受 `scenario`；两种场景均验证错误状态且不请求未筛选结果 | 不通过自动放宽筛选制造“看起来可用”的结果 |
| 服务恢复重试 | 首次 503 保持失败；用户重试使用相同场景参数，服务恢复后才接受成功空列表 | 查询失败与真正没有开放需求保持区分 |
| 快速切换 | 请求在找活旧参数上迟到失败，不覆盖较新的找人结果 | 跨模式隔离保留 |
| 查码 | 400/404/503 是错误，401/资格 403 是受限；都没有正文 | 不能显示成“暂无共享密码”或保留失效正文 |
| 共享暂停 | 明确 `sharing_paused` 或暂停错误时丢弃正文；普通旧响应缺少附加字段时仍可读取 | 这只是客户端响应兼容性，不证明旧服务能落实新暂停规则；云端治理仍必须配套升级 |
| 未读消息 | 只读核对新旧服务均返回消息数和通知总数；新版增加司机圈回复子集。首页只加前两项，通知页缺少子集时不显示细分说明 | 不重复加算司机圈回复；这里是源码核对，没有新增真实通知或原生界面验收 |

`HomeApartments` 的现有失败分支仍把供应商失败设置为不可用；`nearbyResultState` 只有完整成功且没有候选时才给出空态。已有有效目录卡片可保留，并显示更新失败；过期候选由现有时间与位置边界清除。相关已有测试一并运行，不为兼容旧服务削弱这些规则。

## 范围与修正

在既有 iOS27/iPhone18Pro 和 Android AOSP API37 原生开发容器运行候选 Metro8083。只使用 ContributionLab、AccessContributionLab、CommunityVisualLab 的内存 TEST；没有业务库写入、真实发帖或云端变更。

实际发现：手填贡献输入后点返回会立即丢失内容；本人纠正也缺少同类退出保护。本批以 `useAccessFormExit` 统一页头返回和 Expo Router 移除事件：

- 本次已编辑才出现「离开这次填写？／继续填写／放弃并返回」。继续填写保留当前输入；确认离开才执行原返回动作。
- 地址输入和主动更换属于编辑；首次自动加载卡片地址不算编辑。新记录仍不默认猜门别。
- 提交期间阻止误退出；失败保留内容和原幂等机制；成功先解除保护再执行原公寓回程，不弹第二个退出确认。
- 仅保留当前页面内存；不新增截图跨次续填、服务器草稿或普通撤回功能。未修改契约、数据库、权限或依赖。

实现依据为已安装 Expo58 Router 的 [usePreventRemove](https://docs.expo.dev/router/advanced/prevent-screen-removal/)；同时核对安装包实现的 `repeat` 与解除保护返回值。系统边缘滑动/硬件返回的完整复测仍单列，不能由页头点击推断全部系统手势通过。

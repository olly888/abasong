# 短信登录账号准备

更新：2026-10-30。用户已于2026-10-30告知Twilio注册完成；账号状态与Verify Service尚未通过连接器核验，接下来准备Supabase供应商配置。本文是准备步骤，不表示短信已启用或真实登录已验证。

1. 用户访问 https://www.twilio.com/try-twilio ，用自己的邮箱注册，亲自完成条款确认、邮箱和个人手机号验证。
2. 项目信息按实际填写：Abasong、美国司机协作应用、手机号一次性验证码登录、开发测试。出现产品选择时选择Verify/用户验证相关选项。
3. 当前官方支持无需信用卡注册试用。初次准备先使用试用账号，不要求立即购买发送号码或升级付费。
4. 登录Console，进入Identity > Verify > Overview，查看Try out Verify。试用仅能向已验证的接收号码发送验证码，默认包含注册手机号。若当前控制台提供Services入口，后续再准备Verify Service；若只提供试用页面，记录界面所示Service SID供接入核对，不混用Messaging Service SID。
5. 后续需要Account SID、Auth Token和Verify Service SID；Auth Token只输入Supabase服务端供应商配置或经确认的本机忽略配置文件，不发聊天、不放EXPO_PUBLIC_*。
6. 注册完成后告知账号已就绪。接入时在AbasongDevWest上配置Phone供应商、发送限制和测试号码；真实短信测试由用户指定并授权的手机号完成。面向外部司机前另行核对供应商账号升级、客户资料审核、发送国家范围及费用。

## 注册完成后的配置

在Twilio Console准备Account SID（AC开头）、Auth Token及Verify Service SID（VA开头）。如尚无服务且控制台允许创建，名称使用Abasong，开启SMS，保留Fraud Guard；如试用界面限制服务创建，先核对Try out Verify提供的服务信息，不要求为完成此步骤立即升级付费。

用户将三项直接填入AbasongDevWest项目的Authentication → Sign In / Providers（或Providers）→ Phone，供应商选择Twilio Verify，启用Phone后保存。Auth Token由用户直接在供应商配置表单输入，不进入聊天或移动端。保存后先读取公开Auth设置确认Phone启用；这仍不能替代真实收码、验证、会话与退出验收。
